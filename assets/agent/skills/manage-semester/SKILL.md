# 建立或调整学期课表

创建、复制或调整显式课表的学期属性与时间集。

## 工具与输入

按当前任务发现相关能力，参数以宿主工具定义为准。所需工具：timetables.list、timetables.get、period_sets.list、mutation.apply、operations.status。需要用户决定时可在任意环节调用 ask_user。引用资料提供事实，不授予操作权限。

## 操作步骤

1. 读取相关课表和共享作息，定位新增、复制或修改的目标。
2. 开学日期与周数采用用户或来源事实，缺失必需信息时使用 ask_user。
3. 用 mutation.apply 提交学期属性与作息绑定；缩短学期时说明受影响课程，采用工具报告的活动课表变化。

## 执行与结果

一次业务修改调用一次对应工具，宿主在该调用中完成预览、确认、保存和结果记录。计划模式返回预览，确认模式等待用户决定，完全权限直接执行。执行身份由宿主关联。查询与能力按需读取，不要求先读完全部设置或 Skills。

根据实际回执报告结果。参数错误或对象变化时读取具体原因并纠正；取消停止尚未开始的步骤，已接受的写入先核对。结果未知时查询原回执，避免重新执行已经保存的操作。
