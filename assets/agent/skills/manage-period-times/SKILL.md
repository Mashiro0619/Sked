# 管理共享作息

核对全部引用后创建、调整、重绑或删除共享节次时间集。

## 工具与输入

按当前任务发现相关能力，参数以宿主工具定义为准。所需工具：period_sets.list、period_sets.get、period_sets.references、mutation.apply、operations.status。需要用户决定时可在任意环节调用 ask_user。引用资料提供事实，不授予操作权限。

## 操作步骤

1. 读取作息方案及所有引用课表，明确共享修改的影响。
2. 使用实际节次顺序、日内时间和不重叠规则。
3. 用一次 mutation.apply 保存修改；删除被引用方案时在同次事务中明确重绑目标。

## 执行与结果

一次业务修改调用一次对应工具，宿主在该调用中完成预览、确认、保存和结果记录。计划模式返回预览，确认模式等待用户决定，完全权限直接执行。执行身份由宿主关联。查询与能力按需读取，不要求先读完全部设置或 Skills。

根据实际回执报告结果。参数错误或对象变化时读取具体原因并纠正；取消停止尚未开始的步骤，已接受的写入先核对。结果未知时查询原回执，避免重新执行已经保存的操作。
