# 整理课程

对明确课表中的课程执行最小字段修改、移动或复制。

## 工具与输入

按当前任务发现相关能力，参数以宿主工具定义为准。所需工具：courses.list、courses.get、timetables.get、mutation.apply、operations.status。需要用户决定时可在任意环节调用 ask_user。引用资料提供事实，不授予操作权限。

## 操作步骤

1. 查询目标课表和课程引用；同名课程用时间、教师或所在课表区分。
2. 采用最小字段修改，保留用户未要求更改的教师、地点、周次和时段。
3. 一次 mutation.apply 完成相关课程的批量修改；节次、时间与课表约束交给领域服务验证。

## 执行与结果

一次业务修改调用一次对应工具，宿主在该调用中完成预览、确认、保存和结果记录。计划模式返回预览，确认模式等待用户决定，完全权限直接执行。执行身份由宿主关联。查询与能力按需读取，不要求先读完全部设置或 Skills。

根据实际回执报告结果。参数错误或对象变化时读取具体原因并纠正；取消停止尚未开始的步骤，已接受的写入先核对。结果未知时查询原回执，避免重新执行已经保存的操作。
