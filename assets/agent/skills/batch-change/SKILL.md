# 跨对象批量修改

固定对象与版本集合后执行可预检的批量变更。

## 工具与输入

按当前任务发现相关能力，参数以宿主工具定义为准。所需工具：timetables.list、courses.list、calendars.list、events.list、selection.create、selection.get、mutation.apply、operations.status。需要用户决定时可在任意环节调用 ask_user。引用资料提供事实，不授予操作权限。

## 操作步骤

1. 用 selection.create 固定完整目标集合，按需通过 selection.get 分页查看，明确是否包含隐藏与停用数据。
2. 使用最小字段修改，不在执行时重新解释自然语言筛选，不吸收后来新增对象。
3. 同一主库批量修改使用一次 mutation.apply 完成一个事务；以回执确认完整目标集合。

## 执行与结果

一次业务修改调用一次对应工具，宿主在该调用中完成预览、确认、保存和结果记录。计划模式返回预览，确认模式等待用户决定，完全权限直接执行。执行身份由宿主关联。查询与能力按需读取，不要求先读完全部设置或 Skills。

根据实际回执报告结果。参数错误或对象变化时读取具体原因并纠正；取消停止尚未开始的步骤，已接受的写入先核对。结果未知时查询原回执，避免重新执行已经保存的操作。
