# 内置 Agent 的 Skills

Skills 按用户任务组织，帮助 Agent 选择业务工具、补齐信息和解释结果。一个内置 Agent 的多个会话共享技能目录，按需加载正文；不会为每个会话复制独立的技能与长期记忆。

## 资产与契约

内置资源位于 `assets/agent/skills/`，完整目录、版本、摘要和依赖以[manifest](../assets/agent/skills/manifest.json)为准。当前技能包使用工具契约 2.x。它们是 Sked 的产品资源，不依赖开发者机器上的 Codex Skills。

Manifest 记录稳定 ID、内容版本、用途、触发提示、资源路径、SHA-256、来源类型及必需/可选工具。装载器核对实际正文摘要和已登记依赖；缺少必需工具时返回明确原因。

技能正文围绕任务描述行动。例如先定位具体课表，必要时询问开学日期，然后通过一次业务工具调用完成创建或批量调整。内置正文不再要求模型先读取全部能力和设置，不再指导填写宿主操作 ID、执行配额或单独提交准备结果。

## 权限与资料

- Skill 提供工作指导；工具入口解析参数，领域服务处理业务规则。
- 宿主决定三种权限模式，模型文本不能制造授权。
- 用户输入、网页、文件、工具结果和长期记忆按各自来源使用。
- `ask_user` 和 `update_plan` 是通用工具，不限定在几个预设业务场景中。

计划模式返回可读业务预览；确认模式在当前业务调用内等待决定；完全权限执行合法动作。事实不足时仍需要查询或提问。系统权限由实际平台接口决定。

业务修改的一次工具调用由宿主完成准备、确认、保存和回执。查询使用当前业务对象；引用中的名称、Skill 示例或记忆不能替代稳定对象身份。

## 按需发现和运行快照

普通只读工具不依赖 Skills 或记忆初始化。能力按需发现，已经公开的定义不反复加入请求。用户显式引用的 Skill 在发送时核对选定版本，运行使用不可变正文与依赖快照，修改在后续运行生效。

技能篇数、单篇正文和累计正文没有固定容量门槛。请求上下文通过按模型配置的压缩服务管理；完整历史仍保存在会话 JSONL 中。大列表使用可遍历分页，页面大小不限制任务总量。

当前运行的目标、用户决定和真实回执优先于技能中的泛化步骤。参数错误正常回送模型修正，未知保存先核对回执。技能不能把未知效果写成成功。

## 修改、备份与维护

内置覆盖、自定义技能、启停、原版更新和恢复行为使用[共享知识服务](AGENT_KNOWLEDGE.md)。原版包随应用发布，自定义内容进入 Agent SQLite 库。选择性备份携带所选生效正文及原版来源，不授予导入内容额外权限。

更新内置 Skill 时同步 manifest 摘要和依赖，核对公开工具名称及权限说明；更新工具契约时同时修订相关技能，移除已退役调用。
