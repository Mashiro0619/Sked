# 自适应工作台规范

本文记录当前布局、导航和任务状态约定。历史修订、截图清单与测试次数由 Git 历史追溯；待完成的平台验证统一见[发布验收清单](RELEASE_ACCEPTANCE.md)。桌面浮层的交互细节见[桌面浮动面板](DESKTOP_FLOATING_PANELS.md)。

## 布局预算与资源导航

沿用 Material 3 Expressive、用户精确配色与本地优先数据模型。600／840／1200 dp 是窗口等级，实际并栏由 `WorkbenchLayoutPolicy` 按区域预算计算，不能直接作为固定单双栏断点。

字号预算倍率为 `max(1, textScale)`。桌面资源导航预算独立于工作区、日历视图及打开的任务；任务不能为了并栏擅自折叠资源导航。

| 区域 | 正常字号预算 | 约束 |
|---|---:|---|
| 展开资源栏 | 224 dp | 桌面主区域至少 800 dp，并满足共享顶栏内容及原生窗口按钮预算；另计 1 dp 分隔 |
| 紧凑资源栏 | 桌面 56／触控 80 dp | 桌面主区域至少 360 dp；不足时隐藏资源栏但保留入口 |
| 自动并栏画布 | 通用 600／七日周视图 800 dp | 用于判断旁栏空间，不限制窄窗口运行 |
| 显式并排画布 | 360 dp | 仍按字号放大，超出预算时转覆盖 |
| 普通详情／助手 | 默认 360／400 dp，最低 320／360 dp | 可调宽，受可用内容区域约束；完整编辑器使用独立尺寸 |
| 设置双栏 | 索引 224 + 内容 520 + 分隔 1 dp | 按字号及实际可用宽度决定是否并栏 |

- 桌面短窗口优先紧凑资源栏；自动收缩与用户展开偏好分开，尺寸变化不写回偏好。窄窗展开使用临时资源抽屉，恢复宽度后恢复用户偏好。
- 面板显示模式有覆盖、并排和自动。覆盖不预留画布宽度；并排允许画布降至显式并排预算；自动按当前视图的画布预算决定停靠。调整宽度到画布下限后，任务可覆盖剩余画布，不突然释放全部预留空间。
- 详情与助手有各自的打开状态、宽度和草稿。不能同时呈现时只显示最近操作的任务，另一个保留会话并移除输入、焦点与语义。月视图安排栏属于基础视图，任务预留空间时复用其位置。
- 普通表单限制阅读宽度，画布使用剩余空间。可见导航、资源与画布不被嵌套 Navigator 的语义容器遮掉；隐藏区域移除焦点和语义。

实现入口：[布局策略](../lib/widgets/workbench_layout_policy.dart)、[布局常量](../lib/widgets/app_layout_tokens.dart)、[任务框架](../lib/widgets/workspace_frame.dart)。

## 桌面任务与窗口

课程／日程查看、编辑和助手复用工作台任务宿主。完整课程／日程编辑器在覆盖模式使用透明模态浮窗，在并排模式保留编辑栏；拖动、调宽和自动停靠不重建草稿。编辑浮窗首选宽度 600 dp、手动范围 320–680 dp、高度上限 720 dp，并受可用窗口约束。标题与底部取消／保存固定，仅正文滚动；首次拖动后本次会话保持浮动，关闭重开重置。

桌面选择器、分类短表单和查看面板共享内容表面、8 dp 圆角、细轮廓与柔和阴影。标题文字及空白区可以拖动，操作按钮和正文不参与拖动；锚点、边界避让、任务退出、嵌套选择器、独立详情和异步提交规则以[桌面浮动面板](DESKTOP_FLOATING_PANELS.md)为准。原生菜单保留自己的高程和交互。

- 覆盖编辑器阻挡背景业务输入，应用顶栏原有空白区仍可移动窗口；浮窗标题只移动浮窗。并排任务按其宿主规则保留背景交互。
- 当天安排和提醒列表可以打开悬停预览或独立详情。独立详情不随源列表滚动、换日或关闭而销毁；子确认与保存保护继续生效。
- 桌面分类管理使用锚定透明模态任务，资源栏“＋”直接新建名称。颜色按分类 ID 局部更新；管理面板完成退出后再进入原导入／导出页，返回不自动重开。
- 所有退出途径尊重草稿和忙碌守卫；异步完成只关闭自身路由。数据、工作区或父任务失效后，旧回调不得提交到新目标。

`DesktopWindowBridge` 与 Windows runner 通过 `com.mashiro.sked/window` 通信。应用操作与窗口控制共用顶行；引导、恢复、设置和管理不增加独立标题栏。保留边缘缩放、双击最大化／还原、最小化、系统菜单、关闭和 DPI 处理。

最大化区域使用 `HTMAXBUTTON`，非客户区消息交给 DWM／DefWindowProc。关窗先执行草稿守卫、提交延后 UI 写入并等待在途保存，取消或失败不得关窗。原生命中测试与 Flutter 截图不能证明贴靠菜单、真实鼠标拖动或多显示器行为已验收。

## 手机与紧凑触控布局

- 课程／日程详情、编辑与关联清单采用底部模态任务，共享业务内容与保存逻辑。新任务继承已打开的移动模态栈，旋转不搬移现有草稿；输入法高度只扣一次。外部点击按已有偏好请求退出，完整详情／编辑不允许拖拽关闭。
- 首页操作栏与内容使用同一底色。日程工具栏将分类、日期、视图与操作放在一行，不显示左右日期按钮；优先省略同年日期的年份给完整分类名称让位，跨年保留年份，完整日期保留在语义和提示中。
- 工具栏排序与隐藏偏好保留；工作区切换可排序，默认与设置放入更多。仅双工作区启用且底栏隐藏时提供切换入口，更多直接列出两个工作区。
- 底栏保留官方 NavigationBar、64 dp 常规内容区和单次系统安全区；长标签与大字号允许增高。选中状态使用图标、颜色和字重，保留按压、焦点、键盘与辅助技术反馈。
- 紧凑触控周视图默认铺满 5／7 列，关闭“周视图适应屏幕”后采用宽列横向浏览；超过七天的自定义范围继续横向浏览。课表同名偏好独立保存。
- 自定义范围的最小日列宽支持自动或 64–320 dp 手动值，步长 8 dp、手动初值 96 dp；只影响自定义范围。表头、全天区与时间网格共享列宽和命中坐标，不修改真实时长。
- 紧凑月视图使用月历及当日日程的一条滚动流；日期行按字形、农历和字号预算，不留空日程占位。宽屏空间足够时旁置安排。
- 日期表头按实际文字测量高度；月份／年份层优先四列，大字号减列。320 dp 下七列日期不能保证每格 48 dp 宽，应保留文字大小与行高，不以缩字宣称触控预算达标。

## 日期与时间选择

- 日视图选择单日，周视图选择自然周，月视图顶栏选月，列表选择起始日。侧栏小月历翻页只浏览；明确日期导航才改变主日期。
- 普通周入口点按跳周，显式拖选转为自定义范围；自定义入口支持两点与拖选，范围为 1–14 天。反向、跨行及可见邻月可选；越界松手、指针取消、多指、布局或会话变化均不得提交。
- 范围预览不保存，合法完成后一次提交；非法输入显示行内错误，失败保留候选并支持重试。日期／范围导航使用 Provider 串行事务及持久化屏障，保存成功后原子发布，不等待无关的通知互斥锁。
- 手机跳周使用标题附近的紧凑锚定浮层，业务单日与时间使用居中卡片；主页切周、月份导航与范围拖选继续使用对应底部弹层。锚点与边界避让安全区及键盘。
- 手机时间使用三行循环滚轮与一条选中带，可切换手动输入；两种模式共享草稿，运动中或输入非法时禁止切换及确认，取消仍可用。小时与分钟独立回绕，不自动进位。
- 导航选择与业务字段区分：业务日期／时间必须确认，取消不改原草稿；结果不得绕过编辑器校验、保存与任务有效性检查。

## 设置入口与视觉

总览和宽屏索引由 `settingsCatalog` 驱动，顺序为学生课表、通用日程、提醒与通知、外观与语言、工作区、数据与隐私、关于。停用域不显示专属分组，索引回退到第一个有效分组。设置没有全局搜索，语言页保留内部搜索。

| 功能 | 当前入口与契约 |
|---|---|
| 课表／日程显示与交互 | 设置 → 对应工作区分组；周列、网格、默认视图等细项在二级页 |
| 主题与分项颜色 | 设置 → 外观与语言；显式工作区编辑目标与局部预览，不切换活动工作区 |
| 语言 | 外观与语言分组 → 语言；搜索、失败重试及宽屏当前分组保留 |
| 默认提醒、权限与排障 | 提醒与通知；课程和日程均可跟随默认，隐藏日程分类是否继续提醒由用户偏好决定 |
| 课程专属系统提醒 | 课程编辑 → 更多；跟随默认／不提醒／自定义，非法值展开并定位错误 |
| 工作区启停与导航偏好 | 工作区；至少启用一个，隐藏导航不等于停用 |
| 课表、节次及学校站点 | 课表菜单管理节次时间集，编辑／导入选择绑定；管理共享资源不修改当前课表绑定 |
| 分类显隐、名称与颜色 | 日程分类管理；桌面浮动任务，手机／触控平板为页面 |
| 内容导入导出 | 对应资源管理及数据入口；不改变工作区启用范围 |
| 完整备份、恢复、清除与隐私 | 数据与隐私；确认启用变化与草稿，保留危险操作保护 |
| 更新、许可与开发者功能 | 关于；保留平台限制与开发者解锁手势 |

设置行以连续分组表达关系，标题、说明和当前值分层；长文本与大字号换行，不截断关键偏好。手机使用单滚动区的大标题，桌面保留紧凑固定标题和窗口按钮避让。外观手机预览位于控件之后，宽屏旁置。

设置首页的提醒分组只保留总开关和“提醒设置”入口；正常排程的时间范围、数量、容量与续期说明留在提醒详情页，不作为常驻概览显示。权限受阻、排程失败或电池策略限制时，首页显示具体原因并提供处理入口，恢复正常后移除提示；这些提示不夹带排程统计。此展示调整不改变提醒排程、容量、权限或后台续期策略。

显示设置按主页实际采用的平台布局提供选项。Windows、macOS、Linux 的宽窗与窄窗均隐藏日程的“视图切换按钮”“工具栏空间分配”，以及课表和日程的“显示悬浮添加按钮”；桌面仍使用原有工具栏菜单和添加入口。Android、iOS 的手机与平板保留这些选项。隐藏只影响当前设置页展示，不改写既有偏好或备份数据。

下拉菜单锚定当前值按钮，按内容取自然宽度，基本宽度 144 dp、最大 360 dp，并受屏幕安全区约束。整行仍可点击，按钮承担键盘焦点及合并语义；长菜单限高滚动，关闭后恢复焦点，失效会话不得回写。

实现入口：[设置目录](../lib/models/settings_catalog.dart)、[设置页](../lib/screens/settings_page.dart)、[自适应设置框架](../lib/widgets/adaptive_settings_scaffold.dart)。

## 持久化、停用与恢复

- AppData 顶层 schema 为 v4；v3 引入启用工作区与提醒恢复边界，v4 迁移工具栏配置。独立课表／日程文件格式不随顶层版本变更。
- 首次选择仅课表／仅日程／两者，与隐私同意一起保存成功后生效。旧 v1／v2 数据迁移为两域启用；空集合、非法值及活动域不一致进入错误恢复，不静默重新启用。
- `setWorkspaceEnabled` 串行化，停用当前域时原子切换，重新启用不强制切换；`switchMode` 拒绝停用域。普通切换保留会话，停用保留数据、配色和配置，但卸载页面并拦截在途结果。
- 导航、导入导出、主题及默认提醒过滤停用域；只有功能管理提供重新启用入口。单工作区不显示单项切换导航。
- 通知读取 `AppRepository.persisted` 已提交快照，事务和运行时版本边界阻止旧任务回写。按来源清理排程、已展示通知和稍后提醒；重新启用以 UTC 边界排除停用期间已到期提醒。
- 写入失败维持旧启用状态；提醒清理失败保留停用标记、异常反馈和重试。清除数据不扩大运行时锁，避免回入等待。
- 完整备份包含停用域数据和启用选择，排除 API 密钥。恢复确认所有被覆盖域的草稿，即使恢复后仍启用；批准丢弃后退役旧编辑会话，普通导入不改变启用范围。

## AI 布局预览

`DeveloperUiPreferences` 只在本机保存开发者预览功能开关，不进入 AppData 或备份；保存值优先于默认关闭的 `SKED_AI_LAYOUT_PREVIEW`。仅开发者页启用／禁用会写回偏好，普通关闭、Esc、系统返回和布局降级只改变当前面板状态。

每次启动默认收起面板；加载偏好、重试或启用功能仅显示入口，明确点击入口后才展开。`AssistantPaneController` 保存当前会话的打开状态、宽度与输入草稿。预览发送不可用，不调用解析 API、不保存聊天、不执行数据修改；上下文只含启用域、资源标识、日期／视图与选择标识，不含密钥、记录正文或停用域。
