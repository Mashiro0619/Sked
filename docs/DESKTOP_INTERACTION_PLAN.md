# 桌面基础交互补齐计划

状态：D1 会话对象菜单已实现，其余条目待实施；Windows 原生交互验收待进行。初次缺口审查基线为 2fd2fcb3，当前会话行为见[Agent 对话界面](AGENT_CHAT_DESIGN.md)。

## 目标与优先级

Sked 桌面端应支持用户熟悉的对象操作、键盘操作和文件交互。用户能够直接对会话、课程、日程、资源和文件进行操作，无须先切换到目标详情，再寻找分散的按钮。

本计划覆盖整个桌面应用，与[Agent 插件架构及上线目标](AGENT_PLUGIN_ARCHITECTURE.md)并行推进。首先补齐对象右键菜单和常用快捷键；文件拖入、剪贴板附件和系统文件动作与 Agent 文件能力衔接。右键指上下文菜单，本轮不增加鼠标侧键或按住右键划动的轨迹手势。

这批交互直接接入现有业务动作，不等待整个应用完成插件化。共享动作接口为后续插件贡献保留入口，避免菜单、快捷键和工具栏各自实现一套业务保存逻辑。

## 统一对象动作

### 同一动作服务多个入口

建立轻量的 DesktopAction / DesktopActionContext：动作声明稳定身份、文案、图标、可用性、快捷键和执行入口；上下文携带目标对象、焦点区域、宿主身份及当前状态。工具栏、右键菜单和键盘入口读取同一组动作，并调用现有业务服务及反馈机制。

右键命中哪个对象，菜单就绑定哪个对象。打开菜单只建立操作目标，不触发左键进入、切换当前会话或改变日历显隐。即使正在阅读会话 A，也能直接对列表中的会话 B 改名、固定或归档。

执行前重新核对目标身份、存在性、权限和忙碌状态；取消菜单、源对象移除或宿主失活后，尚未接纳的旧回调失效。正常选择动作后，由单次命令继续持有目标和执行结果，不因菜单退场重复执行或改绑对象。菜单不能依赖执行时的“当前选中项”去推测原目标。对象更新后的动作可用性继续由原业务规则决定。

### 对象菜单覆盖

| 对象 | 接入动作 |
| --- | --- |
| 会话行 | 改名、固定／取消固定、归档／恢复、导出、删除；复用各自保存与确认规则 |
| 消息 | 复制整条消息，以及该消息实际支持的编辑并重做、重新生成等现有动作；已选中文字时优先保留文本选择菜单 |
| 课程 | 查看、编辑和删除等已有动作 |
| 日程 | 查看、编辑、复制和删除；重复日程保留本次、未来或全部的原选择流程 |
| 课表、日历分类、节次时间集 | 接入各对象已有的编辑、改名、显隐、复制、导出或删除动作；按对象类型提供实际支持项 |
| Skills、记忆等知识项 | 接入查看、编辑、启停、恢复内置版本和删除等已有动作 |
| 附件与交付文件 | 预览、再次附加、移除等已有动作，并逐步接入保存副本、系统打开、定位及复制路径 |

指针触发在鼠标位置附近打开；键盘触发锚定焦点对象。菜单在窗口边缘避让，长内容可滚动，Esc 关闭，结束后按原输入来源恢复焦点。菜单动作可由当前按钮继续触发，触屏沿用现有入口。

文本字段、选中文字和链接有各自的上下文操作优先级。可编辑文本继续使用剪切、复制、粘贴、全选等标准菜单；对象级动作通过对象的空白区域、操作按钮或键盘入口访问。

### 后续列表批量管理

先在会话历史和资源管理列表接入 Ctrl+点击切换勾选、Shift+点击选择连续范围。勾选集合独立于正在阅读的对象；普通点击继续执行原有打开行为。范围使用当前可见排序与稳定对象 ID，筛选或数据来源变化时清理失效选择。

右键位于已勾选集合内时保留该集合，位于集合外时只操作命中项。菜单提供所选对象共同支持的归档、导出或删除等批量动作，显示目标数量并沿用实际保存和确认规则；批量结果按真实执行结果反馈。改名等单对象动作只在单选时提供，文本编辑中的 Ctrl+A 继续选择文字。

## 键盘、焦点与文本

快捷键按当前可交互区域解析，优先级为顶层菜单或对话框、当前编辑任务、当前内容区域。隐藏页面和后台编辑器不响应。

| 输入 | 目标行为 |
| --- | --- |
| 菜单键、Shift+F10 | 打开当前焦点对象的同一份上下文菜单 |
| Ctrl+F | 展开或聚焦当前区域已有的搜索，例如会话历史、语言列表；不无条件切换到其他页面或全局搜索 |
| 搜索中的 Esc | 临时展开的搜索先收起并保留查询；常驻搜索释放焦点；恢复仍有效的触发焦点，不同时退出外层任务 |
| Ctrl+S | 调用当前编辑器原有的校验与保存入口，遵守忙碌和失败处理；自动保存编辑器通过原 flush 入口处理 |
| F2 | 焦点位于可改名对象时，进入该对象原有的改名流程 |
| Delete | 焦点位于可删除对象时，进入原有删除及确认流程；文本编辑状态下保留删除文字行为 |

Tab / Shift+Tab、Enter、Space、文本选择、Ctrl+A/C/X/V/Z 及重做沿用控件行为。新增快捷键检查输入法合成状态，不抢走输入框或局部控件的编辑按键。菜单项和工具提示显示已接入的快捷键，禁用原因与原按钮一致。

只读正文、路径和需要复用的信息继续提供选择或复制入口；不把整个页面强行变成可选择区域，以免干扰列表、按钮和拖动。

## 桌面文件入口与交付

### 拖入和粘贴

增加桌面输入适配器，将拖入的文件、粘贴的图片和文件列表转换为现有附件输入。先接 Agent 当前输入区；其他导入页面按自身支持格式接入同一适配器。

拖入时显示有效落点和目标区域。接纳绑定当时的会话与输入身份，复用已有复制、核验、进度和取消流程；添加后保留为草稿，发送仍由用户触发。文件夹以资源引用交给 Agent 文件服务处理。

输入区统一接纳一次 Ctrl+V 粘贴动作，读取剪贴板后按载荷类型分派：图片或文件接入附件链，纯文本委托原文本粘贴逻辑。异步读取期间不同时派发第二条粘贴路径；失败保留可重试信息。

### 文件系统动作

建立 DesktopFileActions，接收已登记的文件或产物引用，提供默认应用打开、在资源管理器中定位、复制路径和另存为。附件、笔记、导出与未来 Office 产物共用入口。

已经保存到用户位置的文件直接使用真实路径。私有附件按原文件名生成受管理的打开副本；需要保留到用户目录时使用另存为，定位和复制路径针对实际可用文件。模型正文中的任意路径或 file URL 不直接转成可执行系统动作。

## 恢复后的验收

- 正在查看会话 A 时，右键会话 B 能直接改名、固定、归档或删除 B；打开菜单不切换阅读对象。键盘菜单入口得到同一组动作。
- 课程、日程、资源、知识和附件菜单可直接访问已有业务动作；重复日程和危险操作保留原有确认，旧菜单不作用于新对象。
- 在编辑器内选字、右键、复制粘贴及撤销重做正常；Ctrl+S 只保存当前任务，输入法合成不会产生误提交。Ctrl+F 和 Esc 只影响当前搜索层。
- 拖入文件、粘贴截图进入当前草稿，显示处理结果和取消状态；保存结果能在默认程序打开、在资源管理器定位，并复制真实路径。
- 列表多选完成后，Ctrl／Shift 选择、右键目标和批量确认数量一致；筛选、排序与对象删除后不操作已失效的目标。
- 窗口边缘菜单、大字号、不同 DPI 和窗口缩放下，动作保持可见可操作。滚轮、触控板、滚动条、文本选择及面板拖动各自作用于命中区域，不误触翻页或窗口移动。
- 保留已有标题栏、Snap、窗口恢复、Tab、隐藏区域焦点隔离与保存后关窗行为。Windows 原生鼠标、键盘及系统文件动作单独记录验收证据。
