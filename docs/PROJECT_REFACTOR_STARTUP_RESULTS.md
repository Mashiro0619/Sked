# Windows Profile 独立进程启动结果（2026-10-17）

完整的 18 个独立进程样本通过时间、内存、窗口、输入与文件锁检查。5,000 事件数据集的进程创建至就绪 raster 中位数从 **5.459 s 降至 2.267 s（−58.47%）**，同时就绪报告观察点的整进程 RSS 从 **386.71 MiB 增至 444.41 MiB（+57.70 MiB，+14.92%）**。首个 raster 仍约为 0.44 s。稀疏数据的日期选择响应中位数从 83.246 ms 增至 92.296 ms；这些样本不能概括为所有场景均改善。

结论仅覆盖本报告固定条件下、加入测量与隔离入口的 Windows Profile 版本。三次重复提供描述性范围，不证明统计显著性，也不归因到某一个重构改动。此前工作区挂载、磁盘加载和进程内 UI 测量保留各自边界。

这些检查支持“仪器化基线加对称启动／隔离入口，与仪器化新版比较”。它们不等于重现未修改基线的发布包，也不能单独量化组合根改动的收益。源码核验脚本与逐文件差异在本次 `startup-results/source-review/` 中保留。构建收据曾将七份生成插件文件标为修改；存档完整 Git patch 无这些文件的内容 hunk，当前基线副本在换行规范化后与原始提交相同，但历史原始字节未单独冻结，不能扩写为全工作区逐字节重现构建。

## 校验、旧样本与可接受范围

2026-10-17 仅对已保存证据进行离线核验，没有补采样。完整验证器重放输出与存档候选完全一致；另独立重算 18 个进程各 67 个指标、六组各 67 项统计，并核对 327 个文件的 SHA-256。原始 summary、launcher row、run manifest、result、PID／映像／编译版本、完整 artifact、声明源码、原始 fixture 及语义哈希互相匹配。ready／response 的 14 项视图与可访问性字段在 36 次观察中一致。

QPC／精确 FILETIME 原始样本、stamp 索引、引擎独立残差与 begin 关联重算通过；最大 native bracket 为 2 µs，native offset drift 为 4 µs，独立残差为 3 µs，engine offset drift 为 2 µs，5 ms 门槛没有放宽。launcher 的漂移记录绝对值不超过 77.9 µs，但原始退出 UTC／Stopwatch 终点未落盘，只核对记录值门槛，不能声称独立重算该项。

全部进程在 ready framework、ready report、input、response framework、response report 五处观察到同一 child-owned、可见、未最小化、未 cloak、客户区与显示器相交的 HWND。每个样本均由其他 PID 对实例锁和通知锁得到 Windows Error 33，退出码为 0，没有超时。窗口快照不证明历史 raster 时刻的像素完整呈现或始终无遮挡。
