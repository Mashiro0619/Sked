# Agent 共享技能与长期记忆

一个内置 Agent 的全部会话共享技能和长期记忆。设置中的编辑器与 Agent 工具使用同一知识服务、版本检查和持久化仓储；会话历史、应用业务数据、凭据及知识内容分别存储。

## 技能与记忆

内置技能来自应用资源包。用户和 Agent 可以编辑其生效内容或单独停用技能；编辑建立本机覆盖，不改写资源包。恢复原版内容保留启停选择。应用原版更新后保留已有覆盖并显示原版变化，缺少必需工具的技能不可执行。自定义技能可以创建、编辑、停用和删除；技能正文不能更改宿主权限，也不能通过路径、链接或声明安装执行代码。

技能目录和正文按运行使用不可变覆盖快照。当前运行继续使用已固定版本，修改供下一次运行加载。发现同时查询标题、用途和触发提示，正文按需读取，继续遵守技能数量和输入预算。编辑内容不必使用内置技能的中文章节模板。

长期记忆保存稳定偏好或后续任务需要的信息。Agent 在正常会话运行中查询和维护记忆，不额外创建后台任务。记忆可以保存来源说明、来源会话/消息及结构化业务引用；过期、旧数据世代或尚未验证的引用明确需要重新核对。执行业务操作时仍查询实际课表和日程，记忆不是执行回执。删除聊天不会自动删除共享记忆。

## 修改与权限

`skills.get`、`memories.search/get` 用于查看；`skills.prepare` 和 `memories.prepare` 返回具体变更计划，`external.commit` 才提交。只读计划模式不能写入；询问模式展示完整变更；完全权限按当前模式执行。权限收紧、停止和维护取消在等待队列之后仍会重新检查。

知识写入仍在队列等待时被停止、收紧权限或因版本冲突拒绝，外部回执记录本次未执行；已经开始的存储写入无法确认时仍保留结果未知，不能仅因停止而改写为失败或成功。

用户编辑器直接提交用户选定的变更，但同样核对打开时的目标版本。其他会话或设置页已经修改过目标时保留当前数据并报告冲突，不覆盖编辑器中的草稿。搜索、筛选与记录处于同一滚动区域，新增与说明入口跟随搜索行；放大字号时筛选上下排列。打开编辑器再返回保留搜索及筛选，不改变原有路由和来源失效规则。Agent 不可填写授权字段，自定义正文也不授予权限。

技能列表可按原版内置、自定义、本机修改的内置技能筛选，并分别查看启用、停用或缺少必需工具的记录。启停和工具可用性独立显示：已启用的技能仍可能缺工具，停用不再混称为不可用。记忆列表可按启停筛选；没有摘要时从已加载正文生成最多 160 个字素、最多两行的预览，折叠空白只影响显示，不修改正文或扩大工具读取预算。筛选无结果与尚未保存内容分别提示。

主库的外部操作账本和成功效果回执只保存引用、摘要及内容摘要值；完整预览与有条件逆操作由知识仓储拥有。`knowledge.undo.prepare` 准备一次新的逆操作，再按当前模式提交；任一目标已经修改时整次逆操作拒绝。撤销创建、更新及删除均不通过旧的全库快照回滚。逆操作保留窗口之外不承诺撤销。

## 持久化、删除与恢复

原生使用应用支持目录中的两个 `Sked_agent_knowledge.*.json` 槽；Web 使用 `sked.agent.knowledge.v1.*` 两个本机键。每次保存校验并读回两个槽，正文和操作回执一起保存。读取同时核对保留回执数量、目标、版本顺序、连续的前后内容及最终记录；保留窗口中的新增或删除版本必须有对应回执，错误的逆操作材料不能随快照读入。失败或结果未知时阻止继续写入，重新读取实际存储后再继续。损坏内容不解释为空库，较新格式阻止旧实现覆盖。

知识格式 v2 为历史整段撤销保存有界的已预检逆操作，并区分内容版本与存储版本；只保存准备记录时也会推进存储版本。v1 内容与单次逆操作仍可读取。整段撤销先占用知识写入边界，排空已经接受的保存、拒绝尚未接受的编辑，再预检全部原操作；任一冲突均不开始逆写。未知保存须读取实际存储并核对原批次，重试不重复撤销。已完成准备记录随其完成回执到期而清除，不能占满未完成批次的额度。

成功删除从生效记录中移除内容，并在两个槽中保存终止版本。迟到写入和重复旧请求不能复活记录；明确的条件撤销或所选备份恢复可以重新建立记录。为支持撤销，本机有界操作历史可能暂时保留被删除内容；源聊天和既有导出文件由各自的保留规则管理。

知识仓储上限为 8 MiB、512 条生效记录、128 条操作历史和 4096 条删除身份。单项技能正文最多 24 KiB，单项记忆正文最多 8 KiB。超限明确拒绝，不能截断后宣称完整保存。

知识服务提供按所选生效记录导出和准备恢复的接口，不导出执行权限或主库操作账本。导出内置技能时携带可重现的生效正文和原版摘要；接收端原版不同则准备为覆盖，未安装的原版不能被导入内容冒充为应用资源。未选择的知识记录保留，业务引用的有效性在恢复后重新判断。正式[选择性备份](SELECTIVE_BACKUP.md)界面与 Agent 工具使用同一接口，在跨仓储维护边界中固定知识目标、记录阶段并读回核验；与历史撤销共用排他规则。

应用宿主将知识仓储纳入停止写入、排空、恢复与清空生命周期。清空失败后需要读取实际侧存储，旧内存不能自动重建已删除文件。文件存储、浏览器替身、组件交互与真实平台验收分别记录；确定性测试不替代模型自主维护记忆的任务质量验证。

## 验证入口

- [仓储与双槽恢复](../test/agent/knowledge/knowledge_repository_test.dart)：重启、删除、幂等、逆操作冲突、未知写入和停止队列。
- [历史存储边界](../test/agent/knowledge/knowledge_history_storage_test.dart)：回执到期清理与排空失败后重新加载；[整段知识逆操作](../test/agent/history/knowledge_history_undo_test.dart)验证重复编辑、净删除、冲突及跨重启幂等。
- [选择恢复的知识参与方](../test/agent/knowledge/knowledge_selective_restore_test.dart)：保留未选对象、较大选集单次侧库保存、拒绝过期目标与失效所有权，以及未知写入后读取实际结果。
- [技能与记忆服务](../test/agent/knowledge/knowledge_service_test.dart)：原版覆盖、启停独立、运行快照、自定义发现及旧引用。
- [运行中的技能版本](../test/agent/knowledge/knowledge_scope_snapshot_test.dart)：首次宿主动作按需读取知识，当前范围固定版本，后续范围读取已修改内容。
- [真实工具宿主](../test/agent/tools/knowledge_tool_adapters_test.dart)：三种权限、完整审批、回执不含正文、Skill 依赖字段与原版覆盖／启停／恢复，以及缺失记录、旧版本和失效逆操作的错误与无写入结果。
- [设置列表与编辑器](../test/agent/ui/agent_knowledge_view_test.dart)：来源与启停／工具状态筛选、编辑往返后的搜索筛选保留、有界记忆正文预览与完整原文、持久修改、撤销、保留冲突草稿及大字号入口。
- [应用生命周期](../test/agent/knowledge/knowledge_lifecycle_test.dart)：默认开启时按需读取、维护排空、清空成功及失败后的实际存储恢复。
