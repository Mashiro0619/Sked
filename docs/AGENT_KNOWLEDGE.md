# Agent 共享技能与长期记忆

所有会话共享 Rust 拥有的知识库。设置编辑器与 Agent 工具使用同一版本校验、来源规范和持久化入口；Dart 页面保留只读投影与编辑草稿，业务对象和凭据仍由原有应用宿主保存。

## 内容与生效版本

内置 Skill 来自应用资源包。编辑内置 Skill 建立本机覆盖，恢复原版保留启停选择；应用升级后保留用户覆盖并显示原版变化。自定义 Skill 可以创建、修改、停用和删除。正文提供任务指导，不能安装执行代码或改变权限。

运行中的技能使用固定版本快照。查询与普通业务工具不等待 Dart 知识编辑器投影加载；需要使用某项 Skill 时才向模型提供其正文和实际依赖工具。技能数量、正文长度、记忆长度与累计装载量没有固定额度。

长期记忆保存稳定偏好、来源说明和结构化资源引用。旧数据世代、过期或未验证的引用需要重新核对；业务操作仍读取实际对象。删除聊天不自动删除共享记忆。

## 修改与撤销

一次知识业务工具调用包含完整预览、权限决定、保存与回执。计划模式只返回预览，确认模式等待当前决定，完全权限直接执行。操作身份由宿主生成。

编辑器提交用户选择的修改与预期版本，Rust 生成操作身份、记录变更和真实回执；冲突时保留草稿并说明实际变化。保存成功先投影回执，再刷新列表，刷新失败不会把已经提交的操作显示为保存失败。列表筛选、折叠正文和短预览只影响显示，完整内容保存在知识库中。内置 Skill 的正文视图与完整源文本视图保留原有换行、前缀和独立字段。

知识回执记录原值、目标值、版本和实际操作身份；普通聊天回执使用引用及摘要。条件撤销基于目标的连续版本，任一冲突拒绝整个逆操作。整段历史撤销先固定完整范围，连续修改合并为一次净变更，已经保存的逆操作不会重复执行。

知识已经提交但聊天结果写入失败时，界面保留所请求的变更并显示待核对。恢复从知识库读取原操作回执，补回原工具消息、版本和轮次归属；同一知识修改不会再次提交。

## SQLite 持久化

知识记录、回执、删除版本和历史撤销票据在 Rust 管理的 `knowledge.sqlite` 中分别按行保存。知识修改增加内容版本；准备票据等元数据修改增加存储版本。保存结果由数据库事务确认；编辑器按单条期望变更提交，列表查询只取得生效记录和版本，不以整份档案覆盖知识库。

回执、删除身份和准备票据没有固定数量淘汰。记录和正文没有人为容量拒绝。删除内容从生效记录中移除，支持撤销所需的原值仍保留在操作历史中；清空 Agent 数据同时清除这些记录。

知识使用 Rust 新格式归档参与明确的备份和恢复。未发布的旧 Agent 知识档案直接重建，应用内置 Skills 从资源包装载。课表、日程、连接、凭据与设置由其原有拥有者保存。

恢复使用固定目标。SQLite 把知识变更、存储版本和恢复摘要一起提交，跨库协调器读取版本与恢复标记确认结果；中断后按原目标继续。未知保存先读取实际存储，不能从内存猜测结果。

## 备份与生命周期

选择性备份导出所选生效正文、启停状态及原版来源，不包含执行许可或本机操作回执。接收端原版不同的内置 Skill 作为本机覆盖处理；未安装的原版不能被资料冒充。未选内容保留。

应用维护先排空已接纳写入，再冻结知识拥有者；清空失败后重新读取实际存储。知识修改与历史撤销遵守同一拥有者和维护边界。
