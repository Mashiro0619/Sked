# Agent 结果交付

Agent 使用工具的真实结果展示文件、来源和业务变化。文件和来源直接出现在操作记录下方；代码、参数与完整回执放在可展开的技术详情中。

## 文件

文件保存成功后显示实际保存位置。Python 与 Office 显示已经登记、并取得文件版本的产物；保存失败时可显示原回执保留的恢复文件。

点击文件名可以打开文件，文件菜单提供当前平台支持的动作：

- Windows：使用默认应用打开、在资源管理器定位、复制路径。
- Android 普通路径：打开查看副本，复制的仍是原文件位置。
- Android 文档 URI：使用原 URI 打开，向查看应用授予临时读取权限；也可复制该位置。

恢复文件按原名称生成查看副本，便于系统选择对应的文档应用；显示、复制和定位仍使用恢复原件的位置。

文件已经移走、权限失效或没有对应应用时，当前动作会显示失败，原保存记录继续保留。导入聊天中的原文件位置只供查看和复制，避免同名路径指向本机另一份文件；导入后新执行产生的文件可正常打开和定位。其他平台的文件位置也只供查看和复制。

脚本失败或用户停止后，已登记文件仍可显示。取消的操作显示“已取消”；原回执明确未启动时显示“未开始”。文件列表保留整次操作的失败、取消或待核对状态。执行预览只描述拟执行内容，不生成可打开的文件结果。

## 来源与业务对象

网页结果显示实际访问地址，发生重定向时同时保留原始地址。网站声明的日期与本次获取时间分别显示；“打开来源”访问该网页。

课表、课程、日程等业务变化继续按原回执展示，已保存的对象可从查看按钮进入。拟创建对象、未确认变化及已删除对象不提供误导的打开入口。业务撤销沿用原操作记录。

## 历史与数据

交付视图从原工具结果重建，切换会话、重新打开和恢复聊天后使用同一份回执。文件名、位置和链接来自已知工具字段，模型回复里的任意路径不会自动变成系统文件动作。

聊天备份保存交付记录。通过[持久内容](AGENT_CONTENT.md)导入会话的正文与附件按聊天备份规则携带；外部位置的文件需要另行保留。恢复聊天不会重新运行脚本或重复保存业务对象。

会话、数据或界面贡献变更后，旧按钮和菜单停止接收新动作。界面失活时，交付内容同时退出键盘焦点、指针和无障碍交互。已经开始的系统打开继续针对点击时的文件，迟到反馈不会写到另一份结果上。
