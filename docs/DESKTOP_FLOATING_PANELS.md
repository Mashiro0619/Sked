# 桌面浮层行为与验收

本页维护桌面浮层的行为契约、回归入口与验收方法。历史测试计数、截图和执行结果从 Git 历史追溯；每次候选版本的实际结果按[发布验收](RELEASE_ACCEPTANCE.md)另行记录。

尺寸规则以本页「统一拖拽调整大小」为准，编辑器内容和标题样式分别见对应章节。Windows 引擎中的测试指针与系统级鼠标验收分别记录。

采集脚本归并到[统一场景入口](../integration_test/README.md)。下文源码路径指对应场景模块，重跑使用 `capture_scenarios_test.dart` 并选择 `SKED_CAPTURE_SCENE`；细分组参数继续保留。

以下命令默认将截图写入唯一系统临时目录，日志通过 `SKED_CAPTURE_OUTPUT` 报告绝对路径；需要汇总时显式传入绝对 `SKED_VISUAL_OUTPUT`。测试使用隔离数据；组件指针和截图不能代替原生鼠标、Android 真机或其他平台的实际验收。

## 统一拖拽调整大小

桌面工作区域使用共用分隔条；独立内容浮窗提供四边及四角缩放。日期、时间、颜色等小型选择器、悬停预览和触屏底部任务继续按内容及平台布局。

| 区域 | 可调整边界 |
| --- | --- |
| 资源侧栏及其窄窗抽屉、设置分类、节次时间表集合、学校站点列表 | 与正文相邻的分隔边 |
| 月视图右侧安排、主题预览、导入结果预览 | 左右分栏边界 |
| 月视图底部安排、日／周视图全天日程区 | 上下分界 |
| 贴边详情、编辑器与助手 | 内侧分隔边 |
| 浮动详情、编辑器、提醒／日程列表、分类管理及名称表单 | 四边调整单轴，四角调整宽高 |

- `SkedResizeHandle` 和 `SkedResizableFrame` 共用鼠标命中、方向光标、键盘方向键及辅助技术增减；双击边界或聚焦边界后按 Home 恢复当前呈现方式的默认尺寸。角落优先命中，边界归入输入点击区域，调整不清除表单焦点。
- 每次增量从实际显示矩形计算，固定对边／对角；到达最小尺寸或安全边界后，反向立即响应。浮窗可扩展至可用工作区，不再受原 680×720 dp 上限限制。停靠编辑器沿用其阅读宽度预算。
- 默认打开仍使用原先宽度及内容自然高度。用户调整高度后，标题／操作区固定，正文填满剩余视口并滚动；分类列表不再被默认 400 dp 内容预算阻止扩高。每个打开任务保留自己的 Navigator、焦点、草稿与滚动状态。
- 资源栏的折叠状态独立于宽度，抽屉和展开侧栏共用首选宽度。自动收缩只改变当前显示尺寸；重新有空间时恢复偏好，不能因为偏好过宽而直接关闭分栏。
- 全天区手动扩高后显示全部日程的可滚动内容，拖高立即露出更多行；折叠保留高度。月视图底部安排先为完整月份保留最低高度，再约束安排区域。
- `DesktopLayoutPreferences` 用 `sked.desktop.layout.v1` 保存本机偏好，不进入 AppData 或业务备份。按区域／面板用途保存，具体课程和日程 ID 不作为键；浮动宽高与停靠宽度分别保存。关闭重开保留尺寸，位置重新靠近入口。
- 拖动中仅更新当前实例，松开提交；键盘每步提交内存，磁盘写入合并处理。窗口、输入法和字号变化不回写偏好。保存失败保留当前布局并提供重试，退出前尝试刷新；清除数据先停止布局写入，防止旧尺寸在清除后复活。

回归入口包括 `sked_resizable_test.dart`、`desktop_workspace_resize_test.dart`、`desktop_region_resize_test.dart`、`desktop_layout_preferences_test.dart` 和 `desktop_layout_lifecycle_test.dart`，覆盖鼠标实际边界、RTL、方向光标、重置、草稿／焦点、尺寸重载及保存／清除竞态。工作区几何、独立详情、分类管理和移动布局回归继续保留。

Windows 实际字体验收入口为 `integration_test/capture_scenarios/desktop_resize.dart`，使用内存样例数据和 Flutter 测试鼠标事件，记录截图及几何；系统级鼠标验收须另行执行。

## 桌面分类管理：入口旁透明模态

桌面分类管理不再整页跳转，也不属于提醒／当天安排的独立查看窗。日历保持可见，管理面板以及名称、颜色子任务仍为**透明模态**：点击外部只关闭最上层空闲任务，不能操作背景；保存和子任务期间父面板不退出。手机／触控平板继续使用原分类页面及原名称／危险确认 UI。

- 资源栏分类入口优先右侧、顶栏与溢出入口优先下方，使用仍存在的按钮作为锚点。共享四方向邻接算法，6 dp 间距、至少 8 dp 安全边界，避开标题栏和输入法；有效锚点不无故居中。首次拖动后脱离锚点，缩放仅约束位置；关闭重开重新靠近入口。
- 面板首选 440 dp，大字号最多 520 dp。紧凑标题包含分类数量、带文字的新建按钮和关闭按钮；大字号新建换至标题下方，标题文字／空白可拖、按钮不可拖。正文由内容决定高度，约 400 dp 上限后滚动；名称最多两行，不缩小字号。每行集中颜色、名称、既有口径的日程数量、显示／隐藏图标按钮和更多菜单，隐藏项明确显示「已隐藏」。名称点击重命名；更多仅保留重命名／删除，删除仍经危险确认。
- 资源栏「＋」直接打开名称表单，不先打开管理面板；管理面板内的新建才是子任务。名称保留空值、未修改和放弃草稿守卫。管理面板无总保存：可见性即时保存且失败回滚，名称／颜色分别确认后保存。
- 颜色面板首选 340 dp，复用选择器宿主和从主题设置提取的 `SkedCompactColorPicker`：单预览、六个既有主题槽、HSV 连续色区、色相和 Hex。原主题设置与触控布局保留。主题槽以原整数保存，打开、取消和未改动确认不会固化为当前 RGB；非法 Hex 就地提示且禁止提交，选择槽可修正非法草稿。
- `updateGeneralScheduleColor(id, value)` 从当前数据查找目标，仅更新颜色，保留后来更新的名称、事件、可见性和顺序；缺失 ID 不创建分类。所有任务捕获数据会话、工作区和目标 ID，失效即撤销自己拥有的路由，不能误关新任务或提交到替换数据。名称的嵌套放弃确认跟随名称任务失效，保存失败保留草稿和拖动位置。
- 空闲时 ×、Esc、外部点击关闭管理面板并恢复有效入口焦点；从紧凑资源栏进入也必须立即支持 Esc。父子路由各自拥有关闭权；工作区生命周期与任务守卫同时失效时，已移除的路由不能再次移除。
- 导入／导出作为底部次要文字操作。先关闭管理面板，等待退出动画完成，再从仍有效的工作区上下文打开原传输页面；返回不自动重开。保留备份、JSON／ICS、最后分类删除的原有业务语义，不新增设置或迁移。

### 验证入口

专项测试为 `test/widgets/category_manager_panel_test.dart`、`test/widgets/category_manager_dialog_test.dart`、`test/controllers/general_category_color_test.dart` 及服务测试，覆盖锚点、拖动重开、焦点、透明屏障、失败重试、原始色槽、外部字段更新、删除／替换／工作区失效与手机分支。

Windows 实际字体场景位于 `integration_test/capture_scenarios/category_panels.dart`，覆盖中英文、浅／深／自定义主题、RTL、1×／1.5×／2×、长名称、多分类及窄矮窗。Android 几何／安全区／输入法模拟不能视为 Android 实机验收。

### 分类列表保存反馈

- 显隐保存不显示横向进度条，也不预留进度条空白。保留保存期间禁用、退出守卫、重复提交保护和失败回滚／反馈。这里只移除桌面管理列表的进度提示，手机页面及名称／颜色／危险确认子任务保持原规则。

### 分类列表显隐按钮

- 桌面分类列表不再使用大块 Switch，改为中性色的眼睛／划线眼睛图标，不添加常驻胶囊背景。标准点击区域 36 dp，大字号适当增大；悬停提示说明显示／隐藏操作，辅助技术保留开关状态与按钮操作，隐藏分类仍显示「已隐藏」文字。手机控件保持不变。

### 分类管理审查修复

- 删除确认持有独立的工作区退出守卫。保存中拒绝停用工作区和替换数据，而不是把这些操作排在删除写入后；删除失败仍保留分类、确认框和重试入口，不能由后续工作区写入固化失败的删除快照。
- 管理／直接新建的每次打开都持有可失效的会话通知，名称、颜色、删除和嵌套放弃确认共享该会话。父工作区隐藏、不可交互或销毁会主动撤销本次自有路由，不等待 Provider 数据通知；重新激活不会复活旧任务，旧异步保存完成不能关闭新面板或无关根级弹窗。
- 大字号换行的新建按钮按标题实际高度优先布局，压缩正文前先为标题操作预留空间；保留底部操作与最小正文视口。700×320、2× 字号的新建／关闭／导入导出均可直接点击，更窄矮窗口的标题区允许滚动访问操作，拖动仍只响应标题文字与空白。手机原页面不变。
- 回归覆盖删除成功／失败期间的退出和替换保护（Windows 与 Android 分支）、无数据通知的父工作区失效、所有子任务和嵌套确认清理、无关弹窗保留、旧保存完成与重新打开，以及双语 RTL 矮窗口。Windows 字体矩阵中的 `short-header` 场景核对矮窗标题操作。

## 桌面任务选择器

桌面任务选择器共享四方向邻接定位与标题拖拽；普通原生菜单和手机端沿用各自规则。右侧课程字段优先左侧展开；无法容纳时优先邻接限高／夹紧，不无故跳至屏幕中央。

星期改为紧凑七单元、课程周次改为数字网格与奇偶快捷操作、关联节次显示起止时间、课表和节次方案使用紧凑清单。时间改为输入优先，输入和滚轮互斥但共享草稿；颜色使用单预览、色板、颜色区和 Hex 输入，移除嵌套卡片。分类短表单上限收紧至 360 dp。

## 当天安排复用悬停预览与独立详情

桌面「当天安排」浮窗、固定安排栏以及月视图安排列表的日程项复用提醒详情的交互。固定栏保持自身布局，当天安排没有启动自动弹出／倒计时。日历格、普通日程列表、手机／触控平板仍沿用原详情入口。

- 鼠标停留 300 ms 在日程项旁显示无 X、不可拖动的临时详情；入口、间隙和详情构成连续区域，离开 200 ms 后收起，预览不抢焦点。点击日程项、键盘激活或「独立显示」原地转为带 X、标题可拖动的独立详情。
- 独立详情不随空白点击或当天安排关闭而消失。当天安排换日、浮动／固定布局切换只影响临时预览；已独立的详情保持原事件、位置、正文限高与滚动，除非事件／数据／工作区失效。Esc 按焦点归属处理，编辑和删除继续经过原有保护。
- 提醒与当天安排由工作区的同一个 `_EventListDetailsHost` 持有一份详情。源文件为 `lib/screens/general_event_list_details_host.dart`，复用 `ReminderDetailSessionController`。各列表绑定自己的视口、行锚点、滚动和悬停状态；不能由最后构建的列表覆盖当前锚点。
- 多列表同时存在时，预览满延迟后才切换来源；进入旧详情取消待切换。点击另一列表中的同一实例只聚焦现有独立详情，保留元素和滚动，点击其他实例才切换内容；同名重复实例按实际实例键区分。
- 当前来源滚动、锚点移出可视区、固定栏被隐藏或源列表销毁会收起临时预览。其他列表滚动不关闭它。Offstage 的固定栏不参与锚定；关闭／重开期间每个列表仍独占 GlobalKey，避免路由动画间重用元素。
- 成功／失败、在途删除、旧快照重解析、编辑器冲突和原生子确认使用同一份保护，不另建详情路由。提醒启动倒计时仅联动实际提醒来源，不受当天安排的构建或悬停误干扰。

专项回归：`test/widgets/day_agenda_details_test.dart`；Windows 实际字体验收：`integration_test/capture_scenarios/day_agenda.dart`，覆盖浮动／固定入口、中英文、浅深色、1×／1.5×／2×、RTL、源列表关闭／换日及窄窗。

### 多来源生命周期

- 提醒启动计时器只由当前实际激活来源关联。悬停提醒后，即使关闭了预览，旧来源也不能因用户随后点击当天安排而被永久取消计时。
- 当前入口键与详情内容会话键分开记录。跨列表点击同一实例继续保留元素与滚动，但返回焦点改为最新入口；详情内的编辑／删除等操作不会把有效返回焦点覆盖成面板内部按钮。删除确认取消或保存失败后再关闭，仍返回最后激活的行。
- 安排列表显式携带所选日期作为上下文。日期变化时，即使跨多天日程仍保留相同行键，也要按来源撤销已显示的预览和待打开计时器；静止鼠标不会原地重开，重新移动／进入才能预览。独立详情不受切日影响，另一列表的候选打开／退出计时也不重置。
- 回归覆盖启动提醒计时隔离、双向跨列表同实例切换后关闭／删除取消／失败、固定和浮动安排的跨日等待／预览／独立状态，以及状态机的跨来源计时隔离。

## 提醒详情：悬停预览与独立显示

桌面提醒与当天安排共享临时预览和独立详情：预览没有关闭按钮；独立详情通过「独立显示」进入，不随外部点击或源列表销毁关闭。普通日历详情、手机／触控平板、菜单和选择器继续使用各自入口。

- 三态为 hidden／preview／independent。实际鼠标停留 300 ms 显示预览，离开入口、狭窄连接通道和详情整体区域 200 ms 收起；进入详情取消待关闭及待切换。预览不抢焦点、不提供 X、不允许标题拖动。列表滚动、锚点不可见、失焦、列表关闭或工作区隐藏时收起临时预览。
- 点击提醒行、键盘／无障碍激活或「独立显示 / Open independently」原地转为独立详情，保留同一事件的元素和滚动状态。独立详情显示 X、标题可拖；鼠标移出和悬停其他行不影响它。
- 独立详情没有背景输入屏障。点击空白不关闭它，提醒列表及日历各按原本规则响应；列表的 X、Esc、画布关闭及路由销毁都不带走独立详情。日程的外部关闭设置仍约束普通日历详情，但不适用于这个明确独立的窗口。关闭或重开提醒列表不改变详情的位置、内容或滚动，也不再生成副本。
- 每个工作区保留一份提醒详情。点击同一提醒仅聚焦，点击另一提醒显式切换内容并清理旧滚动和错误反馈。独立后位置不再跟随入口，即使尚未拖动也不跳回提醒行；缩放只重新约束可见位置。详情关闭重开时重新靠近入口。
- Esc 依据焦点归属：根级子确认先处理，详情获得焦点时只关闭详情，提醒列表获得焦点时只关闭列表。详情关闭后只在它持有焦点时恢复有效入口；入口已经销毁时回到工作区，不抢占新任务。临时预览自动消失不改焦点。
- 预览中的编辑／处理／复制／删除操作先转为独立状态，再执行原操作。详情忙碌或子确认打开时禁止切换、关闭及重复提交；失败与删除确认取消保留独立状态。独立不意味着绕过写入保护。成功仍按既有业务流程关闭自己、刷新提醒；编辑使用原完整编辑任务。
- 详情／通道悬停暂停启动列表倒计时，主动独立显示或操作取消本次自动收起。列表可以随后主动关闭，而独立详情继续存在。
- 工作区（不是提醒列表）持有 `ReminderDetailSessionController` 和根 `OverlayPortal`；列表只绑定入口、可见区域和启动计时器。复用共享表面、四方向邻接定位与 `WorkspaceViewPanel`，初始 6 dp 间距、至少 8 dp 安全边界。布局／标题改变不迁移内容。Tooltip 使用完整视口的局部 Overlay，空白区域不命中输入。
- 优先退出处理只接管临时预览；独立详情不在提醒列表的退出链上。异步回调检查事件、会话版本、数据会话和工作区有效性，使用自己的关闭回调而非盲目 Navigator.pop。事件删除、数据替换、工作区失效会撤销独立详情和计时器；根级确认正常位于其上方。

验证入口：`reminder_detail_session_controller_test.dart`、`reminder_hover_details_test.dart`、`reminder_companion_details_test.dart`。Windows 实际字体及原生输入入口为 `integration_test/capture_scenarios/reminder_hover.dart`。原生脚本逐条检查测试 PID、前台、命中窗口和按键占用，不绕过保护。

### 审查修复：独立生命周期的数据与布局安全

## 提醒汇总面板与启动预览

本节针对查看类的「应用内提醒」汇总，不是编辑器的提醒选项选择器，也不改变系统通知投递。

- 使用明确的分组阅读顺序：**进行中 → 即将开始 → 已结束**；组内分别按结束时间升序、开始时间升序、结束时间降序。相同时间按标题与稳定 occurrence key 兜底，不依赖存储顺序或 enum 顺序。
- 「已结束」只表示日程的结束时间已过，不代表未完成任务，不使用红色警告。标题使用主要文字和适度加粗；进行中用可读主题强调色，即将开始用主题第三色，已结束与日期时间使用次级文字。分组标题带图标及数量，不只靠颜色区分。暗色和自定义种子下用共享可读强调色，避免精确用户种子导致低对比度。
- 全天项显示日期与「全天」，不再显示 00:00；定时项显示本地起止时间，跨日项显示两端日期，保持已有 12／24 小时偏好。行点击与显式标记已处理的行为不变，失败留在列表，成功后重新分组计数。
- 启动后首次桌面日程工作区可交互时，有未处理提醒才展示一次查看浮层，10 秒后自动收起。启动时的非活动工作区、空列表、触控端或繁忙／有其他路由的场景跳过本次，不延迟到切换工作区后再弹出，也不会强制切换工作区。一次性状态属于应用壳会话，不写入设置、备份或提醒 acknowledgement。
- 悬停暂停剩余计时，移出后续计；拖动、按下、滚动或键盘操作取消本次自动收起，窗口后台时暂停。自动关闭只能作用于它自己的仍为当前任务的路由，不能关闭新的编辑器、确认框或其他任务。
- 手动打开不计时；自动预览显示期间点击提醒入口，退出旧预览后转为不计时的手动列表，不能叠出两个面板。关闭、自动收起均不等于「已处理」，不会清空铃铛计数。

## 任务行为统一

- 主题种子色、普通颜色值和课程文字颜色保存完成后仅完成自己拥有的路由，不关闭后来打开的其他根级任务；失败保留原任务并支持重试。对应回归：`theme_task_safety_test.dart`。
- 所有颜色编辑入口统一使用 `colorHexInvalid` 和有效性门禁：Hex 接受六位 RGB、可选单个前导 # 与首尾空白；禁止将超长输入截成有效值。非法输入不得提交，重新选色可修正；分类主题槽的原始值保持不变。
- 主题颜色任务捕获实际工作区与数据会话，分类目标额外按 ID 校验。保存中拒绝工作区停用和数据替换；父页面销毁、目标删除和数据替换后撤销自己的任务并拒绝旧回调。
- 节次方案创建和异步分配写入期间同样拒绝停用／替换；写入结束进入子编辑后仍由编辑器自己的草稿守卫决定退出。选择器完成时只关闭自己的路由，失效结果不再进入子编辑。
- 分类任务已迁移到 `SkedTaskSession`／`SkedTaskSessionScope`／`SkedTaskRouteGuard`：会话只管理数据、父任务和目标有效性，失效不可逆；用户退出仍由原草稿／忙碌守卫决定，路由清理只处理自己的任务。
- 选择器共用任务会话及自有路由守卫；桌面与触控的自适应选择器都接收工作区和会话有效性。外部传入会话不由选择器销毁，每次打开的子会话在路由完成与焦点恢复之后释放；原动画和布局保持不变。
- 普通弹窗可显式接入共享会话，普通编辑任务沿用原 sheet／pane 宿主但统一有效性与清理；自有路由完成抽为 `completeSkedTaskRoute`，`completeEditorRoute` 保留兼容入口。调用方传入的父会话不由宿主销毁。
- 主题颜色提交改用 `SkedTaskSubmissionController`：防重入、保存期间退出保护、结果归属和 finally 释放由控制器统一处理；草稿、路由完成和是否显示进度仍由原任务决定，控制器不持有或销毁调用方会话。
- 分类名称、颜色、删除和显隐使用同一个状态内的提交门禁；节次方案创建／分配也改用共享控制器，进入子编辑后释放写入保护并保留子编辑草稿守卫。分类显隐仍不显示进度条，名称退出规则不变。
- 颜色编辑共用 `SkedColorDraft` 原始值、修改状态、有效性和输入重置版本；预览通过调用方解析，不能固化主题槽。主题／分类／描边复用同一 Hex 解析与格式化函数，布局和提交时机不变。

- 普通浮动表单、选择器和独立详情的手动位置共享 `SkedFloatingPositionController`。宿主仍提供实测尺寸、坐标和安全边界，独立详情升级后脱离入口的策略保持不变；每次打开独享位置状态，关闭重开重新定位。

### 编辑器打开时的窗口拖动

浮动编辑器只阻挡应用内容，不禁用原生窗口操作。窗口宿主持有每个可见编辑器的保护租约及原始顶栏拖动区登记，在内容路由之上、原生窗口按钮之下消费顶栏输入。只对原有空白拖动区执行窗口移动、双击最大化／还原和系统菜单，不转发到背景按钮。命中使用当前布局、裁剪和可见性，失效区域及关闭后的租约及时注销。浮窗标题只移动浮窗，保存／子选择器／放弃确认期间也可拖动应用窗口，业务关闭守卫不变。

## 点击入口定位

- 浮窗的可放置区域与入口的可见区域分别计算。侧栏按钮在窗口内即是有效锚点，课表新建／编辑贴近实际按钮，并受画布边缘约束。
- 查看面板接收显式入口矩形：课程详情、日程详情、重叠日程列表、全天折叠组、当天安排和提醒都按实际按钮或卡片定位。键盘及语义激活使用相同入口，不依赖历史指针位置。
- `SkedFloatingAnchor` 在打开时捕获矩形，统一处理全局坐标到宿主坐标的转换；入口移除后保留快照，窗口缩放时重新约束可见位置。菜单关闭后继续打开的编辑器与选择器使用交接时的固定矩形。
- 同一个工作区 Navigator 内的详情／议程进入下一项任务前，宿主自动冻结内部入口，避免隐藏按钮随着新面板移动而反复改变定位。外部常驻按钮仍可随窗口布局变化更新锚点。
- 查看面板拖动后保留本次会话的位置；调整宽度保持拖动面板的尾缘，正文内容和嵌套任务返回后的位置继续保留。

位置回归位于 `test/widgets/floating_panel_anchor_regression_test.dart` 和 `test/widgets/sked_floating_route_anchor_test.dart`，同时覆盖安全边界、来源移除、偏移／缩放宿主及交接后的稳定性。导入字段和导入流程在各自现有测试中补充入口定位断言。

Windows 截图入口为 `integration_test/capture_scenarios/floating_panel_anchors.dart`，按 `--dart-define=SKED_VISUAL_GROUP=student` 与 `--dart-define=SKED_VISUAL_GROUP=general` 分组执行。

## 三类编辑面板：紧凑与规整

本节记录课程、日程和课表桌面编辑器的当前内容样式。初版等宽铺满和全天独占一行的布局已修正为按字段用途取宽；新建／编辑、浮动／并排使用相同表单。移动端继续使用原有布局，业务接口和存储格式不变。

- 名称保留 22 sp 半粗主输入区。普通字段标签上置，使用 12 sp 次级文字；输入和选择值统一 14 sp、浅底细边框、6 dp 圆角。控件基准高度 40 dp，大字号及多行内容可自然增高。输入装饰显式使用标准视觉密度，避免桌面主题把实际高度压缩到 32 dp。
- 字段与列间距 12 dp、分组间距 16 dp；下拉箭头固定在控件尾端，RTL 按阅读方向镜像。“更多”保留轻量折叠入口，取消／保存固定在底部，正文独立滚动。
- 分别测量各字段的标签、选中值、图标及内边距，不再以最长字段作为所有列的最小宽度，也不等分剩余空间。短选择器保持自身宽度，只有显式配置的自由输入分配余量；不足时逐行排布，短控件仍不铺满。自由文本只测标签，打字不会引起表单换列。
- 控件起始宽度按用途设置，再结合实际字体和内容增宽：课程起止时间各 112 dp、星期 136 dp、周次及关联节次 176 dp；总周数／学分 96 dp，课表日期 160 dp、节次时间集 240 dp。日程分类／重复 144 dp、提醒 160 dp，日期 136 dp、时间 104 dp。大字号按 14 sp 处实际倍率增加起始宽度，长值可扩展和换行。
- 日程起止时间上下对齐。正常宽度下标签、日期、时间共处一行，全天紧跟开始时间；窄窗或大字号时改为上置标签，全天与开始标签同行，日期／时间下排或进一步堆叠。日期和时间控件不吸收额外空白。

| 面板 | 默认宽度 | 常用字段排列 |
| --- | --- | --- |
| 课程 | 440 dp | 名称突出；地点留足输入空间；星期／周次并排；开始／结束时间并排；关联节次另行、按内容取宽 |
| 日程 | 480 dp | 名称突出；地点／分类并排；起止时间上下对齐，全天融入开始行；重复／提醒并排 |
| 课表 | 360 dp | 名称突出；总周数／开学日期并排；节次时间集另行、按内容取宽 |

共用实现位于 `workspace_editor_form.dart`、`workspace_editor.dart` 和 `workspace_editor_time_rows.dart`。换列仅修改稳定子节点的约束和位置，日期时间的八个槽位及隐藏的时间控件继续保留；不会因调宽、全天切换或子选择器返回而重新创建输入、焦点或按钮锚点。调宽手柄纳入输入点击区域，拖动时保留焦点和选区。手动范围仍为 320–680 dp，浮动／并排切换保留手动宽度。初始宽度配置共用原锚点实例，嵌套入口的冻结快照继续保留宽度，编辑器重建不覆盖本次调宽结果。

## 课程详情间距与排版

课程桌面详情去掉地点、时间透明卡片中重复的 14 dp 内边距，保留清楚的文字层级和分组。主信息之间为 12 dp，主信息到属性为 16 dp；正文左右 16 dp，首项距离正文顶部 12 dp（含忙碌指示器保留的 4 dp）。地点和时间使用 20 dp 图标、12 sp 次级标签及 14 sp 正文，长地点完整换行。

教师、上课日、周次、学分、备注共用按当前字体及本地化测量的标签列，列间距 12 dp、行间距 8 dp；值列使用剩余全部宽度，备注不截断。窄窗／大字号下，值列不足 160 dp × 字号倍率时改为上置标签。自定义字段独立测量，长字段名不挤宽内置属性的标签列。

标题使用 18 sp 半粗文字，与统一尺寸的编辑／关闭按钮垂直居中；320 dp 窄面板仍保持三个元素同排。标题拖动区域的文字也居中，按钮继续位于拖动区域之外。`WorkspaceViewPanel` 通过可选的头部配置启用这些变化，其他查看面板继续使用原默认值。移动端布局、课程数据和冲突处理不变。

## 桌面面板标题统一

本节取代各面板此前分别继承 `titleSmall`、`titleMedium` 或手写 15 sp／500 的标题规则。桌面主题把若干文本角色压缩为 14 sp；仅改字重仍会带入不同的行高、字距和字形回退，因此标题由 `sked_panel_header.dart` 定义独立语义样式。

| 角色 | 字号／字重 | 用途 |
| --- | --- | --- |
| 操作或集合标题 | 16 sp／600 | 编辑课程、选择周次、日期时间、跳周、分类管理、提醒列表、更新等 |
| 详情对象名称 | 18 sp／600 | 课程或日程本身的名称；独立日期面板的月份导航主值 |
| 编辑正文主名称 | 22 sp／600 | 课程、日程及课表的名称输入 |
| 副标题 | 12 sp／400 | 日历分类、日期说明或任务说明 |

操作及对象标题行高 1.35，正文主名称 1.25，副标题 1.4；统一正常字形、0 字距及均匀行间留白。标题主字体沿用主题和用户设置，Windows 追加按语言选择的 CJK 回退：简体中文用 Microsoft YaHei UI，繁体用 Microsoft JhengHei UI，日文用 Yu Gothic UI，韩文用 Malgun Gothic，并保留调用方已有的字体回退优先级。测试记录请求的字体族与实际合成样式，不把这些信息误作逐字字体解析结果。

标题栏使用方向性边距：起端 16、末端 12、上下 8 dp，正常最小高度 48 dp。主标题与关闭／同排动作居中，标题拖动区内部同样居中；副标题独立放在标题动作行下方 4 dp，不能让关闭按钮对齐标题与副标题的整体中心。长标题、大字号和窄窗仍使用宿主的换行／滚动预算，不限制文字倍率。关闭按钮、动作和正文输入继续在标题拖动区域之外。
