# 桌面轻量浮层：推广与验收

日期：2026-09-30（第一版历史验收）。

## 桌面分类管理：入口旁透明模态（2026-10-02）

桌面分类管理不再整页跳转，也不属于提醒／当天安排的独立查看窗。日历保持可见，管理面板以及名称、颜色子任务仍为**透明模态**：点击外部只关闭最上层空闲任务，不能操作背景；保存和子任务期间父面板不退出。手机／触控平板继续使用原分类页面及原名称／危险确认 UI。

- 资源栏分类入口优先右侧、顶栏与溢出入口优先下方，使用仍存在的按钮作为锚点。共享四方向邻接算法，6 dp 间距、至少 8 dp 安全边界，避开标题栏和输入法；有效锚点不无故居中。首次拖动后脱离锚点，缩放仅约束位置；关闭重开重新靠近入口。
- 面板首选 440 dp，大字号最多 520 dp。紧凑标题包含分类数量、带文字的新建按钮和关闭按钮；大字号新建换至标题下方，标题文字／空白可拖、按钮不可拖。正文由内容决定高度，约 400 dp 上限后滚动；名称最多两行，不缩小字号。每行集中颜色、名称、既有口径的日程数量、显示开关和更多菜单，隐藏项明确显示「已隐藏」。名称点击重命名；更多仅保留重命名／删除，删除仍经危险确认。
- 资源栏「＋」直接打开名称表单，不先打开管理面板；管理面板内的新建才是子任务。名称保留空值、未修改和放弃草稿守卫。管理面板无总保存：可见性即时保存且失败回滚，名称／颜色分别确认后保存。
- 颜色面板首选 340 dp，复用选择器宿主和从主题设置提取的 `SkedCompactColorPicker`：单预览、六个既有主题槽、HSV 连续色区、色相和 Hex。原主题设置与触控布局保留。主题槽以原整数保存，打开、取消和未改动确认不会固化为当前 RGB；非法 Hex 就地提示且禁止提交，选择槽可修正非法草稿。
- `updateGeneralScheduleColor(id, value)` 从当前数据查找目标，仅更新颜色，保留后来更新的名称、事件、可见性和顺序；缺失 ID 不创建分类。所有任务捕获数据会话、工作区和目标 ID，失效即撤销自己拥有的路由，不能误关新任务或提交到替换数据。名称的嵌套放弃确认跟随名称任务失效，保存失败保留草稿和拖动位置。
- 空闲时 ×、Esc、外部点击关闭管理面板并恢复有效入口焦点；从紧凑资源栏进入也必须立即支持 Esc。父子路由各自拥有关闭权；工作区生命周期与任务守卫同时失效时，已移除的路由不能再次移除。
- 导入／导出作为底部次要文字操作。先关闭管理面板，等待退出动画完成，再从仍有效的工作区上下文打开原传输页面；返回不自动重开。保留备份、JSON／ICS、最后分类删除的原有业务语义，不新增设置或迁移。

## 第二版更新（2026-10-01）

第一版的“选择器不可拖动”和“上下不足直接居中”规则已废止。第二版桌面任务选择器共享四方向邻接定位与标题拖拽；普通原生菜单和手机端不变。右侧课程字段优先左侧展开；无法容纳时优先邻接限高／夹紧，不无故跳至屏幕中央。

星期改为紧凑七单元、课程周次改为数字网格与奇偶快捷操作、关联节次显示起止时间、课表和节次方案使用紧凑清单。时间改为输入优先，输入和滚轮互斥但共享草稿；颜色使用单预览、色板、颜色区和 Hex 输入，移除嵌套卡片。分类短表单上限收紧至 360 dp。

第二版相关回归 403 项通过；最后时间增减和限高复验 64 项、方向键与课程选择器复验 30 项通过。4 项 Windows 实际字体视觉测试通过，生成 117 张截图，并检查星期、周次、颜色、时间及大字号节次的代表性结果。第二版截图在 `.scratch/floating-v2/`。原生鼠标测试被前台焦点保护阻止，未绕过保护；第一版原生鼠标通过记录不能代替第二版原生验收。


## 当天安排复用悬停预览与独立详情（2026-10-02）

桌面「当天安排」浮窗、固定安排栏以及月视图安排列表的日程项复用提醒详情的交互；本节扩展了下文早期“仅提醒列表试点”的范围。不是把固定栏变成浮窗，也不为当天安排添加启动自动弹出／倒计时。日历格、普通日程列表、手机／触控平板仍沿用原详情入口。

- 鼠标停留 300 ms 在日程项旁显示无 X、不可拖动的临时详情；入口、间隙和详情构成连续区域，离开 200 ms 后收起，预览不抢焦点。点击日程项、键盘激活或「独立显示」原地转为带 X、标题可拖动的独立详情。
- 独立详情不随空白点击或当天安排关闭而消失。当天安排换日、浮动／固定布局切换只影响临时预览；已独立的详情保持原事件、位置、正文限高与滚动，除非事件／数据／工作区失效。Esc 按焦点归属处理，编辑和删除继续经过原有保护。
- 提醒与当天安排由工作区的同一个 `_EventListDetailsHost` 持有一份详情。源文件为 `lib/screens/general_event_list_details_host.dart`，复用 `ReminderDetailSessionController`。各列表绑定自己的视口、行锚点、滚动和悬停状态；不能由最后构建的列表覆盖当前锚点。
- 多列表同时存在时，预览满延迟后才切换来源；进入旧详情取消待切换。点击另一列表中的同一实例只聚焦现有独立详情，保留元素和滚动，点击其他实例才切换内容；同名重复实例按实际实例键区分。
- 当前来源滚动、锚点移出可视区、固定栏被隐藏或源列表销毁会收起临时预览。其他列表滚动不关闭它。Offstage 的固定栏不参与锚定；关闭／重开期间每个列表仍独占 GlobalKey，避免路由动画间重用元素。
- 成功／失败、在途删除、旧快照重解析、编辑器冲突和原生子确认使用同一份保护，不另建详情路由。提醒启动倒计时仅联动实际提醒来源，不受当天安排的构建或悬停误干扰。

专项回归：`test/widgets/day_agenda_details_test.dart`；Windows 实际字体验收：`integration_test/day_agenda_details_visual_test.dart`，截图输出 `.scratch/day-agenda-details-visual/`。包含浮动／固定入口、中英文、浅深色、1×／1.5×／2×、RTL、源列表关闭／换日及窄窗。本轮截图使用模拟指针，不宣称完成原生鼠标注入验收。

### 多来源审查修复（2026-10-02）

- 提醒启动计时器只由当前实际激活来源关联。悬停提醒后，即使关闭了预览，旧来源也不能因用户随后点击当天安排而被永久取消计时。
- 当前入口键与详情内容会话键分开记录。跨列表点击同一实例继续保留元素与滚动，但返回焦点改为最新入口；详情内的编辑／删除等操作不会把有效返回焦点覆盖成面板内部按钮。删除确认取消或保存失败后再关闭，仍返回最后激活的行。
- 安排列表显式携带所选日期作为上下文。日期变化时，即使跨多天日程仍保留相同行键，也要按来源撤销已显示的预览和待打开计时器；静止鼠标不会原地重开，重新移动／进入才能预览。独立详情不受切日影响，另一列表的候选打开／退出计时也不重置。
- 新增回归覆盖启动提醒计时隔离、双向跨列表同实例切换后关闭／删除取消／失败、固定和浮动安排的跨日等待／预览／独立状态，以及状态机的跨来源计时隔离。
- 修复验收：新增 17 项正式回归，相关测试合计 **490 项通过**；5 项隔离复现／对照场景均通过。全项目静态检查无问题、529 个 Dart 文件格式检查无变更，差异空白检查通过。Windows 实际字体视觉回归生成 **48 张截图**并通过，已复核切换日期后独立详情保留；本轮未执行原生鼠标注入，不将模拟指针截图算作原生验收。

## 提醒详情：悬停预览与独立显示（2026-10-02）

本节明确区分临时预览与真正独立的详情：**废止预览右上角关闭按钮、「展开详情」命名、独立详情的外部点击关闭屏障，以及详情随提醒列表销毁的旧约定**。只适用于桌面提醒入口，不改变普通日历详情、手机／触控平板、菜单和选择器。

- 三态为 hidden／preview／independent。实际鼠标停留 300 ms 显示预览，离开入口、狭窄连接通道和详情整体区域 200 ms 收起；进入详情取消待关闭及待切换。预览不抢焦点、不提供 X、不允许标题拖动。列表滚动、锚点不可见、失焦、列表关闭或工作区隐藏时收起临时预览。
- 点击提醒行、键盘／无障碍激活或「独立显示 / Open independently」原地转为独立详情，保留同一事件的元素和滚动状态。独立详情显示 X、标题可拖；鼠标移出和悬停其他行不影响它。
- 独立详情没有背景输入屏障。点击空白不关闭它，提醒列表及日历各按原本规则响应；列表的 X、Esc、画布关闭及路由销毁都不带走独立详情。日程的外部关闭设置仍约束普通日历详情，但不适用于这个明确独立的窗口。关闭或重开提醒列表不改变详情的位置、内容或滚动，也不再生成副本。
- 每个工作区保留一份提醒详情。点击同一提醒仅聚焦，点击另一提醒显式切换内容并清理旧滚动和错误反馈。独立后位置不再跟随入口，即使尚未拖动也不跳回提醒行；缩放只重新约束可见位置。详情关闭重开时重新靠近入口。
- Esc 依据焦点归属：根级子确认先处理，详情获得焦点时只关闭详情，提醒列表获得焦点时只关闭列表。详情关闭后只在它持有焦点时恢复有效入口；入口已经销毁时回到工作区，不抢占新任务。临时预览自动消失不改焦点。
- 预览中的编辑／处理／复制／删除操作先转为独立状态，再执行原操作。详情忙碌或子确认打开时禁止切换、关闭及重复提交；失败与删除确认取消保留独立状态。独立不意味着绕过写入保护。成功仍按既有业务流程关闭自己、刷新提醒；编辑使用原完整编辑任务。
- 详情／通道悬停暂停启动列表倒计时，主动独立显示或操作取消本次自动收起。列表可以随后主动关闭，而独立详情继续存在。
- 工作区（不是提醒列表）持有 `ReminderDetailSessionController` 和根 `OverlayPortal`；列表只绑定入口、可见区域和启动计时器。复用共享表面、四方向邻接定位与 `WorkspaceViewPanel`，初始 6 dp 间距、至少 8 dp 安全边界。布局／标题改变不迁移内容。Tooltip 使用完整视口的局部 Overlay，空白区域不命中输入。
- 优先退出处理只接管临时预览；独立详情不在提醒列表的退出链上。异步回调检查事件、会话版本、数据会话和工作区有效性，使用自己的关闭回调而非盲目 Navigator.pop。事件删除、数据替换、工作区失效会撤销独立详情和计时器；根级确认正常位于其上方。
- 不新增依赖、持久化偏好或备份格式；新增按钮接入简体、繁体、英文及现有回退本地化。

验证入口：`reminder_detail_session_controller_test.dart`、`reminder_hover_details_test.dart`、`reminder_companion_details_test.dart`。Windows 实际字体及原生输入入口为 `integration_test/reminder_hover_visual_test.dart`，本轮输出 `.scratch/reminder-independent-visual/`。原生脚本逐条检查测试 PID、前台、命中窗口和按键占用，不绕过保护。
