# 桌面轻量浮层：推广与验收

日期：2026-09-30（第一版历史验收）。

## 第二版更新（2026-10-01）

第一版的“选择器不可拖动”和“上下不足直接居中”规则已废止。第二版桌面任务选择器共享四方向邻接定位与标题拖拽；普通原生菜单和手机端不变。右侧课程字段优先左侧展开；无法容纳时优先邻接限高／夹紧，不无故跳至屏幕中央。

星期改为紧凑七单元、课程周次改为数字网格与奇偶快捷操作、关联节次显示起止时间、课表和节次方案使用紧凑清单。时间改为输入优先，输入和滚轮互斥但共享草稿；颜色使用单预览、色板、颜色区和 Hex 输入，移除嵌套卡片。分类短表单上限收紧至 360 dp。

第二版相关回归 403 项通过；最后时间增减和限高复验 64 项、方向键与课程选择器复验 30 项通过。4 项 Windows 实际字体视觉测试通过，生成 117 张截图，并检查星期、周次、颜色、时间及大字号节次的代表性结果。第二版截图在 `.scratch/floating-v2/`。原生鼠标测试被前台焦点保护阻止，未绕过保护；第一版原生鼠标通过记录不能代替第二版原生验收。


## 提醒详情：悬停预览与独立显示（2026-10-02）

本节明确区分临时预览与真正独立的详情：**废止预览右上角关闭按钮、「展开详情」命名、独立详情的外部点击关闭屏障，以及详情随提醒列表销毁的旧约定**。只适用于桌面提醒入口，不改变普通日历详情、手机／触控平板、菜单和选择器。

- 三态为 hidden／preview／independent。实际鼠标停留 300 ms 显示预览，离开入口、狭窄连接通道和详情整体区域 200 ms 收起；进入详情取消待关闭及待切换。预览不抢焦点、不提供 X、不允许标题拖动。列表滚动、锚点不可见、失焦、列表关闭或工作区隐藏时收起临时预览。
- 点击提醒行、键盘／无障碍激活或「独立显示 / Open independently」原地转为独立详情，保留同一事件的元素和滚动状态。独立详情显示 X、标题可拖；鼠标移出和悬停其他行不影响它。
- 独立详情没有背景输入屏障。点击空白不关闭它，提醒列表及日历各按原本规则响应；列表的 X、Esc、画布关闭及路由销毁都不带走独立详情。日程的外部关闭设置仍约束普通日历详情，但不适用于这个明确独立的窗口。关闭或重开提醒列表不改变详情的位置、内容或滚动，也不再生成副本。
- 每个工作区保留一份提醒详情。点击同一提醒仅聚焦，点击另一提醒显式切换内容并清理旧滚动和错误反馈。独立后位置不再跟随入口，即使尚未拖动也不跳回提醒行；缩放只重新约束可见位置。详情关闭重开时重新靠近入口。
- Esc 依据焦点归属：根级子确认先处理，详情获得焦点时只关闭详情，提醒列表获得焦点时只关闭列表。详情关闭后只在它持有焦点时恢复有效入口；入口已经销毁时回到工作区，不抢占新任务。临时预览自动消失不改焦点。
- 预览中的编辑／处理／复制／删除操作先转为独立状态，再执行原操作。详情忙碌或子确认打开时禁止切换、关闭及重复提交；失败与删除确认取消保留独立状态。独立不意味着绕过写入保护。成功仍按既有业务流程关闭自己、刷新提醒；编辑使用原完整编辑任务。
- 详情／通道悬停暂停启动列表倒计时，主动独立显示或操作取消本次自动收起。列表可以随后主动关闭，而独立详情继续存在。
- 工作区（不是提醒列表）持有 `ReminderDetailSessionController` 和根 `OverlayPortal`；列表只绑定入口、可见区域和启动计时器。复用共享表面、四方向邻接定位与 `WorkspaceViewPanel`，初始 6 dp 间距、至少 8 dp 安全边界。布局／标题改变不迁移内容。Tooltip 使用完整视口的局部 Overlay，空白区域不命中输入。
- 优先退出处理只接管临时预览；独立详情不在提醒列表的退出链上。异步回调检查事件、会话版本、数据会话和工作区有效性，使用自己的关闭回调而非盲目 Navigator.pop。事件删除、数据替换、工作区失效会撤销独立详情和计时器；根级确认正常位于其上方。
- 不新增依赖、持久化偏好或备份格式；新增按钮接入简体、繁体、英文及现有回退本地化。

验证入口：`reminder_detail_session_controller_test.dart`、`reminder_hover_details_test.dart`、`reminder_companion_details_test.dart`。Windows 实际字体及原生输入入口为 `integration_test/reminder_hover_visual_test.dart`，本轮输出 `.scratch/reminder-independent-visual/`。原生脚本逐条检查测试 PID、前台、命中窗口和按键占用，不绕过保护。

### 审查修复：独立生命周期的数据与布局安全（2026-10-02）

- 独立详情的数据不能由源列表行负责刷新：显示和操作前按日历、事件与实例起始时间重新解析当前实例。备注、地点、标题及重复例外使用最新值；实例被改期、排除或截断时关闭旧详情，不能仅因事件 ID 还存在就继续操作旧快照。确认框返回后删除／复制也重新解析，不覆盖其他入口已保存的修改。
- 自身删除的乐观数据变化不等于删除已提交：仅对当前会话在途删除暂缓实例消失清理，保持忙碌、面板位置和错误宿主。失败回滚后可原地重试，成功只关闭自己的会话；数据替换、工作区退出及失效仍立即清理，旧回调不能影响后续会话。
- 后台已有完整编辑器时，独立详情的编辑按钮禁用，执行时也检查接管条件，不能先关闭详情再被编辑器拒绝。原编辑器退出后可以重试；普通详情和触控端默认不受新增可选条件影响。
- 独立时保存本会话的正文限高，后续只按可用窗口限制；关闭列表、切换入口及源锚点消失不能改变它。内容仍自然收紧，大字号长备注保留位置与滚动，窗口缩小后恢复不重新吸附入口。

## 提醒汇总面板与启动预览（2026-10-01）

本节针对查看类的「应用内提醒」汇总，不是编辑器的提醒选项选择器，也不改变系统通知投递。

- 使用明确的分组阅读顺序：**进行中 → 即将开始 → 已结束**；组内分别按结束时间升序、开始时间升序、结束时间降序。相同时间按标题与稳定 occurrence key 兜底，不依赖存储顺序或 enum 顺序。
- 「已结束」只表示日程的结束时间已过，不代表未完成任务，不使用红色警告。标题使用主要文字和适度加粗；进行中用可读主题强调色，即将开始用主题第三色，已结束与日期时间使用次级文字。分组标题带图标及数量，不只靠颜色区分。暗色和自定义种子下用共享可读强调色，避免精确用户种子导致低对比度。
- 全天项显示日期与「全天」，不再显示 00:00；定时项显示本地起止时间，跨日项显示两端日期，保持已有 12／24 小时偏好。行点击与显式标记已处理的行为不变，失败留在列表，成功后重新分组计数。
- 启动后首次桌面日程工作区可交互时，有未处理提醒才展示一次查看浮层，10 秒后自动收起。启动时的非活动工作区、空列表、触控端或繁忙／有其他路由的场景跳过本次，不延迟到切换工作区后再弹出，也不会强制切换工作区。一次性状态属于应用壳会话，不写入设置、备份或提醒 acknowledgement。
- 悬停暂停剩余计时，移出后续计；拖动、按下、滚动或键盘操作取消本次自动收起，窗口后台时暂停。自动关闭只能作用于它自己的仍为当前任务的路由，不能关闭新的编辑器、确认框或其他任务。
- 手动打开不计时；自动预览显示期间点击提醒入口，退出旧预览后转为不计时的手动列表，不能叠出两个面板。关闭、自动收起均不等于「已处理」，不会清空铃铛计数。
- 实际字体截图入口：`integration_test/reminder_summary_visual_test.dart`；本地证据目录：`.scratch/reminder-summary-visual/`。截图覆盖中英文、浅／深色及 1×／1.5×／2× 字号与矮窗滚动。截图和组件指针测试不代表原生鼠标验收。
- 本轮相关回归 323 项通过，覆盖排序、启动／空列表／繁忙跳过、10 秒关闭、悬停与后台暂停、拖动／滚动／键盘接管、手动重开、显式处理失败重试、新路由保护、RTL、手机与编辑器。Windows 视觉测试通过并生成 14 张实际字体截图；检查暗色状态文字后修正对比度，并加入至少 4.5:1 的测试。全项目静态检查无问题，519 个 Dart 文件格式检查无变更，差异空白检查通过。

## 实现契约

共享表面与标题手柄位于 `lib/widgets/sked_floating_surface.dart`；桌面选择器适配器在 `lib/widgets/sked_adaptive_picker_dialog.dart`，复用 `showSkedPickerTask` 的会话和焦点处理。`SkedTaskDialog` 仅在宿主显式提供 scope 时渲染为紧凑内容，否则将可空样式参数原样交给 Material UI 的 AlertDialog，避免覆盖移动端库默认值。

`showExpressiveDialog` 新增默认关闭的 `desktopFloating` 选项，由 `SkedDesktopFloatingDialog` 提供稳定锚点、首选／最大宽度和标题拖拽开关。第一版短表单初始宽度 360 dp、大字号最多 440 dp；第二版分类名称表单上限收紧至 360 dp，并受可用窗口约束。二级选择器保留各自阅读宽度，通过换行和滚动适配大字号，不按字号扩大空白。

短表单首次拖动后不再跟随锚点，窗口变化重新约束可见位置；关闭重开恢复入口定位。默认普通弹窗不订阅新增的路由当前状态，避免嵌套编辑返回时重置 closure 内的选择状态。桌面任务的 builder 状态跨宿主布局变化保留，不重复提交或重置忙碌状态。
