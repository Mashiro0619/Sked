- 问答、计划、队列、压缩、历史编辑重做、知识、附件、标题、用量和备份已接入 Rust，正式装配已完成切换。

## 所有权与接口

Rust 拥有模型及工具循环、运行取消、会话与交互状态、上下文、知识、Agent 存储和结果投影。Dart 业务宿主拥有课表日程规则、领域校验、业务保存与回执、业务撤销、导入导出、通知、学校网页及设备动作。系统安全存储继续保管凭据。

桥接使用类型化的 `initialize`、`dispatch`、`query`、`watchEvents`、`submitHostResult`、`shutdown`。Flutter 用 `RustAgentUiDelegate` 连接现有界面。命令和事件覆盖已有行为，只有动态工具参数、schema 和服务协议材料使用 JSON。

每个活动会话保持一份执行对象；运行及连续队列收尾后释放执行全文。侧栏和运行订阅读取轻量状态，聊天页面按连续窗口读取消息，版本、来源和运行详情按需读取；离开页面释放正文并保留阅读位置。停止请求立即反馈，已接纳的业务保存完成后才开放继续。普通运行不设置 Token、模型轮数、工具次数或时限配额。

工具定义、参数和使用说明同源；发现状态随会话恢复。模型仍用一次业务工具调用完成一次操作。结果区分模型摘要与界面完整详情，参数错误指明字段。审批仅允许／拒绝，保留计划、确认和完全权限模式。

## 存储

| 内容 | 存储 |
| --- | --- |
| 消息、工具调用与结果、运行、队列、问答、摘要、历史版本及操作绑定 | 每会话一个追加式 JSONL |
| 会话列表、消息位置、分页和查询索引 | `conversation-index.sqlite`，可重建 |
| Skills、记忆、知识版本及撤销记录 | `knowledge.sqlite`，正式知识数据 |
| 图片与其他附件 | 私有文件，JSONL 保存引用 |

每个会话由 Rust 顺序写入，一次关联状态变化保存成一条完整记录。流式文字用于实时显示，完整消息结束后保存；草稿沿用原保存节奏。编辑、重做和重新生成追加版本记录。索引保存记录位置及完整计数、用量和管理检查摘要，不重复保存聊天全文；展示查询只解码请求的记录，跳过协议历史和未选择的旧版本。

Agent 备份只实现新布局的导入导出；业务备份仍由现有 Dart 实现负责。

## 正式装配与验证入口

正式入口为 `lib/main.dart`，由 `AppRuntime` 创建应用级 `AgentApplication`，通过 `AgentRustClient` 连接 Rust 核心。Windows、Android 启用该执行路径；其他平台保留普通应用功能，Agent 显示暂不可用。

`rust/src/api` 提供生成桥接，`AgentRustClient` 等待原生事件订阅就绪后开放命令。停止或退出先关闭新请求入口，宿主仍可提交已接纳保存的最终回执；重复退出调用等待同一收尾过程。

后续插件化已将默认装配迁入 `rust/src/api/default_profile.rs`，由 `rust/src/plugins` 管理服务租约与异步清理，公开 FRB 命令保持一致。该次改造的实施与验收状态单独记录在[插件架构计划](AGENT_PLUGIN_ARCHITECTURE.md)。

`RustAgentBusinessHost` 为每次运行持有业务作用域，复用 `ApplicationToolHost` 和 `MutationCoordinator`。准备记录持久化后才进入业务保存；待审批对象建立后才发布允许／拒绝入口。历史主库撤销通过 `RustAgentMainUndo` 读取原始回执并复用领域撤销入口。

原生模型客户端在发送前检查会话与工具参数中的当前连接凭据，并对流式正文、思考、工具结果和错误执行脱敏。流式输出保留可能属于凭据的尾部，避免分片泄露；短凭据按敏感字段和授权语法识别，保留普通正文。

原生请求体接口支持把私有附件分块编码到模型协议中，发送时核对字节长度和摘要，并响应取消。传输保留用户配置的完整地址与查询参数，禁止自动重定向。

原生管理接口覆盖会话草稿与选择、分页、知识编辑、附件导入、新格式备份、历史恢复、宿主操作和保留期清理。未决回执先从原拥有者核对，后续进度保持已接纳操作的身份与归属；新任务按当前未决操作和重做状态接纳。HTTP 连接通过对应连接的明确许可后再发送内容。

`RustAgentUiDelegate` 消费原生会话及运行投影，当前上下文计量、压缩状态、重生成目标与实际活动状态均来自 Rust。立即补充交接期间保持运行状态，旧保存收尾之后才开放继续。页面释放订阅不关闭核心。

离线验证入口为 `integration_test/agent_rust_offline_journey_test.dart`：模型使用预置回包，FRB、Rust 核心、业务工具、主库文件和 JSONL 使用正式实现。流程覆盖工具发现、三种权限、流式回复、已接纳保存期间的页面关闭、排队、停止继续、退出及重新打开数据。

Rust 工具链版本与目标维护在 `rust/rust-toolchain.toml`；手动 Cargo 命令从 `rust/` 目录运行。Flutter native assets hook 使用同一工具链，Android 编译使用项目当前最低 API，不提升 Android 基线。Android 的 `SkedApplication` 在启动时加载原生库并初始化系统证书验证器，AAR 版本取自 `Cargo.lock` 中的配套发布版本。Android Release 已在模拟器启动，确认原生库加载与系统证书初始化成功。
