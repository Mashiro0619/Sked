# Agent 设置与对话界面

本文说明正式界面的组织与交互。Agent 的运行、权限、持久化及平台边界仍以[使用逻辑](USAGE_LOGIC.md)和[运行时](AGENT_RUNTIME.md)为准。

## 入口与共享状态

设置总览有独立的 Agent 设置分类，直接进入 Agent 设置页。功能管理只保留 Agent 启用开关；关闭功能后仍可从设置总览管理连接与偏好。

手机使用完整对话页面。桌面可以在课表或日程旁打开 Agent 面板，并通过面板标题栏的展开按钮进入完整对话工作台。返回工作区会恢复原面板。两种桌面呈现与手机页面使用同一个应用级会话仓库和运行时；呈现变化不新建 Agent、不重复发送、不停止已有运行。

完整页面按实际可用空间展示会话侧栏。窄窗口和手机通过会话按钮打开历史侧抽屉；侧栏和抽屉读取同一本地历史，提供标题搜索、归档筛选及恢复入口。抽屉的标题、搜索和历史处于同一滚动区域，大字号和键盘占用空间时仍可操作。新建、改名、归档、导出和删除继续使用原有会话操作与保存规则。

## 阅读与输入

用户消息使用独立的填充容器；Agent 回复以正文排版，支持 Markdown、列表、引用、代码块及文本选择。消息与代码块分别提供复制入口，复制内容来自对应原文。操作卡仍由宿主回执生成，回复中的文字不能替代实际保存结果。

工具参数和普通工具输出收在执行详情中，展开后可以检查完整内容。来源材料保留独立的查看与移除规则。回复里的远程图片引用不会在阅读时自动联网加载；点击允许的网页或邮件链接才交给外部应用打开。

输入区包含多行输入、附件、权限选择和发送或停止操作；可选模型与思考强度控件在同一区域呈现。运行中可以继续写草稿，并明确选择调整当前要求或追加下一条消息。`Ctrl+Enter` 发送当前输入，运行中追加为待处理消息；输入法仍在组合文字时不触发快捷发送。普通 Enter 保留换行。

输入区与消息区分别处理滚动。键盘、大字号或小高度使输入区空间不足时，输入区内部可以滚动，保持操作可达。流式输出不重置输入框的选择和焦点。

阅读接近底部时，新消息和流式内容保持跟随。用户向上阅读后停止自动跟随，并提供回到最新消息的按钮；期间有新内容时按钮显示标记。重新跟随后清除标记，代码块内部的横向滚动不改变跟随状态。阅读位置记录稳定消息身份和消息内相对位置；关闭重开、面板与完整工作台互换、宽度或字号变化时仍定位同一条消息。定位使用该消息作为滚动原点，前后内容保持按需构建。草稿和阅读位置共享于同一仓库的本次应用生命周期，阅读位置不进入聊天导出。

## Material 3 Expressive

界面使用应用现有的语义色彩、`SkedShapeScheme`、填充图标按钮、胶囊选择和统一菜单表面。输入焦点通过轮廓变化表达；会话侧栏和发送／停止图标使用可重新定向的弹簧过渡，复制反馈及菜单使用短状态过渡。发送／停止在状态改变时立即切换操作与读屏标签，过渡期间只存在一个可执行按钮。流式文字不逐 token 播放进入动画。

动效遵循 `SkedMotionPolicy`：减少动态效果时去除空间运动，关闭动画时直接呈现终态。隐藏的侧栏不保留可点击、键盘焦点或读屏入口。桌面标题的拖动区域与按钮区域分开，完整页面保留系统标题栏控制所需空间。
