# Agent 设置与对话界面

本文说明正式界面的组织与交互。Agent 的运行、权限、持久化及平台边界仍以[使用逻辑](USAGE_LOGIC.md)和[运行时](AGENT_RUNTIME.md)为准。

## 入口与共享状态

设置总览有独立的 Agent 设置分类，直接进入 Agent 设置页。功能管理只保留 Agent 启用开关；关闭功能后仍可从设置总览管理连接与偏好。

Agent 设置采用与应用设置一致的页面层级。总览提供“连接与模型”“运行偏好”“技能”“记忆”四个分类；连接和知识列表是二级页面，单模型、技能和记忆正文在三级页面编辑。每页独立滚动，保留父页输入和阅读位置，窄窗和触屏沿用固定或折叠标题。入口提供按钮名称与可操作状态，Windows 原生无障碍读取同一导航语义。

运行偏好按对话指引、单次运行限额和聊天记录保留分组，各组说明影响范围。窄窗或大字号按原阅读顺序显示限额，宽窗可并列；完整字段标签保留可读名称与输入语义。改变窗口或字号保留草稿、校验和统一保存，设置冲突与退出保护不变。

返回未保存页面时先确认是否丢弃，保存期间阻止退出；保存失败保留输入并说明结果。子模型保存只更新模型，父连接页未保存的端点与密钥保持原值。保存使用已提交配置快照，较新设置不被旧草稿覆盖；成功后只完成自己的来源页面，被新页面覆盖时保留新页面。知识读取、连接诊断和模型入口绑定当次页面与目标，覆盖后返回不复活旧回调；已接受持久操作继续完成，旧结果不在新页面显示提示。

Agent 与课表、日程共用主界面导航，在中央内容区切换。桌面和大屏使用同一个工作台外壳与资源侧栏，会话历史放在 Agent 的资源区；手机底栏加入 Agent，隐藏底栏时仍能从主抽屉进入。导航按已启用的业务目的地与 Agent 计算数量、选中态和标签预算；只有一种业务工作区时，启用 Agent 仍可显示两个目的地。触屏导航目的地的实际点击范围至少 48dp，短窗口允许滚动以保留完整操作范围。Agent 是界面目的地，不新增持久化 AppMode。各入口提供完整名称、正确角色、实际启用与选中状态，禁用时不保留执行动作。工具栏和更多菜单不重复提供 Agent。

主外壳持有一个保留状态的 Agent 槽位，首次进入时才加载聊天宿主，切换目的地保留草稿和阅读位置。点击抽屉入口先关闭抽屉，再选择中央 Agent；所有会话入口先选定目标会话，再等待主外壳激活完成。导航或设置忙碌时请求等待；较新的业务目的地选择、功能停用和宿主失效会结束旧激活请求。切回原业务工作区不写 AppMode，切换到另一业务工作区仍以保存成功为准；停用 Agent 时显示已提交的业务工作区。隐藏内容不接收输入、焦点和辅助技术动作，迟到 UI 回调不能在重进后恢复执行，应用级 Agent 已接受的运行和持久操作继续完成。

Agent 按顶层目的地处理返回：先收起菜单、抽屉等浮层，没有浮层时沿用应用原有顶层返回规则，不自动切回进入前的工作区。内嵌标题使用主导航按钮，保留主界面的窗口拖动与系统按钮空间；设置中的 Agent 分类继续独立可达。

设置的紧凑工具栏按物理右侧预留窗口按钮，包括 RTL：返回仍沿语言方向排列，保存等页面动作与窗口按钮分别占用自己的区域。窄窗口和大字号下的返回与保存保持可点击。

聊天在加载或初始化失败时也保留主导航、标题和设置入口，沿用就绪界面的工具栏高度与物理右侧窗口按钮预算，包括大字号和 RTL。错误按主存储未就绪、聊天记录读取失败、连接初始化失败提供安全说明，不展示存档正文、凭据、路径或原始异常；错误区域可滚动。重试共享应用层初始化，失败保留原记录，不清空会话或推定模型强度。保留时间清理成功后才开放运行；清理写入失败后的重试重新读取已保存的会话。

Agent 资源侧栏和主抽屉读取同一本地历史，提供标题搜索、归档筛选及恢复入口。窄窗口、手机或侧栏折叠时通过主导航打开资源抽屉；历史正文按资源区实际高度滚动，短窗口、大字号和键盘占用空间时仍可操作。新建、改名、归档、导出和删除继续使用原有会话操作与保存规则。会话或可交互宿主改变后，旧权限菜单、会话动作和未开始的发送不能作用于新会话。

历史区顶部是一行新建、搜索和更多操作。桌面操作使用 32dp 图标目标，会话行高 36dp、行距 2dp，选中态使用紧凑圆角。字号增大时按内容扩展目标与行高，触屏目标和行高至少 48dp。搜索按需展开，关闭或隐藏后保留输入，归档筛选放在更多菜单，普通与归档列表分别保留滚动位置。新建使用同一个历史入口，抽屉先完成自身关闭再显示草稿。隐藏或收起的历史区停用点击、焦点和语义动作，旧菜单结果不能在重进后生效。

历史区内恢复归档时就地显示忙碌与安全错误。保存失败后保留可重试入口，先重新读取实际存储，再恢复仍有效的会话；关闭或替换历史宿主后，已接受保存继续完成，迟到反馈不污染新的历史区。

首次进入空历史时直接显示可输入的聊天界面，未发送草稿不进入会话历史。已启用但未完成连接配置时，提示下方提供“连接与模型”按钮，直接打开现有连接设置页；返回聊天保留草稿，配置完成后移除提示与入口。隐藏、覆盖或更换宿主与会话后，旧按钮回调失效，维护期间不开放入口。新建入口复用应用当前的未发送草稿；首次消息保存成功后才出现在历史列表，初始模型和权限随该草稿保留。归档、导出及历史版本操作只对已保存会话显示。

空历史的草稿创建等待当前宿主可交互；工作区转场、返回或重新激活后重新核对当前来源。旧宿主任务不会在另一个仓库创建草稿，已选会话及恢复选择保持原位，整个首次激活过程不写入存档。

未发送聊天的主标题显示 Agent，不重复放置新建按钮。标题沿用主工作台的工具栏高度与操作预算，桌面拖动文字不产生悬停提示，系统窗口按钮始终保留在物理右侧，包括 RTL。正文与输入栏两侧统一留白，空态使用简短引导和紧凑间距；小窗口与大字号保持导航、会话入口及发送操作可达。

## 阅读与输入

用户消息使用独立的填充容器；Agent 回复以正文排版，支持 Markdown、列表、引用、代码块及文本选择。消息与代码块分别提供复制入口，复制内容来自对应原文。操作卡仍由宿主回执生成，回复中的文字不能替代实际保存结果。

回执卡沿用运行时的结果核对规则。通用工具失败使用“执行详情”入口查看完整错误。`outcome_unknown`／`outcomeUnknown`、未知或待完成的外部效果，以及外部回执未收尾、需要恢复或数据状态未知时显示“需要核对操作结果”；明确失败或未执行显示“操作未完成”，准备结果显示“更改已准备好”。“已保存”或“已完成”只来自确认的回执字段，普通错误不会产生完成状态。主库更改已保存而提醒安排仍待完成时继续显示已保存，提醒状态单独说明。

等待审批使用独立的决策表面，与普通正文和已完成回执区分。业务审批卡在输入草稿之前就提供“补充当前要求”入口，作为次操作置于批准／拒绝组之前，主决策保持在卡片末尾；点击仅定位原输入框并显示修改指引，保留已有草稿与选区，不批准、拒绝或发送请求。用户写好调整后仍通过输入区原有的“补充当前要求”提交；当前计划或权限、会话、宿主来源变化后旧入口失效。HTTP 传输许可不提供业务修改入口。宿主计划包含清空本机数据时，在折叠详情之外直接说明聊天及文件、知识、业务数据、凭据和登录会话等实际删除范围，以及不可撤销和退出后果；按钮明确写出清除并退出并使用危险操作配色。危险呈现依据具体宿主变更，不根据模型摘要中的词语推断。英文、简体中文及繁体中文提供完整警告，其余语言暂按显式登记使用英文回退。

每轮完整结束后，仅最终回复提供消息复制按钮。过程说明、工具调用前后的中间输出、运行中及失败中断后的部分输出保留文字选择。用户消息继续提供复制与编辑并重做，回复的重新生成与版本切换放在所属正文下方。用户消息操作沿输入侧对齐，回复操作沿正文侧对齐；桌面随悬停或键盘焦点出现，最新消息和已有多个版本的回复保留入口，触屏直接显示并保留 48dp 点击范围。平台请求语义树或开启无障碍导航时，桌面历史消息也显示同位置的真实操作按钮，读屏无需先悬停或 Tab 聚焦；宿主隐藏或不可交互时仍移除这些操作的输入、焦点与语义。消息正文不重复提供第二个复制按钮，代码块仍可单独复制。

正文外链与复制入口绑定当次消息和可交互宿主，包括按下时的来源。切出、页面覆盖或消息改变后，旧回调与尚未松开的旧点击失效，恢复显示不会重新执行；已经交给系统的复制或外部打开继续完成，迟到反馈不改写新操作的状态或显示旧错误。正文与代码选择保持可用，远程图片仍只显示替代文字。

工具活动按发生顺序穿插在消息正文之间，相邻且属于同一轮的调用归并为活动入口。带正文的调用消息先显示正文，再显示对应活动，后续说明和独立回执分开相邻活动组。每组先显示数量和真实状态，再按需查看调用参数与返回内容。旧会话按用户消息边界组织显示，不补造轮次归属。准备、更改回执和错误继续独立显示，未知与未开始不误报为完成。活动列表最高 280dp，单项详情最高 320dp，完整内容左对齐、等宽排版，可滚动和复制；展开只影响阅读，不更改运行上下文或存档。来源材料保留独立的查看与移除规则。回复里的远程图片引用不会在阅读时自动联网加载；点击允许的网页或邮件链接才交给外部应用打开。

活动阅读锚点使用稳定的会话与轮次身份，交互失效不改变它。历史中的重复工具标识按所属组和消息顺序配对，保留各次参数与结果；无法唯一归属的旧运行记录独立显示，不合并进最新轮次，也不放宽运行时的重复调用限制。

Windows 中，Agent 自有的纯文本选择区域在同一个只读语义节点上提供完整可读名称与原文，保留文字选择和复制。范围包括审批预览、回执、工具与资源详情、来源和历史正文、用户消息与提示、代码块、图片替代文字、连接端点和附件说明；其他平台继续使用原有选择语义。Markdown 正文保留各段落和链接自身的富文本语义。

多行输入框下的操作区按逻辑方向分成两组：附件与权限位于起始端，模型／强度合并选择与发送／停止位于末端。模型按钮按内容收缩，最大宽度为 320dp 且不超过剩余空间；沿用 Sked 主题和 `labelLarge`，不铺满余量或增加独立胶囊底色。未选择模型时只显示“选择模型”和箭头。空间不足依次收起权限文字、省略过长模型名、隐藏行内强度，tooltip、语义名称和同一选择浮层保留完整配置；最小操作目标仍放不下时才换行。触屏有效点击范围至少 48dp，不缩小用户字号。模型保存失败、选择失效和下一轮生效提示位于输入区内、固定操作行上方。下一轮提示只在当前选择与进行中运行的已知模型快照不同期间显示，恢复相同选择后收起。

合并浮层采用紧凑居中布局：当前英文强度档位在上，模型名与切换箭头紧随其下，底部是带离散停靠点的胶囊滑杆。模型标题始终是具有悬停和焦点反馈的切换入口，只有一个模型时也可以打开模型列表。列表顶部使用独立返回图标和静态标题，桌面返回按钮为 32dp 方形，触屏为 48dp 方形。点击标题和行尾空白保留列表，悬停与焦点反馈限于返回按钮自身。选择其他模型时，支持当前强度则保留，否则使用该模型配置的默认强度；保存成功后回到卡片，保存失败留在列表显示反馈并允许重试。字段含义通过模型提示、滑杆语义和当前值说明，不重复展示两组字段标题与端点文字。右上角恢复设置中的默认模型及该模型配置的默认强度，提示中显示完整恢复目标。当前模型与默认模型不同，即使当前强度已是其自身默认值也可重置。保存成功后更新卡片，保存期间禁止重复操作，失败保留原选择并允许重试。默认配置、当前选择发生变化或浮层关闭后，旧重置回调失效。所有停靠点只按已配置的具体档位排序，不补造缺失档位；仅一个有效档位时直接显示值，失效选择仍提供明确重选动作。切换行的长模型名最多两行，完整名称保留在提示和语义中；字号增大时浮层自然增高。拖动只预览，结束后才保存完整二元选择；取消预览恢复保存值，保存失败保留错误反馈。切换会话或模型配置失效时关闭旧浮层并拒绝旧回调。模型选择只影响下一次请求，正在执行的快照保持原值。

模型浮层的最大宽度为 244dp，包含菜单表面内边距。卡片和列表共享该宽度与统一菜单宿主，切换时内容使用 120ms 淡入淡出、高度使用 180ms 过渡，并保持靠近触发器的边缘稳定。退出的页面立即移除点击、焦点和读屏动作，迟到回调不能更改当前页面的选择；减少动态效果时高度立即就位，关闭动画时全部直接呈现。强度与模型名共用紧凑的标题区，切换入口的有效高度至少 48dp；常规字号和单行模型名下，完整卡片高度不超过 116dp。单模型和多模型的名称均最多两行，完整名称保留在提示和语义中。内容按剩余宽度布局，强度页和模型列表保留完整边框与圆角。窄窗口与 2× 字号下允许自然增高并在需要时内部滚动，完整表面保持在可见窗口内。

强度滑杆从当前绘制位置和速度连续追随新档位，轨道填充、停靠点明暗与拇指共用同一动画位置。键盘和读屏按实际档位步进，保存值保持离散。保存期间锁定新操作并维持轨道颜色与拇指尺寸，成功后恢复操作，失败时回到实际保存值。减少动态效果或关闭动画时立即呈现目标位置。

模型浮层打开时，首次系统返回先关闭浮层并撤销预览，随后按当前宿主的返回规则处理。Esc、外部点击、宿主覆盖或销毁立即使预览失效，退场动画中的旧回调不得保存，也不遗留返回拦截。取得菜单焦点引起的输入法分帧收起，在窗口尺寸、DPR 和安全区稳定、遮挡逐边未增加时保留选择；新增遮挡或窗口几何变化仍取消旧浮层。

运行中可以继续写草稿，并明确选择调整当前要求或追加下一条消息。`Ctrl+Enter` 发送当前输入，运行中追加为待处理消息；输入法仍在组合文字时不触发快捷发送。普通 Enter 保留换行。

桌面空输入框采用紧凑内边距，权限操作的最小高度为 32dp。继续操作放在底部权限按钮旁，空间不足时随操作区换行。触屏继续入口位于草稿上方并保留完整点击目标。

输入区与消息区分别处理滚动。空间充足时，附件、草稿、运行中的调整／追加操作及模型状态在输入区内部滚动；附件、权限、模型与发送／停止的主操作行固定在底部，不随长草稿或附件滚出可视区。触屏输入底部为文本选区手柄的完整点击区域留出空间，避免覆盖操作行；桌面保持紧凑间距。布局按实际剩余高度、字号和操作目标预算保留至少一行草稿及消息阅读空间；极短窗口无法同时容纳时改为消息与完整输入区一起滚动，不用固定操作行挤光正文。键盘与窗口变化保留同一编辑控件、输入法连接、草稿、选区和正在组合的文字；即使向上阅读旧消息，极短布局的输入区也保持挂载，但不计作消息或阅读锚点。流式输出不重置输入框的选择和焦点。

阅读接近底部时，新消息和流式内容保持跟随。用户向上阅读后停止自动跟随，并提供回到最新消息的按钮；期间有新内容时按钮显示标记。重新跟随后清除标记，代码块内部的横向滚动不改变跟随状态。阅读位置记录稳定消息身份和消息内相对位置；关闭重开、返回工作区后再次进入、宽度或字号变化时仍定位同一条消息，不跳到末尾。定位使用该消息作为滚动原点，前后内容保持按需构建。草稿和阅读位置共享于同一仓库的本次应用生命周期，阅读位置不进入聊天导出。

## 修改请求与回复版本

纯文字回复可以在原消息位置重新生成。首个新文字到达前保留原文，实时内容、运行提示和所需的传输确认都属于该回复；阅读定位到稳定消息身份，不把新内容接到后续消息末尾。成功后替换该回复并保留原文与新版本，取消、响应失败或保存失败恢复已保存的原文，后续消息、工具回执与业务操作保持原有身份和位置。该过程沿用当前连接、模型、取消和用量边界，不提供执行工具，也不重新操作业务数据。

回复旁的箭头和版本计数可直接浏览已保存的文字；默认显示当前回复，新一次重新生成回到最新版本。浏览仅改变本次应用生命周期的阅读状态，不保存为新的活动回复，不改变后续模型上下文或调用模型。会话菜单中的“消息历史”继续提供完整旧消息后缀与回复版本。

具有完整宿主轮次记录的用户消息提供“编辑并重做”。编辑框说明将撤销该轮次及其后的本会话 Agent 操作，并只重做选中的一个请求；取消编辑保留草稿。宿主先核对所有主库与知识逆变更，遇到冲突、不可逆操作、缺失回执或容量不足时整段不开始，用户可以取消或将编辑内容放回输入区继续修正。旧消息后缀和其中的附件引用进入历史版本，后续旧请求不自动发送。

撤销或重做中断后，聊天显示继续入口；有未完成批次时禁用新发送。多个页面同时继续共享同一个流程，已完成的逆变更不会重复执行。重启和存储重试只恢复已经接受的撤销，新的模型请求仍等待用户继续。旧会话没有完整归属时保留阅读能力，不补造可撤销范围；协议与恢复边界见[历史重做](AGENT_HISTORY.md)。

## Material 3 Expressive

界面使用应用现有的语义色彩、`SkedShapeScheme`、填充图标按钮、胶囊选择和统一菜单表面。输入焦点通过轮廓变化表达；会话侧栏和发送／停止图标使用可重新定向的弹簧过渡，复制反馈及菜单使用短状态过渡。发送／停止在状态改变时立即切换操作与读屏标签，过渡期间只存在一个可执行按钮。流式文字不逐 token 播放进入动画。

动效遵循 `SkedMotionPolicy`：减少动态效果时去除空间运动，关闭动画时直接呈现终态。路由覆盖、恢复以及动画偏好变化保留状态切换组件中的工作区与输入状态；退场内容不保留点击、键盘焦点或读屏入口，关闭动画时隐藏尚未结束的退场内容。隐藏的侧栏不保留可点击、键盘焦点或读屏入口。桌面标题的拖动区域与按钮区域分开，完整页面保留系统标题栏控制所需空间。
