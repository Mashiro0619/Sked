# Agent 历史、回复版本与撤销协议

历史重做以宿主记录的交互轮次和操作回执为依据。各布局从侧边导航进入完整聊天，共用正式运行时：用户消息提供“编辑并重做”，纯文字回复提供“重新生成回复”，会话菜单可查看消息历史。会话格式 v5 保存轮次、旧消息后缀、回复版本和重做进度，继续读取 v1–v4；旧记录不会因为升级而补造操作归属。

归档恢复的保存状态与安全错误显示在当前历史区，包括独立历史抽屉和主界面的资源抽屉。保存失败保留原归档，重试先读取实际存储并恢复写入状态，再恢复仍属于当前来源的目标；读取期间短暂关闭运行请求不取消这次重试。恢复处理中阻止重复点击，已接受的保存继续由原拥有者完成。关闭、隐藏、切换会话或替换宿主后，迟到失败不显示在新历史区，尚未开始的恢复不转交给新目标。

独立历史抽屉随来源失效完成自身路由，输入、焦点和语义同时退出；不会弹出覆盖它的新页面。主界面资源抽屉遵循同一活动状态边界。仓库身份变化始终结束旧来源，即使前后都没有选中的会话，也不能通过切回旧仓库复活旧入口。

## 轮次与版本

`ConversationTurn` 记录起始用户消息、按原顺序排列的消息、运行身份及实际写操作绑定。继续与调整当前要求归属原轮次，消费下一条 follow-up 时才开始另一轮。操作必须在接受写入前记录到相应运行及真实工具调用；模型文字、时间戳和人工整理的摘要不能生成这份归属。

只撤销选中完整轮次及其后续轮次。中间出现没有归属的已执行写操作、缺回执、未知效果、不可逆操作或超预算时，整段预检失败。旧聊天可以阅读；没有完整归属的轮次不允许补造撤销范围。导入历史使用 `executionHistoryStart` 划定不可执行前缀，预检不允许选择或移走此前的消息。

`ConversationHistoryVersion` 保存被替换的原消息后缀、原运行与轮次；`ConversationReplyRevision` 只保存某条回复的文字版本。历史中的附件引用继续参与回收判断。查看旧版本不改变活动上下文，不重放旧消息或工具。

会话管理的 `conversations.describe` 同步公开这些字段的管理归属。执行边界、轮次归属和重做进度由宿主维护；历史重做与文字回复版本由对应的用户操作更新，不提供原始字段写入口。

编辑对话框取消后保留本次编辑草稿。整段预检被拒绝时，可以取消，或选择保留当前业务数据并把编辑内容放回输入框，由用户继续修正。已经进入撤销或重做阶段的会话显示继续入口；在该流程完成前不能发送另一条请求。网页来源交接的原消息进入历史版本后，重复交接仍核对原身份与原文，不重新创建会话或发送旧请求。

## 全部预检后才开始

`ConversationRedoCoordinator` 使用一个持久批次身份，依次记录 `prepared → undoing → undone → ready → running → completed`。停止、失败或重启记录错误与真实阶段，不把流程重新设为起点。重复提交同一编辑内容复用同一批次；重复继续共享在途流程。

宿主先停止选中会话并排空已经接受的操作，撤销旧审批、待处理输入与计划，再在共同的写入边界内核对所有参与仓储。所有票据、完整消息范围和保存预算通过之后，才能接受第一个逆变更。任何尚未开始的预检失败都不改变主库与知识正文。

- 主库复用持久原回执，逆序演算整段修改后一次保存。票据摘要绑定数据世代、原操作集合及完整逆变更；重新获得写入边界或重启后只能重建同一摘要的目标。已有 `undoBatchId` 回执还需与实际已应用状态一致，才能跳过已经完成的主库撤销。
- 知识仓储保存完整准备计划，聊天只保存其身份和摘要。同一记忆先创建再修改时，预检在影子版本上倒序演算，合成为每个对象的一次净修改。穿插人工修改或其他会话修改会使对应版本不连续，整体拒绝。创建后删除的净空结果仍保存逆操作回执及新的删除版本。
- 任一仓储写入开始后发生失败，宿主持有恢复边界，禁止普通业务写入。继续必须先读取拥有者的实际存储和回执，核对已经完成的阶段；不能重新准备另一套逆变更，也不能先启动模型重做。

全部逆变更确认后，会话仓储在一次保存中保留旧版本、发布选中的一个新请求、固定初次运行身份并切换到 `ready`。后续旧请求不自动重放。新运行失败或停止之后，显式继续为同一请求建立新的运行尝试，以 `continuedFromRunId` 关联上一尝试，每次分别计算轮次、工具和 token 预算。所有尝试仍归属于同一重做用户轮次，沿用已有操作回执，已接受的撤销只执行一次。

批次保留原始重做运行身份及实际中断错误码，已有存档可从该身份沿运行关联找到最后一次尝试。重启只核对状态，显式继续才会发起新的模型请求。连续点击继续共享同一个在途尝试，已经完成的尝试可直接完成批次收尾。预算耗尽后的续跑不会累计旧尝试用量来再次拒绝新请求，历史用量记录仍完整保留。

启动只检查独立的小型恢复标记，正常启动不因此读取整份聊天。存在标记时，应用在开放普通写入前读取各仓储、核对回执并完成已接受的逆变更，随后保留 `ready` 请求等待用户继续，不自动调用模型。界面的存储重试也先处理仍持有的历史预约；正在进入或执行撤销时拒绝并发恢复。标记已经实际清除但清理回执丢失时，只有原进程确认此前已进入安全释放阶段，并重新核对存储之后才能释放预约。

## 知识格式与恢复

知识格式 v2 继续读取 v1，并新增独立的 `storageRevision` 和有界准备批次。业务修改增加业务 revision，保存准备票据只增加存储 revision，避免双槽中的同业务版本异内容被误判为不可恢复冲突。拥有者计划、原回执与正文都不进入普通聊天工具摘要。

知识写入预约会排空已接受的保存并拒绝尚未接受的旧编辑。它是不可从 JSON 或备份构造的宿主对象。恢复期间只有持有该预约的批次可以提交；普通编辑与 Agent 工具继续遵守其正常写入门禁。未来格式或无法核对的存储保持拒写，不用内存旧副本覆盖。

取消尚未开始的聊天批次时，先在相同写入边界中确认删除该批次，再清理知识仓储中对应的未执行票据。聊天容量预检失败且能够确认没有保存批次时，同样清理票据；聊天保存结果不明时保留票据，避免删掉仍可能被恢复流程引用的准备材料。清理准备票据不改变知识正文或业务 revision。

## 仅重新生成文字

重新生成回复使用已核验的历史和操作结果，不提供工具定义，也不接入工具执行器。服务即使忽略空工具目录并返回工具调用，也会在发布回复前拒绝。该路径不能重做、撤销、再次通知或改变业务数据；旧结果未知仍按未知描述。连接、取消、请求预算、用量和同会话活动运行互斥仍由运行时接线负责。

流式重生成绑定应用运行身份与原回复的消息身份，显示在原回复位置。流式文字只用于展示；成功后一次保存新文字、对应的协议续传项和回复版本，消息身份与顺序保持不变。取消、模型失败或保存失败不发布新版本，原文继续保留；迟到响应不能覆盖已经取消的运行。新响应没有续传项时清除原回复的旧续传项，后续请求只使用活动回复实际对应的文字与协议材料。

重生成与普通回复使用相同的敏感值校验，完整响应的文字及非正文协议续传项都在保存前核对；续传结构检查实际嵌套字符串值和字段名，包括密钥自身含引号或反斜杠的情况。服务回显当前 API Key 的完整值时拒绝发布，错误状态只提供安全代码，不把回显内容写入消息、版本或聊天存储。旧历史中的工具参数和工具正文按声明的 JSON 字段解码一次，发现当前密钥时拒绝新传输并保留原历史；普通文本和续传结构内看似 JSON 的字符串保持字面内容，不继续解码。

重新生成较早的回复时，请求使用截至该回复的已核验上下文；成功后保留之后的用户请求、工具记录与业务回执，不撤销或重放后续操作。下一次普通发送读取替换后的活动回复及保留的后续历史。浏览旧回复版本只改变阅读内容，不改变活动消息或下一次请求上下文。

重生成要求完成响应包含非空、非纯空白的正文。空输出或只有隐藏推理续传项的完成响应按回复不完整处理，保留原文与原有版本，不用空内容覆盖可读回复；错误状态不展示服务响应正文。

- [历史区恢复与反馈](../test/agent/ui/agent_history_feedback_test.dart)：真实保存失败、存储读取后重试、忙碌门禁、隐藏与替换来源，以及已接受保存的完成边界。
- [完整范围与严格归属](../test/agent/history/conversation_history_preflight_test.dart)：跨轮次选择、旧历史、缺绑定、不可逆效果及导入前缀。
- [持久阶段与重复点击](../test/agent/history/conversation_redo_coordinator_test.dart)：全部预检、跨仓储故障、日志回执丢失、停止与继续。
- [真实主库逆变更](../test/agent/history/conversation_main_undo_test.dart)：重建摘要、目标漂移、一次保存、实际终态及最终权限。
- [知识整段逆变更](../test/agent/history/knowledge_history_undo_test.dart)：连续编辑、人工穿插、净空结果、重启及未知保存、双槽恢复与旧格式。
- [文字回复边界](../test/agent/history/conversation_reply_regeneration_test.dart)：空工具请求、非法工具调用与空白正文的拒绝。
- [原位回复运行](../test/agent/runtime/agent_runtime_controller_test.dart)：原回复流式身份、较早回复替换后的完整后续历史、取消与失败保留原文、新回复协议续传项的替换与清除，以及合成 HTTP 经过实际 Responses 解码后的空输出、空白完成和嵌套敏感值或字段名的拒绝。
- [正式应用与界面](../test/agent/history/conversation_history_application_test.dart)：真实工具调用归属、主库与知识逆变更、跨仓储中断及重启恢复、存储重试、清理标记回执丢失、重做失败后继续、未执行票据清理、网页交接去重，以及手机大字编辑和桌面回复版本查看。
- [独立恢复标记](../test/agent/history/conversation_history_marker_test.dart)：原生文件重新打开、损坏拒写，以及 Web 适配器的偏好存储替身验证。

应用专项使用实际运行时、工具协调器及存储拥有者，以合成模型、内存存储和故障注入核验终态。手机与桌面界面通过 Widget 环境验证；原生标记使用 Windows 临时文件，Web 标记使用偏好存储替身。这些证据分别覆盖其实际范围，真实模型、浏览器刷新、系统强杀和实体设备验收仍由最终平台阶段完成。
