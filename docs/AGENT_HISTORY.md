# Agent 历史、重生成与重做

聊天历史保存原始消息、工具调用与结果、运行用量、业务操作归属以及回复和重做版本。展示折叠与分页不会改变模型协议历史。

## 阅读与身份

页面默认读取最新消息页，边界保留完整工具调用及结果组。跨页的长任务通过轮次索引关联原请求与操作，无需一次展开整个轮次。切换会话和普通刷新保留已展开范围与阅读锚点；后台新增消息后继续保留旧页，删除或重做后按当前快照重建连续窗口。

侧栏和运行订阅读取轻量状态，页面读取连续消息窗口；回复版本、历史版本、来源正文及操作详情按实际选择读取。历史版本使用该版本内的稳定消息 ID 继续分页，读取游标之前的完整消息组。用量总计由完整运行记录聚合，详情再读取对应运行。离开页面时释放正文缓存，保留窗口边界和阅读位置；返回时先载入保存的窗口，再恢复阅读锚点。执行与归档显式读取完整源，不改变阅读窗口。

消息、轮次、运行和操作绑定使用稳定身份。工具调用的本地身份包含运行与模型轮次；服务重复使用 call ID 时，展示、统计、问答与恢复回执仍关联原工具组。原生协议记录保留服务返回的 ID，发送历史时由 Rig 维护调用与结果的配对。业务回执保存在其业务拥有者中，聊天中的自然语言不能制造已保存或已授权的事实。操作 ID 由宿主绑定到原始工具调用，模型不用复制新操作身份。

会话事实保存在原生追加式 JSONL，SQLite 保存可重建的身份、位置和状态摘要。展示查询按索引读取所需记录，跳过同一事务中的其他正文、协议历史和旧版本。运行期间保留执行所需的完整记录，连续队列完成后释放；归档与历史检查的临时全文不进入页面缓存。新格式归档由 Rust 编解码；未发布的旧 Agent 开发档案直接重建，不保留旧格式兼容。

## 编辑并重做

编辑历史请求时先固定受影响轮次、附件、引用及对应业务操作。全部逆变更在写入前核对；任一真实冲突使整段修改保持未执行。

历史维护租约先关闭普通写入入口并排空其他运行；主库和知识库各自提交自己的净逆变更与回执。跨库阶段由历史批次和独立恢复标记记录。已经开始保存后发生中断，继续读取原批次与实际回执，不重新生成一套撤销操作。

逆变更完成后，在同一次会话事务中保存旧历史版本、发布编辑后的请求并切换重做阶段。后续旧请求不会自动重放。重做失败或停止后，显式继续沿用批次和已经完成的撤销；新的运行尝试单独记录服务用量。

“结束重做”结束后续重做流程，并保留实际已经保存的结果与历史。取消尚未开始的批次清理其未执行票据，不改变业务正文。已保存但结果未知的写入须先核对。

待继续的重做批次保留原入口，新消息、重新生成、手动压缩和操作卡等待该批次继续或结束。接纳前先核对已保存回执，再按当前会话状态复核。

已经接纳的回答在正常停止时保存为唯一工具结果，并消费待回答记录。若进程中断时只保存了答案、尚未发布工具结果，重启和历史重做从这份持久记录补齐原工具身份；上下文已变化时保留答案并标记其原上下文。

首个写入恢复前读取小型标记，普通启动不为此扫描整个聊天。恢复仅处理已接纳的步骤，新模型请求等待用户继续。问答、引用变更和数据世代共同决定旧回答是否仍适用于当前请求。

## 重新生成回复

重新生成只请求替换指定回复的文字，不提供业务工具。成功后在原位置保存新正文、对应协议材料和回复版本；失败、取消、空白输出或保存失败保留原回复。普通回复、中止时保存的部分回复及各次重新生成版本记录产生该正文的实际模型与协议；已有版本缺少来源信息时继续保留可读正文，不猜测其来源。

重新生成较早回复时使用截至该回复的上下文，之后的用户请求、工具记录和业务结果继续保留。浏览旧版本只改变阅读内容。模型切换和回复变更会重新核对上下文摘要的来源，旧摘要不能覆盖新决定。

## 存储与恢复

原始与退役历史版本的消息、工具调用、运行和轮次作为会话事务追加到 JSONL，编辑一个会话不重写其他聊天。历史数量、批次数、操作数和正文长度没有人为容量门槛。

输入队列独立存储，尚未执行的要求不会伪装成工具或 notice 消息。摘要记录来源范围并保留原文；分页与摘要都不删除协议历史。恢复聊天后的追问会重新组装只读历史上下文，保留用户请求、回复、工具参数及结果文本，同模型和切换模型均适用。附件回收同时考虑当前消息、队列、草稿、旧版本与待重做请求。

业务主库把实际变更与回执一起保存，Agent 库只关联结果。停止后已接纳的保存等待核对，继续和重启不重复业务修改。
