# Agent 设备文件

设备文件通过 `sked.files@1` 提供服务，Windows 和 Android 默认 Profile 装配各自的系统文件 Provider。模型使用 `files.info`、`files.list`、`files.search`、`files.close_cursor`、`files.read`、`files.new` 和 `files.write`；Android 另用 `files.access` 读取系统授权状态及用户选取的位置。文件保存沿用应用的三种权限、操作审批和持久回执。

## 资源与读取

Windows 使用当前系统用户的文件权限，接受绝对盘符路径和 UNC 路径。资源记录保留请求位置、系统解析后的位置及文件身份；设备命名空间、备用数据流和普通文件分别处理。写入已有文件时要求普通文件，重解析点变化、资源占用和权限失败返回具体原因。

目录和文件名、文本搜索按页读取。游标绑定原查询和文件访问会话，后续页继续原遍历；关闭访问会话释放其游标。分页控制单次返回量，可以继续读取全部结果。目录变化、不可访问的子项和无法处理的内容通过实际结果及问题项表达。

取得所需结果后，可将 `nextCursor` 交给 `files.close_cursor`，关闭当前运行中的该项遍历并等待文件句柄释放；重复关闭保持成功。文本搜索尚未读完时会持有当前文件的读取句柄，修改这个文件前先关闭相应游标，再读取版本并准备写入。

搜索查询按非空 UTF-8 字面量匹配，保留空格、制表符和换行；可用全空白查询定位缩进或连续空行。

文件读取先将原内容复制为私有不可变快照，记录源文件身份、元数据、字节长度和 SHA-256。复制期间持有读取句柄，完成后按快照 ID 和字节偏移继续读取。重新打开外部文件会得到新快照；已有快照继续代表此前读到的版本。

新内容在私有目录分块暂存，完成后形成相同的内容快照。暂存句柄属于本次访问会话，关闭或取消时释放尚未完成的内容。二进制通过分块接口处理，文件内容不需要一次跨越整个 Dart/Rust 桥接。

`files.info` 分别报告资源支持的读取、列目录、新建、修改及写入方式。真正打开资源时再次核对系统权限和提供者状态，权限变化会返回当前错误。

## Android 授权与资源

Agent 设置中的文件访问页提供所有文件权限入口，以及系统文档和目录选择器。Android 11 及以上从系统设置返回后重新读取所有文件访问状态；较旧版本查询实际读写权限，Android 10 同时使用系统支持的旧版存储方式。普通路径遵守当前应用的系统权限。

文档选择保留真实 `content://` URI 和提供者身份。目录选择保留目录树 URI，后续子文档沿同一系统授权访问。选择结果按系统实际返回的读写标志取得持久授权；每次使用都核对当前授权，撤销后通过文件访问页重新选择。

本机授权记录存放于不参加系统备份的私有目录，便携备份也不携带授权。移除位置或清除应用数据时释放本服务取得的持久授权；取消或退出页面后，迟到的选择结果不能重新登记旧请求。

取得持久授权前先保存获取意图，取得后记录实际权限与归属。保存或回滚失败时保留待清理记录；清除等待选择请求和回滚结束，并核对权限已释放。重开后无法确定某项授权归属时保留待核对状态，避免把清空本地列表当成系统授权已清除。

URI 内容通过提供者的描述符流式读取，支持不能定位偏移的流；读取结果再保存为可分页的私有快照。外部版本按实际身份、元数据和内容摘要记录。Android 的原文件可以被其他应用并发修改，写入前重新读取并核对预期版本。

Android 缓存最近使用的 64 项快照句柄；在途读取和保存继续持有自己的引用。淘汰句柄保留磁盘内容，重新打开时核对原版本和完整摘要。

## 准备、审批与保存

新建普通路径要求目标不存在；新建文档使用父目录、名称与 MIME 类型描述目标，系统创建返回后才获得真实文档 URI。修改要求携带实际读取所得、含 SHA-256 的文件版本。准备阶段冻结请求目标、可获取的父目录身份、预期版本、待写内容和写入方式，审批展示这份材料。计划模式返回预览，询问模式由现有协调器确认，完全权限模式在相同校验后执行。

修改来源以资源身份、不透明版本、内容摘要和字节长度核对；可选的显示时间省略时沿用本次实际观察值，提供时一并校验。预览和后续保存始终使用核对后的完整版本。

原生准备句柄与具体内容绑定，不能用预览 JSON 重建。宿主生成操作 ID，接纳后同一 ID 只等待或返回原结果。准备失效、取消或所属应用被替换后，不能再启动写入。

Windows 保存通过句柄固定父目录和原文件，持有期间排除与版本校验冲突的写入和删除。发布前重新核对文件身份、元数据和内容摘要。修改已有文件时，先把原件移到同目录的唯一恢复位置，再以禁止覆盖的重命名发布新文件；其他程序在空档创建目标时，保留对方文件并返回冲突。新内容和原件的恢复位置随回执提供。

替换保留原文件的自主访问控制列表（DACL）及继承保护状态。暂存写入句柄先排除其他读取者，完成 DACL 复制后才写入内容；封存后核对同一对象、稳定版本和 DACL，再发布。不能完成复制与核对时在改变目标前停止；文件系统不支持持久访问控制列表时，按其实际能力处理。

EFS 加密文件可以按系统权限读取。当前替换方式不能保留其加密授权信息，因此修改在准备阶段返回 `unsupported`，保留原文件及其加密状态。

每个目标改名步骤先记录持久意图，私有证据和新文件完成同步后才继续。改名开始前取消可直接结束；开始改变目标后继续收尾，并报告实际文件结果。失败和取消的状态都不能替代对文件效果的核对。

Android 普通路径新建使用排他创建；修改在同一文件描述符上核对身份和完整内容版本后写回，保留原文件身份和权限。URI 修改写回原 URI，新建调用放在批准之后；原件内容先保存为快照。写入、关闭双方描述符和读回核对分别完成后，才报告已保存结果。

| 预览中的写入方式 | 实际保障 |
| --- | --- |
| `handleExclusive` | Windows 持有文件与父目录句柄，并以禁止覆盖的重命名发布。 |
| `exclusiveCreate` | Android 普通路径以排他创建取得新文件。 |
| `optimisticPathStream` | Android 普通文件在写入前核对版本，再通过同一描述符写回；其他程序仍可并发修改。 |
| `providerStream` | Android 文档使用提供者的创建或写入接口，保存后关闭并读回核对。提供者不提供通用的原子版本替换。 |

## 回执与恢复

文件回执同时记录操作身份、材料摘要、目标状态、原内容快照、恢复资源及错误。实际目标在尚未取得新文档 URI 时可以为空。

| 状态 | 含义 |
| --- | --- |
| `notStarted` | 本次操作没有开始改变目标；例如在接纳前取消或准备失效。 |
| `published` | 新文件已发布，保存位置和实际版本进入回执。 |
| `conflict` | 当前资源与预期不同；回执同时保留本次已经发生的效果和恢复资源。 |
| `failed` | 已取得完整失败证据；例如新文档已创建，但后续写入失败。 |
| `unknown` | 中断或证据不足，暂时无法确定这次操作的完整文件效果。 |

完整终态回执保存原次操作的结果。以后其他程序修改目标，不会把此前成功保存的回执改成失败。未完成记录由 `writeId`、宿主操作 ID 和材料摘要定位，恢复入口只核对原始证据及当前文件身份，不再次移动文件或重放写入。确认发生并已收尾的冲突保留其文件效果，同时向模型返回冲突，供下一次明确操作处理。

已有 Windows 写入记录沿用保存时的格式和摘要核对，再补入当前结果字段；原操作身份、材料摘要和已记录结论保持有效。

效果单独记录为 `notStarted`、`observed` 或 `unknown`，`settled` 表示是否已有完整结算证据。失败可以同时有已观察到的文件变化；尚未结算的结果继续等待核对。创建调用已经发出但新 URI 尚未返回时保持未知，不按同名文档猜测，也不自动再次创建。

同一投影用于即时工具结果、操作查询和恢复。Agent 完成文件任务时依据真实保存回执提供结果位置，相关交付界面按[插件计划](AGENT_PLUGIN_ARCHITECTURE.md)继续接入。

## 生命周期

文件访问会话有独立取消与关闭入口，模型运行结束时清理所属游标和未完成内容。资源创建后即归属本次访问，首屏失败或结果尚未回传也纳入关闭等待。阻塞文件工作在原生工作线程执行；等待方退出不会遗弃已接纳的底层操作。提供者关闭失败时保留待清理身份并返回错误，后续关闭或退出可再次核对。Provider 退出停止新接纳，释放未启动的准备句柄，等待实际文件工作与回执收尾后结束。

Android 元数据查询和目录准备也在取得游标后立即登记。查询或关闭失败时，原文件访问或设置页继续拥有清理责任；设置页取消、清除授权和引擎退出都等待所属查询完成并处理遗留游标。
