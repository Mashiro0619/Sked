# 对象选择备份与恢复

设置的“备份与恢复”提供对象选择页，原保存和分享文件入口也先选择对象再生成 ZIP，复制旧 JSON 文本的兼容入口继续保留。从文件恢复支持新的 ZIP 与旧完整 JSON；从文本恢复的 JSON 也进入同一选择页。先查看和勾选对象，再查看实际新增、替换及依赖复制的清单，确认后才开始写入。滚动列表或取消确认保留筛选输入和选择，返回文本输入保留原文。重新打开备份或加载当前数据时清空筛选输入。等待确认时没有执行进度；接受后的恢复属于应用，离开页面不会取消已经开始的跨库写入。

## 选择与身份

可选择单个课表、节次时间集、日程分类、学校站点、Skill、记忆和聊天，应用偏好按组选择。默认导出勾选普通业务数据和偏好，聊天、共享知识及 Agent 配置需显式勾选。聊天引用的附件元数据随历史保留，每份文件的二进制独立勾选。未包含的文件保持缺失状态，不能因为目标设备已有同 ID 内容就隐式使用它。

设备设置另按来源平台与分组保存，包含面板尺寸和开发者预览偏好，需显式选择；它们不包含系统授权、窗口句柄或运行许可。设备分组只应用于相同平台，异平台分组在选择和确认页明确列出并跳过，本机偏好保持原值。Agent 的对象清单提供 `supportedOnThisPlatform`，恢复计划提供 `unsupportedGroups`，实际结果列出跳过项。

同 ID 的选中对象替换其原位置，不存在则新增；同名不合并，空选择不清空数据。课表引用的节次集以及聊天引用的文件属于明确依赖。未直接选中的依赖与目标设备发生冲突时，只复制该依赖并重绑所选对象；直接替换被未选对象引用的共享资源会要求补选相关对象或取消。课程和日程子对象发生 ID 冲突时，只重绑所选父对象中的冲突项及其提醒、显示引用。

学校站点使用[持久身份](SCHOOL_SITE_IDENTITIES.md)。旧 JSON 没有站点 ID 时，由备份内容和原始顺序建立稳定的导入身份；不会使用名称或 URL 猜测本机对应站点。

## 归档与导入边界

ZIP v1 使用 `manifest.json`、逐对象 JSON 和按摘要标识的二进制文件。清单声明对象身份、依赖、路径、长度和 SHA-256；读取核对清单及文件，拒绝未声明项、重复项、错误摘要、循环依赖、链接、加密归档、路径越界及不支持的版本，不把 ZIP 路径解压到文件系统。单份附件最多 32,000,000 字节，整个归档及解压内容各有 128 MiB 上限；单对象 16 MiB，清单 2 MiB，最多 2,048 个对象。旧完整 JSON 继续使用 20,000,000 字节导入预算。

文件与文本入口遇到未来 ZIP、旧 JSON 外层或 AppData 格式时显示升级提示，保留输入和当前数据。导出取消会传递到实际附件读取；读取仍在等待时也能停止并释放导出占用，尚未完成的产物不能报告为已保存。

API 密钥、Cookie、系统授权、设备运行许可和操作回执不进入便携归档。可选择 Agent 连接地址和模型目录，但不携带密钥；恢复到不同目的地会清除旧目的地凭据，原目的地未改变时保留其本机凭据。Agent 开关与三种权限使用接收设备的选择。旧 JSON 不从兼容默认值中补造 Agent 连接或偏好选择。

读取备份清单只加载聊天、共享知识和必要的附件读取状态，不初始化模型连接、不访问凭据存储，也不触发历史保留清理。Agent 关闭或凭据存储暂不可用时，普通数据仍可导出和恢复；实际聊天或知识库读取失败仍明确阻止清单生成，不能静默遗漏。选择恢复连接配置时才核对凭据存储，读取失败或格式过新在 journal 写入前拒绝；已接受恢复仍遵守原有跨库核验与继续恢复门禁。

聊天恢复只发布可阅读历史，包括回复和历史版本、来源与附件引用。旧运行、审批、输入队列、工具续传和重做能力不恢复；导入前缀通过 `executionHistoryStart` 与新的执行历史分开。普通文字中的引用不因恢复而当作授权或业务目标。

全新会话首次发送前的正文、来源与文件引用只属于本次应用生命周期，不进入备份清单。普通备份读取、预览、设置和导航保留该草稿。完整恢复或存在实际写入的选择性恢复在全部目标读回且完成标记清除后丢弃恢复前的新会话草稿，选择性恢复是否勾选聊天不改变此边界；失败、取消、空选择和没有待恢复目标的继续操作保留草稿。未选持久聊天中的既有草稿和历史继续保留，来源仍记录采集时的数据世代，不为旧来源补造新的授权。维护释放后按全部剩余聊天、历史版本和待发送引用回收附件，仍有引用的文件不会因丢弃新会话草稿而删除。

## 固定目标与故障恢复

恢复预约先阻止新业务写入，排空已经接受的主库及侧库操作、连接保存、设备偏好保存和附件写入，然后冻结聊天、知识及设备偏好拥有者。所有参与仓储先准备和验证目标，二进制先写入专用暂存存储；任何预检失败都不开始业务写入。未返回准备结果就失败的附件参与者负责清理自己的部分暂存内容。

聊天参与者在 journal 写入前按完整存档规则校验合并后的目标，包括总数量、字节预算和共享引用关系；不能只验证每个导入聊天。合并后超过 200 个聊天时拒绝本次恢复，主库数据世代和各仓储内容保持原值，不留下待继续的恢复任务；新增后恰好 200 个或在上限内替换同 ID 聊天仍可恢复。

首次 journal 固定数据世代、对象映射和每个仓储的原值、目标值及阶段。附件、主库、必要的凭据处理、学校站点、设备偏好、知识和聊天依次确认；每步都读取拥有者实际存储。设备偏好逐组选定目标，某组已经保存而下一组失败时，继续只写尚未到达目标的组，不替换未选组。恢复中断后普通写入保持关闭，重新打开应用或“继续恢复”都沿用原目标。正式主页检测到写入被阻止时关闭已有设置和编辑页面，进入数据恢复页；从该页重试也继续原恢复目标，核验完成后才重新开放编辑。已保存但阶段回复丢失的步骤通过实际内容识别，不重复分配 ID 或重新准备目标。即使 journal 已到完成阶段，重试清理前也核对最终数据。

原生 journal 使用双槽并写入完成墓碑，浏览器使用受控偏好存储。二进制暂存位于应用专用目录或独立 IndexedDB；不会用原设备文件路径恢复。只有全部仓储确认后才移除暂存并清除 pending 标记，解除普通写入限制。损坏、未来版本或无法确认的 journal 保留恢复边界。

历史撤销与备份恢复共用维护门禁；已有历史撤销身份或 pending 标记时不能开始备份恢复。同时存在两种恢复标记时保留两者并拒绝写入。Agent 发起恢复走同一个应用拥有者，仅在排空时排除正在等待这次恢复结果的发起运行，避免等待自身。

Agent 选择性恢复在接管恢复之前重新核对固定目标；已经发生的目标变化或已撤销的请求返回未开始写入的失败，保留本地数据。进入恢复拥有者之后的异常继续保留未知结果，由生命周期读取原 restoreId、数据世代和参与仓储目标继续；不能从 journal 当前为空推断此前没有写入。

旧整体恢复 API 继续为兼容调用保留。其新准备目标先固定站点身份；升级发现旧 prepared journal 中没有站点 ID 时，先持久化并读回身份再写业务库。它与选择性恢复各有独立 journal，不同时重放。

## 可复现验证

- [纯选择与依赖规划](../test/backup/selective_backup_planner_test.dart)和[主数据合并](../test/backup/selective_backup_app_data_test.dart)覆盖未选保留、共享依赖、子对象重绑及导入权限边界。
- [归档检查](../test/backup/selective_backup_codec_test.dart)覆盖字节、摘要、预算、路径和版本拒绝；[journal](../test/backup/selective_restore_journal_test.dart)及[协调器](../test/backup/selective_restore_coordinator_test.dart)覆盖持久阶段和实际结果核对。
- [真实应用组合](../test/backup/selective_backup_service_test.dart)覆盖保存、排他、部分暂存失败和恢复；[原生仓储重开](../test/backup/selective_backup_recovery_test.dart)在系统临时目录使用主库、学校、聊天、知识、附件和 journal 的文件实现，验证新的运行时继续同一目标。
- [恢复与新会话草稿](../test/backup/backup_draft_boundary_test.dart)覆盖真实完整与选择性恢复的成功、失败、取消和空操作，完成清理失败后的继续恢复，临时选择不写入聊天存档，以及维护释放后保留历史引用并回收旧草稿文件。
- [懒加载恢复边界](../test/backup/backup_dormant_agent_test.dart)核对恢复前后不读取聊天与附件，首次进入完成服务恢复后即可附文件，并继续清理真正无引用的文件。
- [选择页](../test/backup/selective_backup_page_test.dart)及[设置入口](../test/widgets/settings_backup_restore_progress_test.dart)覆盖窄窗、放大字号、旧文件与文本、滚动和取消后的筛选与选择保留、重新载入来源后的筛选清空、恢复进度、故障继续和离开页面后的保存所有权。
- [设备偏好](../test/backup/selective_backup_device_test.dart)覆盖严格读取、相同与不同平台、未选保留、两组之间中断、写后读回和重新绑定真实 UI 拥有者；[导出取消](../test/backup/selective_backup_cancellation_test.dart)核对挂起读取取消及占用释放。
- [Agent 工具](../test/backup/selective_backup_tools_test.dart)通过真实应用运行作用域验证选择、权限、保存及发起者排空，并覆盖非法与重复选择、同会话来源约束、准备后人工修改目标，以及主库保存后阶段写入失败的未知结果和沿用同一恢复身份、数据世代及仓储目标的生命周期恢复。模型和原生目的地使用确定性替身；这些测试不代替实际平台文件选择器、真实 API、浏览器刷新或实体设备验收。
