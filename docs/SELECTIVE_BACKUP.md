# 对象选择备份与恢复

备份按具体对象选择：课表、节次时间集、日历、学校站点、Skills、记忆、聊天及设置分组。先查看范围，再保存文件或确认实际恢复影响。空选择不清空数据，取消保留当前数据和选择。

导出等待附件读取时，取消会立即结束本次导出；读取稍后完成也不会生成备份。

## 身份与选择

同 ID 的选中对象替换原位置，不存在则新增；同名不会隐式合并。课表引用节次集，聊天引用附件元数据。共享依赖发生冲突时，复制必要依赖并重绑选中对象；直接替换被未选对象使用的共享资源时明确要求补选或取消。

聊天和共享知识需显式选择。附件元数据随聊天保存，二进制逐项选择；未携带的文件在恢复后保持缺失。设备设置按来源平台和分组保存，异平台项目在清单及结果中列为跳过，本机值保留。

旧学校站点缺少 ID 时，使用备份内容和原始顺序建立稳定导入身份，不通过名称或 URL 猜测目标。

## 新归档格式

新 ZIP 使用选择性备份版本 2，manifest 另外声明 `agentSchema: sked-agent-records` 与 `agentVersion: 3`。Agent 对象直接保存 Rust 导出的便携会话快照、知识记录和附件元数据；Dart 负责对象选择、依赖映射和 ZIP 包装。逐对象 JSON 和按摘要命名的二进制文件分别保存。长度、SHA-256、对象依赖、唯一身份及归档路径参与校验，ZIP 内容不解压成任意本机路径。

Agent 版本 2 的原生归档继续读取，已开始的版本 2 恢复沿用原目标和恢复身份。旧 v1 ZIP、声明 Agent 版本 1 但只包含业务分组的 v2 ZIP 继续读取；包含已退役的版本 1 Agent 聊天、知识或附件时明确报告版本不支持。旧完整业务 JSON 和文本入口继续进入对象选择，不从兼容默认值补造 Agent 配置。

对象数量、消息数量、单文件、单对象、清单及总字节数不再使用旧固定容量门槛。分页、折叠和预览只影响加载与展示。损坏、摘要不符、未知版本、未声明文件、重复身份或循环依赖按实际问题拒绝。

恢复的聊天消息保留只读历史身份。完整记录保存原始执行边界，分页视图按页起点换算边界，加载更早消息或重开数据库后均不把导入历史转成待执行内容。

凭据、Cookie、系统授权、执行许可和本机操作回执不进入便携归档。连接地址和模型目录可选择导出，密钥始终留在安全存储；恢复到不同目的地时由凭据拥有者处理原凭据。接收设备保留自身的 Agent 开关与权限选择。

## 聊天与草稿

聊天导入保留可阅读消息、来源、附件及历史和回复版本，包括工具名称、调用参数与结果配对；旧运行、输入队列、待回答交互、业务执行许可及协议续传不激活。导入历史与后续执行使用明确边界。同 ID 聊天被恢复时，原操作展示记录和上下文摘要在同一事务中移除。

工具内容通过原消息的正式引用保存，当前消息和历史版本都参与附件依赖与回收。恢复复制附件时同时重绑两处引用；原文件来源作为阅读证据保留，系统授权仍由接收设备决定。

空新会话草稿不进入备份。完整或有实际写入的选择性恢复在全部参与者确认后清除恢复前的新会话草稿；失败、取消和空操作保留。未选持久聊天的草稿和历史继续保存，附件根据全部剩余引用回收。

备份读取不调用模型、不打开密钥存储，也不触发历史保留清理。真实聊天或知识存储错误明确报告，不能当作空内容导出。

## 事务和中断恢复

恢复先排空已接纳写入并冻结参与拥有者，固定对象映射、数据世代和每个目标。二进制先进入专用暂存。历史撤销与备份恢复共用维护入口，不同时执行两个互相覆盖的恢复。

主库、凭据、学校站点、设备偏好、知识和聊天按已登记阶段保存。会话目标和恢复摘要进入同一次 JSONL 提交，知识目标和恢复摘要进入同一个 SQLite 事务。协调器通过 Rust 核对固定目标与恢复标记，不在 Dart 中重建原生摘要算法。

跨库 journal 保留固定目标和进度。重启或“继续恢复”读取实际已保存结果，跳过完成步骤，不重新生成 ID 或重放效果。全部阶段确认后清理暂存和 journal，并刷新正常的数据视图。数据库 marker 作为已提交事实保留，阶段回包丢失时仍可核对。

Agent 发起的完整或选择性恢复在各自已有的 journal 中固定本次操作的完成账本，复用既有主库目标。所有参与者确认后才保存最终回执，再清理 journal。最终回执保存失败时，恢复继续完成同一目标；原操作身份、请求摘要、恢复 ID 和前后数据世代共同绑定这条记录，其他旧世代操作保持失效。完整 JSON 恢复 journal 使用版本 3 保存这份完成账本，继续读取版本 1、2；回执已保存但回包丢失或 journal 清理失败时，重启核对同一账本并跳过已完成的业务写入。

原生跨库 journal 继续由专用文件拥有者保存；它不承担正常聊天或知识的日常持久化。Agent 恢复阶段接受当前格式及兼容的版本 2 原生目标。

Agent 使用 `backups.inspect` 查看范围、`exports.generate` 生成产物、`exports.write` 保存文件及 `backups.restore` 恢复选中对象。业务动作各用一次模型调用，权限确认在调用中完成。发起恢复的运行在排空时排除自身，已经接纳的恢复由应用继续核对。

选中对象与本机内容一致，或只选中不支持的平台设置时，Agent 返回无变化结果和跳过清单。计划、询问和完全权限模式均直接返回，不请求确认、生成操作回执、进入维护或切换数据世代。
