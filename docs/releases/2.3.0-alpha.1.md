# Sked v2.3.0-alpha.1

本版本为预发布版本，集中更新自适应工作区、日期与时间选择、设置与编辑体验，并修复通知和数据保存问题。建议体验前先导出完整应用备份。

## 新增

- 新增“功能管理”，可分别启用或停用学生课表与通用日程，至少保留一个工作区；停用时保留数据与配置，并停止对应功能和提醒，之后可重新启用。
- 通用日程新增 1–14 天的自定义日期范围，支持跨周、跨月选择、直接输入起止日期和手机拖选；保存后可按所选天数前后浏览，重启后保留范围设置。
- 自定义日程视图新增自动／手动最小列宽；空间充足时等宽铺满，不足时横向滚动，日期表头、全天栏与时间网格保持对齐。
- 新增“设置 → 关于 → 接收预发布更新”开关，新安装默认开启，可接收 Alpha、Beta、RC；已有渠道设置保留，关闭后仅接收正式版。偏好会持久保存，切换渠道时清理旧的更新提示。
- 新增 Microsoft Store 专用 MSIX 构建与产品身份配置，商店包使用独立数字版本规则并检查包清单；商店版由 Microsoft Store 管理更新，不使用 GitHub 的预发布开关。商店上架仍需单独送审。

## 工作区与界面

- 重构桌面与宽平板布局，以资源侧栏、课表／日历主区域和详情／编辑面板协同工作；窗口变窄时自动调整为浮层或独立任务，保留浏览位置、面板状态与编辑草稿。
- 仅启用一个工作区时不再显示多余的模式切换；双工作区导航保持同等层级，侧栏展开与收起时不再造成图标跳动或日历突变重排。
- Windows 顶部操作与窗口控制整合为一行，改善窄窗口与大字体下的日期、跳周和更多菜单布局；修复首次启动页、空课表主页无法拖动窗口的问题。
- 修复手机整周日程布局，恢复课程／日程详情和编辑的底部弹窗；首页顶部操作合并为一行，日期标记与课表统一，减少不必要的空白。
- 优化手机底部工作区导航的选中状态、图标位置与系统安全区，统一导航区背景，避免重复底部留白。
- 紧凑月视图改为上方月历、下方当天安排的单一滚动页面，缩减空日程占位；改善农历、大字体和两位数日期的显示，宽屏继续保留侧边安排。
- 优化日／周视图的固定表头、全天日程展开、重叠事件分栏与溢出入口，短事件不再为适应布局而虚增显示时长。
- 统一主页、侧栏、标题栏、详情面板和弹窗的背景与层级，改善浅色／深色模式的一致性，同时保留用户选择的主题色、课程色与分类色。

## 日期与时间选择

- 统一日期选择器在日、周、月导航和业务表单中的体验，支持日历与输入模式；手机按任务使用紧凑弹窗、锚定跳周菜单或底部日期范围选择，桌面选择器就近锚定操作入口。
- 时间选择改为独立循环的小时／分钟滚轮，并保留直接输入、24 小时格式与输入校验；窄屏、键盘弹出和大字体下的操作区可自适应换行。
- 课表跳周改为紧凑数字网格，打开时显示当前选中周，支持滚动和键盘操作，并区分实际当前周与学期外的边界周。
- 统一日期选中高亮和数字居中，修复日期被背景裁切、月份／年份层过宽及重复标题占位；切换输入模式、旋转或调整窗口大小时保留选择草稿。

## 设置、编辑与数据管理

- 设置首页改为分组总览，优先展示已启用的课表／日程设置，之后为通知、外观与语言、功能管理、数据与隐私和关于；宽屏索引定位同一组内容，详细选项收进独立页面。
- 设置、主题与提醒控件统一为连接式分组，调整图标、文字、当前值和说明层级；选项菜单锚定当前值，修复菜单关闭后的焦点及图标居中问题。
- 外观页可编辑另一工作区的主题而不切换当前工作区；语言设置保留独立搜索页和搜索状态，保存期间统一保护工具栏与系统返回。
- 重做节次时间集编辑器，按时间顺序展示节次、起止时间、时长与课间；支持紧凑新增入口、时间校验和清晰的等待／保存／失败状态，增删与调整窗口时保留列表位置。
- 分类管理统一为可滚动列表，展示颜色、事件数量、显隐与操作；新增和重命名使用简洁确认弹窗，取消不创建占位分类，保存失败保留草稿。
- 课程专属提醒收进“更多”，摘要区分沿用默认、关闭和自定义；无效的自定义提前分钟数会明确提示，不再静默退回默认设置。
- 统一课表／日程导入导出页的分组、间距与操作布局，窄屏和大字体时改单栏；移除空课表重复标题、宽屏设置重复返回按钮和“数据与隐私”中的重复备份入口。
- 完整应用备份与恢复在设置总览保留唯一入口，并保留工作区启用状态、自定义日期范围和列宽等设置；修复存储恢复提示出现时的标题栏对齐。

## 修复与稳定性

- 修复日期导航或清除自定义范围后日程列宽设置丢失的问题；课表配置保存失败时恢复原选中周，同时保留等待期间的新导航，删除非活动课表不再无关跳周。
- 加固磁盘保存失败后的回滚与恢复副本隔离，避免已报告失败的修改或旧临时副本覆盖较新数据；保存结果无法确认时明确提示并保护后续写入。
- 修复已确认失败的 API 密钥写入反复阻止 Windows 关窗或停用课表工作区的问题；结果仍未知时继续校验，不直接忽略错误。
- 修复持久化 UTC／带偏移时间的重复日程在部分时区漏掉查询范围内首次实例的问题，保留现有 ICS 导入行为；通知启动超时后可在数据就绪时恢复订阅，排程仅使用已提交的数据快照。
- 加固编辑器退出和草稿保护，完整数据替换后清退旧编辑会话；导入提交与保存期间阻止重复操作或返回，失败后保留可重试内容。
- 校验日程结束时间及节次输入，明确展示错误，避免无效时间被静默修正后保存。
- 修复通知在重建排程、切换语言、重启或恢复后可能重复投递的问题；仅对确认未提交且仍在补发时限内的提醒补发一次，保留“稍后提醒”的独立状态。
- 修复通知运行时锁顺序与队列清理引发的死锁，避免相关导航和保存操作卡住；完善 Windows 待处理通知识别与重复排程清理。
- 更新比较遵循 SemVer：正确识别 `alpha.1 < alpha.2 < beta.1 < rc.1 < 正式版`，数字后缀按数值比较，忽略 `+构建号`；同版本 RC 升正式版现在会提示更新。
- GitHub 更新检查按渠道筛选全部分页中的有效发布，不再遗漏预发布版本或误用发布时间作为版本顺序；支持自定义更新源提供正式版／预发布列表，草稿发布始终排除。
- 更新检测与版本显示优先读取 Flutter 的完整构建版本，避免 iOS/macOS 原生版本字段丢失预发布后缀；Windows MSIX 打包兼容预发布版本，并使用数字版本生成包身份。

## 开发者预览

- 新增默认关闭的 AI 侧栏布局预览，仅显示只读工作区上下文并保留本次消息草稿，不会发送请求、执行操作或修改数据；这不是已接入的 AI 对话功能。

## 预发布说明

- 新安装默认包含预发布更新，升级保留已有渠道设置；旧配置缺少开关字段时仍按原有关闭状态读取。已安装的旧客户端仍使用旧更新逻辑，不会因发布此版本自动获得新能力，必要时需手动安装。
- 按 SemVer，`2.3.0-alpha.1` 低于 `2.3.0`；版本号已经是 `2.3.0` 的安装包不会把本版本识别为升级。应用版本比较与 Android／Windows 的构建号安装规则相互独立。
