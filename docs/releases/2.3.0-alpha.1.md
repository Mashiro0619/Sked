# Sked v2.3.0-alpha.1

这是 2.3 系列的首个 Alpha，面向愿意反馈问题的测试用户，不是正式稳定版。**安装或切换分发渠道前，请先导出完整应用备份。** 应用版本为 `2.3.0-alpha.1+14`。

## 主要变化

- **自适应工作区**：桌面与宽平板采用资源侧栏、主视图和详情／编辑面板；窄窗口、手机与大字体下自动调整布局。学生课表和通用日程可分别启用，停用时保留数据并停止对应提醒。
- **更灵活的日历**：支持 1–14 天自定义日期范围、自动或手动最小列宽；优化月视图、全天日程、重叠事件和手机端浏览体验。
- **统一的日期与时间选择**：日期选择支持日历／输入模式，时间选择支持独立小时／分钟滚轮和直接输入；改善跳周、键盘和旋转后的草稿保留。
- **重做设置与编辑体验**：按功能分组设置，改进节次时间集、分类管理、课程提醒和导入导出页面，保留完整应用备份的唯一入口。
- **预发布更新渠道**：新安装默认开启“接收预发布更新”，可在“设置 → 关于”关闭。已有选择保持不变；旧配置缺少字段时仍按关闭读取。
- **Microsoft Store 分发支持**：提供独立商店包和商店更新入口。这不表示商店已经上架；商店认证和发布范围单独管理。

## 重要修复

- 日期导航不再丢失自定义列宽；保存失败后正确恢复选中周，且不覆盖等待期间的新导航。
- 加固保存失败回滚和恢复副本隔离，避免失败修改或旧临时文件覆盖较新数据；保存结果不确定时明确提示并保护后续写入。
- 修复已确认失败的密钥写入持续阻止 Windows 关窗或停用课表工作区的问题。
- 修复通知排程、动作轮询之间可能出现的互等；恢复对账只使用已提交数据，清除数据后取消过期任务。
- 改善通知启动超时后的恢复、重复提醒处理，以及 UTC／带偏移时间的重复日程查询。
- 更新比较遵循 SemVer，正确识别 Alpha、Beta、RC 与正式版，GitHub 检查覆盖所有分页并排除草稿发布。

## 下载与升级注意事项

- **Android**：多数手机选择 `arm64-v8a` APK；不确定架构时使用通用 `release.apk`。其他架构文件按设备选择。覆盖安装还要求包名、签名和系统版本规则兼容。升级时尽量沿用原来的包类型（通用包或同架构包）；从分架构包换成通用包可能被系统判为降级，不要为绕过限制直接卸载并丢弃数据。
- **Windows x64**：下载 `windows-portable-release.zip`，完整解压后运行 `sked.exe`，不要只复制 EXE。首次运行可能遇到系统安全提示，请核对来源和校验值，不要关闭系统安全防护。
- 旧客户端仍使用旧更新逻辑，不会因为服务器新增 Alpha 就自动具备预发布检查能力；本次测试可能需要从 Releases 手动下载安装。
- 按 SemVer，`2.3.0-alpha.1 < 2.3.0`。已安装版本显示为 `2.3.0` 的开发包不会把本版本视为更高版本；构建号相同也不保证系统允许覆盖安装。请先备份，不要为降级直接卸载并丢弃数据。
- Microsoft Store 版与站外版身份、更新渠道不同，不保证覆盖安装或数据自动迁移；切换前备份，并避免两份程序同时提醒。商店提交用的未签名 MSIX 不是普通侧载安装包。

## Alpha 阶段的边界

- 默认关闭的 AI 侧栏只是布局预览，不是已接入的 AI 对话功能，不发送请求或执行操作。
- 自动化测试、构建和包清单检查不能代替真机通知投递／操作、升级数据保留、WACK 或商店认证。尚未完成的平台验收不应视为已通过。
- 反馈问题时请提供平台、应用版本、复现步骤和必要日志；不要公开完整备份、课表隐私或 API 密钥。
