# Sked v2.3.0-rc.2

## 桌面端

- **浮动面板贴近入口，支持拖动**：日期、时间、星期、课程周次、节次、课表、节次时间方案和颜色选择，以及分类名称表单，靠近点击的控件打开。可从标题拖动，调整窗口或继续输入时保留草稿与位置；关闭重开重新靠近入口。这些选择器和名称表单仍需先完成或取消，才能操作背景；普通菜单不增加拖动标题。
- **选择器更紧凑**：星期改为横向单元，课程周次使用数字网格与全选／单周／双周／清空操作，关联节次直接显示起止时间；课表与节次方案使用紧凑清单。时间选择以输入为主，可切换到滚轮，切换不丢草稿；颜色编辑减少重复预览和卡片。
- **日程重复与提醒就地编辑**：两个字段均打开可拖动的小面板。重复方式、间隔、次数和截止日期在同一面板设置；提醒使用紧凑多选。确认只修改编辑器草稿，最终保存日程时才写入。
- **提醒与当天安排支持悬停预览、独立显示**：鼠标停留在条目上可预览详情，移出后收起；预览无关闭按钮、不可拖动。点击条目或「独立显示」会原地转为可拖动的独立详情，保留正文滚动；点击空白或关闭来源列表不会关闭它，点击其他条目则切换当前详情，不叠加窗口。
- **启动时限时展示应用内提醒**：初始通用日程工作区有提醒且可交互时，自动展示一次列表，默认 10 秒收起。悬停或窗口失焦暂停计时，操作后取消自动收起；手动打开不计时。列表增加状态分组、数量和文字颜色层级。
- **分类管理不再整页跳转**：入口旁的小面板集中显示颜色、名称、事件数量、显隐与更多操作。可直接点击名称重命名、点击颜色编辑；显隐改为轻量图标，不再显示保存进度条。资源栏「＋」直接新建，导入／导出从面板底部进入。管理期间背景日历不可操作。
- **分类颜色支持精细调整**：新增六个主题色槽、连续颜色区、色相与 Hex 输入。确认只更新颜色，不覆盖后来修改的名称、事件或显隐；取消和未修改确认不会把主题色槽固化为 RGB。
- **课程与菜单细节**：改善课程卡片的文字层级、间距与换行，编辑按钮仅在悬停或聚焦时显示；节次与时间标签居中，课程系统提醒方式和颜色模式使用一致的下拉菜单。
- **修复桌面交互问题**：AI 布局预览不再随启动或启用功能自动展开；修复多个提醒／安排列表之间的预览与焦点归属、独立详情操作使用旧数据，以及分类子任务关闭和矮窗操作可达性问题。

## 手机／触控平板

- 修复父页面被移除后，选择任务仍留在屏幕上的问题；失去归属时只关闭该选择器，不关闭上方其他弹窗。

## 手机、平板与桌面共用的改进

- **提醒顺序明确**：按正在进行、即将开始、已结束排列，各组分别按结束时间升序、开始时间升序、结束时间降序排序，同时间条目保持稳定顺序；「已过期」改为「已结束」，不再暗示事项未完成。
- **非法颜色不能保存**：主题种子色、普通颜色、课程文字自定义色和描边色统一校验六位 Hex，允许一个前导 `#` 与首尾空白；错误就地显示，禁止静默保存旧颜色。重复选择当前「自定义」模式不会解除错误状态。
- **保存不误关其他弹窗**：颜色保存完成只结束发起保存的任务，失败保留输入并允许重试。颜色设置与节次时间方案保持原工作区／课表归属，保存期间阻止重复提交、工作区停用及数据替换，过期结果不会写到新任务。
- **重复规则摘要正确显示**：自定义重复间隔超过 30 时不再错误显示为 30，按实际 1–999 间隔展示。

## 升级说明

- 升级前建议导出完整应用备份。相对 RC.1 不新增数据迁移，AppData v4 及课表／日程导入导出格式不变。
- 站外版本需开启「接收预发布更新」才能收到 RC 更新；Microsoft Store 版本由商店管理更新。
- Windows 便携版需解压完整目录后运行。Android 覆盖安装建议沿用相同签名与包类型，从分架构 APK 换用通用 APK 可能被系统判为降级。
- README 的手机和桌面截图仍为旧版，尚未反映 RC.2 的界面变化。
