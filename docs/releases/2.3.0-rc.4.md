# Sked v2.3.0-rc.4

2.3.0 第四个候选版，重点修复课表冲突课程、手机布局与选择器问题，改进设置导航、日历、学校导入及无障碍交互，并减少日程与提醒列表的重复计算。

## 课表与课程

- **冲突课程显示更准确**：修复三门以上课程、包含关系和部分重叠时的显示与切换；相邻但不重叠的课程不再判为冲突，当周课程优先于非本周预览。
- **编辑后同步更新**：冲突详情、课表卡片与当前／下一门课程提示使用一致的课程范围；修改或删除课程、调整节次方案后，及时更新冲突选项并清理失效的显示偏好。
- **点击与切换更可靠**：修复短课程点击范围重叠、切换周次时打开错误周课程，以及切换课表后把编辑结果写入其他课表的问题。
- **课程详情更紧凑**：收紧标题、地点与时间的间距，对齐信息图标和属性列；上课日、时间、周次继续独立呈现，长备注和大字号可正常滚动阅读。
- **选择器布局更稳定**：手机上课日选中项与其他行保持一致高度，勾选标记在右侧居中；收紧课表选择面板，保留同一行的编辑入口。

## 设置、日历与菜单

- **设置导航跟随滚动**：左侧当前分类随设置正文滚动更新，点击分类、缩放窗口和滚动到页面底部时保持定位一致。
- **手机设置布局更统一**：统一标题、状态栏间距和滚动折叠表现；精简课程提醒中的重复说明。
- **菜单与视图切换**：统一弹出菜单、下拉菜单的布局及交互反馈，弹层适应安全区和键盘；通用日程右上角的视图切换默认使用弹出菜单，保留已保存的切换方式。
- **日历与日期选择**：修复月视图选日时的画布跳动，补齐今天标记和选中语义，改善窄屏星期文字、月份标题、日期与教学周标记的显示。
- **主题与文字**：默认主题色调整为灰蓝色，改善主题预览、独立色彩标记、颜色输入提示和窄屏元信息的可读性。

## 导入、性能与无障碍

- **学校导入更易恢复**：配置加载失败可就地重试，校对预览保留编辑内容；学校站点选中状态、表单错误与手机条目操作位置更明确。
- **减少重复计算与重建**：优化月视图、日期导航、日程查询、提醒查询与长列表，以及课程选中、当前课程描边和节次编辑；隐藏列表不再保留键盘焦点。
- **补齐操作反馈**：恢复底部导航按压与悬停反馈，完善颜色控件键盘调整、课程周次与隐私链接的读屏操作，以及提醒列表跨分组焦点顺序。
- **减少动画更一致**：启用减少动画后，加载图形保持静止；改善提醒预览关闭和来源回收时的辅助技术稳定性。

## 升级与验证范围

- 升级前请独立保留完整应用备份和旧版安装包。AppData 顶层保持 **v4**，通用日程格式保持 RC.3 的 **schema 6**；RC.2 不支持此格式的日程及包含它的备份。
- 覆盖安装应保持相同渠道、签名和包类型。Android 通用 APK 与分架构 APK 的版本规则不同；Windows 便携版需解压完整目录。
- 本轮自动化与模拟手机布局验证不能替代 Android 真机覆盖升级、系统通知或 Windows 干净环境验收；相关实际设备验证仍需继续完成。
