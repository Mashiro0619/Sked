# Sked v2.3.0-rc.1

这是 2.3.0 的首个候选发布版。本说明合并了 **Alpha.1 已引入的主要更新与 RC.1 的进一步改进**，从上一正式版直接升级的用户无需先阅读或安装 Alpha.1。

本轮重点是：**自适应双工作区、更灵活的日历视图、更统一的日期与时间选择，以及数据保存和通知可靠性改进。** 已体验 Alpha.1 的用户可直接查看下方“RC.1 相比 Alpha.1 的进一步改进”。

**升级前请先导出完整应用备份。候选版本不等同于正式版，建议保留旧版安装包与升级前备份。**

## 2.3.0 主要更新（包含 Alpha.1）

### 自适应课表与日程工作区

- 学生课表与通用日程采用同等层级的工作区导航。桌面与宽平板通过资源侧栏、课表／日历主区域和详情／编辑面板协同操作，窗口变窄时自动调整，保留浏览位置和编辑草稿。
- 新增“功能管理”，可独立启用或停用课表与日程，至少保留一个工作区。停用时保留数据和配置，并停止对应功能及提醒；只启用一个工作区时不再显示多余的模式切换。
- Windows 顶部操作与窗口控制整合为一行，改善窄窗口和大字体下的布局，修复首次启动页及空课表主页无法拖动窗口的问题。
- 优化手机顶部工具栏、底部导航和系统安全区，恢复课程／日程详情与编辑的底部弹窗，减少重复留白。
- 统一主页、侧栏、面板及弹窗的背景与层级，改善浅色／深色模式的一致性，同时保留用户设置的主题色、课程色和分类色。

### 更灵活、更紧凑的日历

- 通用日程新增 **1–14 天自定义日期范围**，支持跨周、跨月选择、输入起止日期和手机拖选；可按所选天数前后浏览，重启后保留范围设置。
- 自定义范围支持自动／手动最小列宽，空间不足时横向滚动，日期表头、全天栏与时间网格保持对齐。
- 手机月视图改为上方月历、下方当天安排的单一滚动页面，缩减空日程占位，改善农历、大字体和两位数日期显示。
- 优化日／周视图固定表头、全天日程展开、重叠事件分栏与溢出入口，短事件不再为了布局而虚增显示时长。

### 统一日期与时间选择

- 日期选择器支持日历与直接输入；桌面弹层就近锚定操作入口，手机按任务使用紧凑弹窗、跳周菜单或底部范围选择。
- 时间选择支持独立循环的小时／分钟滚轮，同时保留直接输入、24 小时格式和输入校验。
- 课表跳周使用紧凑数字网格，支持滚动与键盘操作，并区分实际当前周和学期外边界周。
- 改善日期高亮、文字居中、窄屏及大字体布局；切换输入方式、旋转或调整窗口时保留选择草稿。

### 设置、编辑与备份

- 设置首页改为分组总览，宽屏保留侧栏索引；可编辑另一工作区的主题而不切换当前工作区。
- 重做节次时间集编辑器，按时间顺序显示起止时间、时长与课间，支持紧凑新增、输入校验及明确的保存／失败状态。
- 分类管理集中展示颜色、事件数量和显隐操作；取消新增不留下占位分类，保存失败保留草稿。
- 课程专属提醒区分沿用默认、关闭和自定义，无效的提前分钟数会明确提示。
- 统一课表／日程导入导出布局，完整应用备份与恢复在设置总览保留唯一入口，并保留工作区启用状态、自定义日期范围和列宽等设置。
- 保存、导入和完整数据替换期间加强重复操作与退出保护；失败时保留可重试内容，数据被完整替换后清退旧编辑会话。

### 数据与通知可靠性

- 加固磁盘保存失败后的回滚及恢复副本隔离，避免失败修改或旧临时副本覆盖较新数据；保存结果无法确认时保护后续写入并明确提示。
- 修复日期导航后列宽设置丢失、保存失败导致无关跳周，以及已确认失败的 API 密钥写入反复阻止 Windows 关窗等问题。
- 修复带 UTC／时区偏移的重复日程漏掉查询范围内首次实例的问题；通知启动超时后可在数据就绪时恢复，排程仅使用已提交的数据。
- 改善 Android／Windows 课程与日程系统提醒，修复重建排程、切换语言、重启或恢复后可能重复投递的问题，保留“稍后提醒”的独立状态。
- 修复通知运行时锁顺序和队列清理可能引起的卡住问题，完善 Windows 重复排程清理。系统提醒仍受权限、电池策略和操作系统限制，不保证所有设备上绝对不漏发或不重复。

### 更新渠道与开发者预览

- 新增“设置 → 关于 → 接收预发布更新”。新安装默认开启，升级保留已有渠道设置；关闭后只接收正式版。
- 更新比较遵循 SemVer，正确区分 Alpha、Beta、RC 和正式版；同版本 RC 升正式版可提示更新。GitHub 更新检查按渠道筛选全部分页，不再以发布时间代替版本顺序。
- 新增独立的 Microsoft Store 打包与身份配置；商店版由 Microsoft Store 管理更新，商店上架与认证另行进行。
- 新增默认关闭的 **AI 侧栏布局预览**，仅展示只读工作区上下文并保留本次消息草稿，**不会发送请求或执行操作，不是已接入的 AI 对话功能**。

## RC.1 相比 Alpha.1 的进一步改进

- 桌面面板支持 **覆盖／并排／自动** 显示，扩大可拖动宽度范围并保留偏好；缩放窗口、切换显示方式和进入编辑器时保持草稿。
- 日程详情、应用内提醒与临时当天安排在覆盖时按内容收缩，并排时保持全高；超长正文可滚动，短面板下方的日历仍可操作。
- 重做桌面月视图，统一日期网格与选中效果；常驻当天安排可见时隐藏重复入口，窄窗口恢复临时安排入口。
- 当天安排将添加操作移至顶部；详情操作更集中，提醒处理后列表、数量与面板高度即时更新。
- 修复面板拉伸和顶部对齐、日期选择器悬停背景溢出、开发者设置导航，以及关闭 AI 布局预览时丢失入口或草稿的问题。

## 安装与更新注意事项

- 应用版本：`2.3.0-rc.1+15`；Android 构建号 15，站外 MSIX 数字版本 2.3.0.15，Store 数字版本 2.3.15.0。
- GitHub 的 Latest 标签与应用更新渠道是两个概念。本版本仍带有 `-rc.1` 后缀；支持新渠道逻辑的客户端只有在开启“接收预发布更新”后才会提示更新。关闭该选项不会因 GitHub 标为 Latest 而改为接收 RC。
- 旧客户端可能使用 GitHub Latest 和旧版比较逻辑，行为与新客户端不同；必要时可手动下载安装。已安装 2.3.0 的新版客户端不会把低于正式版的 RC 当作升级。
- 原生平台数据位于系统应用支持目录。非常旧的 Documents 目录存档不保证自动迁移，跨渠道安装前务必导出备份。
- Windows 便携版需解压完整目录后运行，不能只复制 exe；GitHub 站外包与 Microsoft Store 包身份不同，不保证覆盖安装或自动共享数据。
- 系统通知受权限、电池策略和操作系统限制；自动化排程测试不等于所有设备的横幅、响铃及冷启动点击均已验收。
