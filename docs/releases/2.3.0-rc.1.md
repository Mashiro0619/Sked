# Sked v2.3.0-rc.1

2.3.0 首个候选发布版，重构课表与日程的自适应界面，改进导航、日历、编辑与设置体验，并修复数据保存和通知问题。

> **升级前请先导出完整应用备份。** 本版本为候选版，建议保留升级前备份和旧版安装包。

## 工作区与桌面布局

- 新增「功能管理」，可独立启用或停用课表、日程，至少保留一个工作区。停用保留数据和配置，并停止对应功能与提醒；只启用一个工作区时隐藏多余的切换入口。
- 重构桌面与宽平板布局，通过资源侧栏、课表／日历主区域和详情／编辑面板协同操作，调整窗口时保留浏览位置与编辑草稿。
- 统一两个桌面工作区的侧栏和顶栏响应式规则：宽窗完整侧栏、窄窗图标侧栏、极窄窗隐藏侧栏并保留入口。相同窗口、字号和偏好下，切换工作区或日历视图不再改变导航等级。
- 自动收缩时展开资源改为覆盖式抽屉，不挤压日历、不改写侧栏偏好；拉宽窗口后恢复原偏好。
- 添加课程／日程保留顶栏直接入口，空间不足时缩为加号按钮，不再只能从更多菜单进入。
- 桌面面板支持「覆盖／并排／自动」，扩大可调整宽度范围并保留偏好；切换显示方式或进入编辑器时保持草稿。
- 日程详情、应用内提醒和临时当天安排在覆盖模式下随内容收缩，并排时保持全高；长内容可滚动，短面板下方的日历仍可操作。
- Windows 顶部操作与窗口控制整合为一行，改善窄窗口和大字体布局，修复首次启动页、空课表主页无法拖动窗口的问题。
- 统一主页、侧栏、标题栏、面板和弹窗的背景与层级，改善浅色／深色模式一致性，保留用户选择的主题色、课程色与分类色。

## 手机导航与弹窗

- 将「工作区切换」纳入课表和日程各自的工具栏排序与显示配置。新安装及旧默认配置将工作区、设置收进「更多」，用户可重新排序或移回顶栏。
- 修复隐藏底部导航后无法切换工作区的问题。双工作区启用且底栏隐藏时，工具栏或更多菜单保留切换入口；单工作区或底栏可见时不再重复显示。
- 工作区在顶栏时通过一个按钮打开切换菜单，进入更多后直接列出两个工作区，不再嵌套。统一勾选、圆角与交互底纹，移除日程分类的重复入口。
- 设置与必要的工作区入口不受隐藏更多菜单影响，空课表也遵循同一配置和入口保留规则。
- 修复手机整周日程布局，将首页顶部操作合并为一行，减少重复留白；优化底部导航的选中状态、图标位置和系统安全区。
- 恢复课程／日程详情与编辑的底部弹窗，改善课表相关弹窗高度及键盘避让，保留滚动内容、编辑草稿和底部操作。

## 日历视图

- 日程新增 **1–14 天自定义日期范围**，支持跨周、跨月选择、输入起止日期和手机拖选；可按范围天数前后浏览，重启后保留设置。
- 自定义范围支持自动／手动最小列宽，空间充足时等宽铺满，不足时横向滚动；日期表头、全天栏与时间网格保持对齐。
- 重做桌面月视图，统一日期网格与选中效果。常驻当天安排可见时隐藏重复入口，窄窗口恢复临时安排入口。
- 手机月视图改为上方月历、下方当天安排的单一滚动页面，缩减空日程占位，改善农历、大字体和两位数日期显示。
- 优化日／周视图固定表头、全天事件展开、重叠事件分栏与溢出入口，短事件不再为适应布局而虚增显示时长。
- 当天安排将日期与添加操作集中到顶部；日程详情集中展示编辑、复制、提醒处理和删除操作，处理提醒后即时更新列表、数量与面板高度。

## 日期与时间选择

- 统一日、周、月导航和表单中的日期选择体验，支持日历与直接输入；桌面弹层就近锚定入口，手机按任务使用紧凑弹窗、跳周菜单或底部范围选择。
- 时间选择采用独立循环的小时／分钟滚轮，保留直接输入、24 小时格式与输入校验；窄屏、大字体和键盘弹出时自适应调整操作区。
- 课表跳周改为紧凑数字网格，打开时定位选中周，支持滚动与键盘操作，区分实际当前周和学期外边界周。
- 统一日期高亮与数字居中，修复日期裁切、月份／年份层过宽、重复标题和悬停底纹溢出；切换输入方式、旋转或调整窗口时保留选择草稿。

## 设置、编辑与备份

- 设置首页改为分组总览，按已启用工作区展示相关选项，宽屏保留分组索引，详细选项进入独立页面。
- 设置、主题和提醒控件统一为连接式分组，优化图标、当前值和说明层级；选项菜单锚定当前值，修复菜单关闭后的焦点问题。
- 外观设置可编辑另一工作区的主题而不切换当前工作区；语言设置保留搜索页面和搜索状态，保存期间保护返回操作。
- 重做节次时间集编辑器，按时间顺序展示节次、起止时间、时长与课间，支持紧凑新增、时间校验和明确的保存／失败状态；增删及调整窗口时保留列表位置。
- 分类管理集中展示颜色、事件数量、显隐和操作。取消新增不留下占位分类，重命名或保存失败时保留草稿。
- 课程专属提醒收进编辑器「更多」，区分沿用默认、关闭和自定义；无效的提前分钟数明确提示，不再静默退回默认值。
- 统一课表／日程导入导出页面，改善窄屏与大字体布局，移除空课表重复标题、宽屏设置重复返回按钮及重复备份入口。
- 完整应用备份保留工作区启用状态、自定义日期范围、列宽及工具栏配置；修复存储恢复提示出现时的标题栏对齐。
- 统一设置总览和「关于」页进入开发者模式的导航，宽屏保留设置侧栏，窄屏保留正常返回入口。

## 数据保存与提醒修复

- 加固磁盘保存失败后的回滚与恢复副本隔离，避免失败修改或旧临时副本覆盖较新数据；结果无法确认时明确提示并保护后续写入。
- 修复日期导航或清除自定义范围后列宽设置丢失的问题；修复课表保存失败、删除非活动课表时发生无关跳周的问题。
- 修复已确认失败的 API 密钥写入反复阻止 Windows 关窗或停用课表的问题；写入结果仍未知时继续校验。
- 加强保存、导入与完整数据替换期间的重复操作和退出保护；失败后保留可重试内容，完整替换后清退旧编辑会话。
- 严格校验日程结束时间及节次输入，避免无效时间被静默修正后保存。
- 修复带 UTC／时区偏移的重复日程在部分时区漏掉查询范围内首次实例的问题，保留既有 ICS 导入行为。
- 通知启动超时后可在数据就绪时恢复，排程仅使用已提交的数据。
- 修复重建排程、切换语言、重启或恢复后可能重复投递的问题，限制补发条件并保留「稍后提醒」的独立状态。
- 修复通知锁顺序与队列清理引发的卡住问题，完善 Windows 待处理通知识别与重复排程清理。

## 更新与平台支持

- 新增「设置 → 关于 → 接收预发布更新」。新安装默认开启，已有渠道偏好保留，关闭后只接收正式版。
- 更新比较遵循 SemVer，正确区分 Alpha、Beta、RC 和正式版，按数值比较数字后缀，同版本 RC 升正式版可提示更新。
- GitHub 更新检查按渠道筛选全部分页，不再以发布时间代替版本顺序；支持自定义更新源的正式版／预发布列表，排除草稿发布。
- 更新检测与版本显示优先读取 Flutter 完整版本，避免 iOS／macOS 原生版本字段丢失预发布后缀。
- 新增 Microsoft Store 专用 MSIX 打包与身份配置，兼容预发布版本；商店版由 Microsoft Store 管理更新，上架与认证另行进行。

## 开发者预览

- 新增默认关闭的 **AI 侧栏布局预览**，仅展示只读工作区上下文并保留本次消息草稿，**不会发送请求、执行操作或修改数据，不是已接入的 AI 对话功能**。
- 关闭预览面板时保留顶部入口和消息草稿，启用／禁用由开发者模式中的功能开关控制。

## 升级注意事项

- 完整应用数据升级至 **AppData v4**，一次性迁移手机工具栏配置：旧默认采用新布局，自定义顺序、显示状态和普通隐藏策略保留，后续不反复重置。独立课表／日程导入导出格式不变。
- **旧版不支持 v4 完整数据，降级请使用升级前备份。** 跨渠道安装前同样建议导出备份，不保证自动共享数据。
- Windows 便携版需解压完整目录后运行，不能只复制 exe；Microsoft Store 包与 GitHub 站外包身份不同。
- 系统提醒仍受通知权限、电池策略及操作系统限制。
