# Sked v2.3.0

2.3.0 是面向所有用户的正式版。本说明以 **上一正式版 2.1.1 → 2.3.0** 为范围，汇总 Alpha.1、RC.1–RC.4 以及候选版之后的改进，按正式版的最终行为整理。

从 2.1.1 升级的用户可阅读下方完整变化；已经使用 RC.4 的用户可先看「相对 RC.4 的主要变化」。各阶段原始说明保留在文末，预发布期间调整过的默认值以本篇为准。

## 工作区、导航与桌面布局

- **按需启用课表和日程**：首次启动可选择「仅课表」「仅日程」或「两者」，之后在功能管理中调整，至少保留一个工作区。停用保留数据和配置，并停止对应功能与提醒；只启用一个工作区时隐藏多余的切换入口。
- **统一自适应导航**：桌面与宽平板使用资源侧栏、课表／日历和详情／编辑区域。窗口变窄时依次调整为图标侧栏或入口菜单，同一窗口下切换工作区、切换日历视图不再无关改变导航等级。临时展开资源使用覆盖式抽屉，拉宽后恢复侧栏偏好。
- **面板显示方式可选**：支持「覆盖／并排／自动」，按可用空间展示编辑器、详情、提醒与当天安排。短内容按需收缩，长内容保留滚动；切换布局、调整窗口或进入子任务时保留草稿和浏览位置。
- **区域尺寸可调整并记住**：资源栏、安排栏、设置导航、主题与导入预览、学校站点分栏可拖拽调宽，月历议程和全天日程区域可调整尺寸。手动尺寸保存在本机，重启后恢复，并适应窄窗和大字号。
- **浮窗可拖动、缩放**：课程／日程编辑、详情、提醒和分类等面板支持适用的边缘缩放与键盘尺寸调整；正文滚动条不与缩放操作争用。编辑器打开期间仍可从应用顶栏空白处移动窗口。
- **手机工具栏可配置**：课表和日程分别保存工具栏顺序与显示方式，工作区切换和设置可收进「更多」或移回顶栏。隐藏底部导航时仍保留必要的切换入口；只有一个工作区或底栏已经可见时，减少重复入口。
- **手机布局与底部弹窗**：精简顶部操作，恢复课程／日程详情和编辑的底部弹窗，改善底部导航、安全区、横屏键盘和大字号适配。拖拽关闭弹窗仍遵守草稿确认及保存期间的退出保护。
- **Windows 窗口行为**：顶部操作与窗口控制整合为一行；记住位置、大小和最大化状态，再次启动时激活已有窗口。修复首次启动、空课表和编辑器打开时的窗口拖动问题。

## 课表、课程与节次

- **重做课表日视图**：按课程议程展示当天安排，突出时间、地点、课程顺序与状态。当天无课时显示学期内下一节实际课程，并跳过本机时区中不存在的日期。
- **冲突课程更准确**：修复多门课程完整／部分重叠、包含关系与非本周预览的优先级；相邻但不重叠的课程不再判为冲突。详情、卡片和当前／下一课程提示保持一致，编辑、删除或调整节次方案后及时更新冲突选项。
- **修复点击与周次归属**：短课程保留有效点击入口，翻周或切换课表后不会打开错误课程或把编辑结果写入其他课表；学期外不再高亮当前／下一课程。
- **课程信息更易阅读**：非本周课程保留色相并显示明确状态，短节次按可用高度排列内容；窄格中的拉丁文字按单词换行或省略。课程详情收紧重复留白，时间、上课日和周次保持独立，长备注与大字号可滚动阅读。
- **课表键盘操作**：方向键用于控件焦点移动，PageUp / PageDown 用于上一周／下一周，避免操作表单和选择器时意外翻周。
- **节次时间集重新整理**：按时间顺序展示节次、起止时间、时长和课间，区分课表绑定与共享资源管理。没有时间集时可直接新建，正在使用的方案不能删除；切换、返回和保存失败时保留必要确认与草稿。
- **学期与时间边界**：缩短学期或导入包含学期外明确周次的课程时先说明影响，并保留原周次；缺少有效开学日期时先确认再导入。修复折叠空闲时段后的自定义时间偏移，以及节次自动生成、规范化越过当天范围的问题。

## 日历、重复日程与当天安排

- **新增 1–14 天自定义范围**：支持跨周、跨月选择、输入起止日期和手机拖选，可按所选天数前后浏览，重启后保留范围。最小列宽可自动或手动设置，宽度不足时横向滚动，表头、全天栏与时间网格保持对齐。
- **重做月历与时间轴**：桌面月历与侧边当天安排协同展示；手机月历采用上方月历、下方安排的单页滚动。月视图、周视图与侧栏统一从周一开始，修复选日画布跳动，改善今天标记、月份标题、农历和教学周显示。
- **保留日程的实际时长**：优化固定表头、全天事件展开、重叠事件分栏与溢出入口，短日程不再为撑满卡片而虚增显示时长；窄窗口、跨年范围和大字号下保留日期端点与完整语义。
- **明确重复日程的编辑范围**：可选择「仅本次」「本次及以后」或「整个系列」。单次修改与拆分后的系列独立保存，范围外的实例和已处理提醒保持原状；从旧详情执行操作时读取最新数据。
- **重复规则与日期边界**：编辑导入规则时保留实际重复间隔，修改间隔前说明对例外日期与已处理提醒的影响，保留仍然匹配的例外。修复月末、夏令时、缺失午夜／日期以及 UTC／带偏移时间下的实例遗漏与定位问题。
- **提醒可单独设置**：日程支持「跟随默认」「关闭」「自定义」；旧记录保留原有提醒含义，调整全局默认不会覆盖正在编辑的自定义草稿。「隐藏日程分类后仍提醒」默认关闭，可单独决定隐藏分类的应用内提醒和系统通知是否继续。
- **详情可预览或独立显示**：在提醒和当天安排中悬停可预览日程，点击后转为可拖动的独立详情，保留正文滚动。关闭来源列表不会关闭独立详情；编辑、复制、处理和删除使用当前数据，失败或取消后保留可继续操作的状态。

## 编辑器、选择器与设置

- **编辑表单更紧凑**：突出课程／日程标题，按空间排列地点、分类、日期、时间、周次与节次；教师、学分、备注、自定义字段、颜色或提醒等补充内容按任务收进「更多」。统一标题、滚动正文与底部操作区，保留可见的焦点、错误和保存反馈。
- **选择器贴近操作入口**：桌面的日期、时间、星期、课程周次、节次、课表、时间方案和颜色选择器就近打开，适用面板可从标题拖动；普通菜单保持简洁。旋转、调整窗口或切换输入方式时保留选择草稿。
- **日期与时间可直接输入**：日期选择支持日历与输入模式。桌面时间选择以输入为主，可切换小时／分钟滚轮；手机保留适用的滚轮与输入方式。星期使用紧凑排列，课程周次支持数字网格、全选、单周、双周与清空。
- **分类与颜色就地管理**：分类面板集中展示名称、颜色、事件数量、显隐和操作，可直接重命名或调整颜色。颜色支持主题色槽、连续选择、色相和 Hex 输入；非法值明确报错，取消不创建占位项，颜色保存不覆盖后来修改的名称、事件或显隐。
- **设置按功能分组**：优先显示已启用工作区的选项，详细设置进入独立页面。桌面分类高亮跟随正文滚动，修复点击定位、页面底部和缩放后的同步；语言页保留搜索状态，修复带搜索区域的紧凑顶部栏高度。
- **主题偏好独立保留**：可在外观页编辑另一工作区的主题而不切换当前工作区。新安装默认跟随系统明暗，使用灰蓝主题种子和多彩课程配色；已有主题、不同课程的相同自选颜色及各工作区偏好继续保留。
- **菜单与视图切换**：统一菜单、下拉选项和选择反馈，适应安全区与键盘。日程视图切换默认使用弹出菜单，已有循环切换设置保留；移除重复入口和在当前桌面布局中不生效的选项。

## 应用内提醒与系统通知

- **启动提醒有明确收起规则**：桌面启动时，初始日程工作区可交互且有未处理提醒，会自动展示一次，10 秒后收起；空列表、非初始工作区或忙碌场景跳过，不延后补弹。悬停或窗口失焦暂停计时，用户操作后取消自动收起，手动打开不计时。列表按状态分组，处理后同步更新数量与空态。
- **提前提醒查询更完整**：查询覆盖当前配置的有效提前量，修复只查看未来 24 小时事件造成的遗漏；长列表分页展示。修复超大提前量、跨缺失日期的索引顺序与实例定位问题。
- **Android 权限与恢复**：开启系统提醒时说明通知和精确闹钟权限，受阻时显示状态与修复入口；权限恢复后重新安排未来提醒，后台恢复可以重建仍有效的闹钟。
- **电池限制改为可靠性提示**：电池优化限制会提示可能影响投递，不再直接阻断具备必要权限的排程。通知与精确闹钟权限仍是必要条件，系统投递仍受厂商后台策略影响。
- **减少重复投递与错误补发**：修复重建排程、切换语言、重启和恢复后的重复通知；稍后提醒只重新安排被操作的那条记录。后台任务完成后再收尾，失败重试有上限，避免排程与保存流程卡住。
- **Windows 通知更一致**：按触发时间安排通知并保留有效卡片，点击正文进入对应日程；通知设置说明直接排程的范围、容量与状态。普通便携版仍受 Windows 对历史通知卡片读取／取消能力的限制。
- **隐私选项更明确**：「通知中显示标题」明确适用于普通通知及锁屏，默认关闭；受权限或工作区状态限制的提醒显示相应状态与修复入口。

## 导入、备份、隐私与数据保存

- **免配置开始导入**：未配置解析接口时提供 JSON 文件导入和手动添加指引；解析原文默认收在「解析详情」，可复制完整内容或进入「编辑 JSON」。校对表单与 JSON 保持同步，保存失败保留草稿和重试入口。
- **导入前报告问题**：学校站点配置加载失败可就地重试；文件、模型条数和文本编码有独立校验，超大文件、超限记录或非法 UTF-8 不会静默部分保存。明确周次保留原义，不会因异常输入被误当成每周上课。
- **ICS 重复规则更完整**：改善重复次数、UNTIL 截止时刻、等价规则、年度重复、例外日期，以及按原始 UID 合并改期／取消实例；接受 UTC 别名与本机一致的命名时区。无法完整表示的规则、时区、闰日和月末差异在应用前列入报告，由用户确认。
- **ICS 往返更稳定**：规范化换行与折行，避免重复导入时向备注追加日历名称。日程 JSON 保留提醒策略与月末重复日期；ICS 用于日历交换，不携带 Sked 的提醒设置。
- **备份与恢复分清作用**：导出备份不会替换当前数据；执行恢复前明确说明将替换的内容、保留的本机解析接口地址、模型与提示词。API 密钥不进入普通备份，恢复后需要重新填写。
- **恢复和保存有保护**：恢复期间显示进度并暂停并发修改；保存、导入或返回只作用于发起任务，不误关后来打开的页面，不把旧结果写入其他课表。失败后保留可重试内容，结果仍无法确认时保护后续写入。
- **保留已有数据的含义**：只编辑课程名称等字段时，未修改的多行、数字、布尔及嵌套自定义字段保留原类型。加固磁盘失败回滚和恢复副本隔离，避免失败修改或旧临时副本覆盖较新存档。
- **学校网页会话可清理**：新增退出网页登录入口，清除应用数据时同步清理学校网页会话。已保存解析密钥时，更换接口地址需要确认；解析失败不直接展示异常原文，导入错误使用可读提示。
- **Android 设备间迁移**：在系统支持的设备间迁移中，通过受控数据工件转移课表、日程和普通设置，排除解析密钥、学校登录会话及设备绑定的通知记录。

## 更新、性能与无障碍

- **每次启动检查一次更新**：完成隐私同意和首次引导后自动检查；编辑、查看详情、其他弹窗打开或应用失焦时只更新设置中的版本标记，启动检查失败保持安静。手动检查可查看错误并重试。
- **更新提示可读、可重试**：弹窗展示完整版本、预发布状态与 Markdown 日志，长内容独立滚动；检查、打开入口或忽略操作失败后保留恢复入口。所有分发渠道使用相同版本筛选，按钮按安装来源打开 GitHub、Google Play 或 Microsoft Store。
- **正式版默认只接收正式更新**：新安装的 2.3.0 默认关闭「接收预发布更新」，已有选择继续保留。Alpha、Beta、RC 与正式版按 SemVer 顺序比较，同版本 RC 可升级到正式版；忽略某个 RC 不会连带忽略后续 RC 或正式版。商店版本可能晚于 GitHub，开启预发布选项不等于加入商店测试渠道。
- **减少重复计算与写盘**：复用月历、日期导航、未变化日程的展开结果和提醒索引，长列表按可见内容构建，减少无关重建与重排；合并适用的连续偏好保存，同时保留数据替换与事务边界。原生端将存档编解码和导入预处理放到后台处理。
- **键盘、读屏与大字号**：补齐课程、日期、周次、提醒状态和操作名称，改善焦点顺序、可见焦点、触控目标和文字对比度；隐藏列表不再保留键盘焦点。修复窄窗与大字号溢出，减少动态效果设置同时作用于翻页和加载图形。
- **本地化修正**：修正月份、星期、动作、课表／日程术语、计数短语及通知文案，缺少的译文按当前模板回退。资源检查通过不等同所有语言均完成人工校对。
- **开发者布局预览**：提供默认关闭的 AI 侧栏布局预览，仅展示只读上下文和本次草稿，不发送请求、不执行操作，不是已接入的 AI 对话功能。

## 相对 RC.4 的主要变化

RC.4 用户已经具有上文中的自适应面板、拖动缩放、悬停详情、重复实例编辑等能力。本次正式版继续补充：

- 课表日视图改为课程议程，无课时展示学期内下一节课；完善非本周颜色与状态、短节次排版、完整日期标题及翻周快捷键。
- 新安装默认跟随系统明暗、使用多彩课程配色，并按正式版关闭预发布更新；已有选择保留。
- 导入增加免配置指引、折叠解析详情与明确的 JSON 编辑入口；补齐开学日期确认、文件／条数限制和 ICS 应用前完整报告。
- 备份恢复保留本机解析配置，学校网页支持退出登录和会话清理，Android 增加受控设备间数据迁移。
- Android 提醒补齐权限恢复、稍后提醒隔离与后台收尾；电池限制改为提示。Windows 增加窗口状态恢复、再次启动激活、通知正文导航及排程范围说明。
- 继续修复保存归属、重复规则间隔与例外日期、设置顶部栏及列表空态，并完善提醒索引、日程展开复用、偏好写盘、无障碍和本地化。

## 升级与回退

- **从 2.1.1 升级**：完整应用数据从 AppData v2 迁移到 v4，通用日程从 schema 4 升到 6。内置迁移会处理工作区启用状态与手机工具栏配置；旧默认采用新布局，自定义顺序和普通显示偏好保留，正常升级无需先清空数据。
- **从预发布版升级**：RC.1／RC.2 已使用 AppData v4，RC.3／RC.4 已使用日程 schema 6；从 RC.3／RC.4 升级时，这两个格式版本保持不变。RC.2 及更早版本无法读取新版日程及包含它的备份。
- **回退前保留旧备份**：升级前独立保留完整应用备份和旧版安装包。需要降级时使用升级前备份，并另存新版期间新增的数据；不要让旧版直接覆盖新版存档。
- **备份不等同完整复制本机环境**：API 密钥需重新填写；恢复保留本机解析接口地址、模型与提示词，桌面区域尺寸仅保存在本机。ICS 不交换提醒设置，完整迁移请使用应用备份。
- **覆盖安装保持渠道与包类型**：Android 沿用相同应用 ID、签名、渠道和 APK 类型；通用 APK 与分架构 APK 的原生构建号规则不同。Windows 便携版需解压完整目录，Microsoft Store 版与站外版身份不同，不保证直接覆盖或自动迁移。
