# 使用逻辑与数据兼容

## 内置 Agent 与会话

Sked 只有一个应用级 Agent。多个会话分别保留消息、输入草稿和运行状态，共用连接、统一指令、运行预算及内置 Skills；新建会话不会创建另一个 Agent。功能管理中的 Agent 开关控制正式入口：手机、平板和桌面都从侧边导航进入完整聊天。切换工作区、调整窗口或关闭聊天不会改变运行所有权。关闭功能会停止新请求和未提交步骤，保留连接与会话，并核对已经接受的写入。

新装默认显示 Agent 入口。原有本机数据升级到 AppData 版本 6 时进行一次开启迁移，保留原连接和权限；此后用户关闭会被保存，不因重启或恢复旧便携备份再次开启。默认执行策略仍为每次修改前询问。打开聊天或 Agent 设置时才初始化会话侧存储，默认开启本身不读取全部历史，也不发送模型请求。尚未打开聊天时不加载会话，也不运行聊天加载动画。

权限由用户在宿主界面选择，工具参数、模型回复和网页材料不能改权限或代替确认。

| 模式 | 行为 |
| --- | --- |
| 只读计划 | 查询、分析和准备变更；不提交业务修改、文件写出或系统操作。正常会话记录仍可保存。 |
| 每次修改前询问 | 展示本次明确目标及变化，确认只适用于该计划。准备内容或目标过期后重新生成计划，不沿用旧确认。 |
| 完全权限 | 在字段、引用、版本和存储校验通过后连续执行，包括明确的删除、恢复和清空；系统原生授权仍需由系统提供。 |

资源查询可以覆盖非当前课表、隐藏分类和停用工作区；修改这些资源不隐式切换或启用工作区，也不绕过其提醒开关。批量操作保存完整目标集合，分页只改变展示范围；目标或数据版本变化后旧计划失效。保存状态以业务回执为准，已保存、外部效果未完成和结果未知分别显示。撤销是一次新的受版本保护操作，不能用旧全库快照覆盖之后的手动编辑。

课程冲突显示选择先读取指定课表、指定周的实际完整冲突组，只能选该周允许置顶的课程；部分重叠和非本周预览不能取代正在展示的本周课程。重置同时清除同一组的旧格式选择。日程自定义范围接受 1970-01-01 至 2100-01-01 内连续 1–14 个自然日（包含首尾），焦点在范围内时保持，否则移到首日；取消范围时，隐藏周末的周末焦点回到同周周五。两类偏好都通过主数据计划提交并支持撤销，可修改停用工作区，无需切换页面。

运行中可以停止、追加待处理输入或调整接下来的要求。停止阻止后续步骤，已经进入保存或外部执行的动作继续核对结果。重启后中断的运行不会自动重放；继续前先核对已有回执，结果未知时保留待处理状态。用户确认过的连接目的地改变后，旧会话不会自动发送到新地址。

会话支持改名、归档、恢复、导出和删除。删除运行中会话会停止新步骤并终止该会话的写入身份；在途已经接受的业务操作仍可能完成，其最小操作回执由业务层保留。删除聊天不会撤销已保存的课表或日程。默认保留会话，保留天数为 0 表示不自动清理；配置 7–3650 天后，只清理已完成、无输入草稿、无活动运行及排队输入的过期会话。上下文可以使用有界摘要，原消息仍保留在本地，不能把摘要当作业务数据来源。选择性备份可以显式加入聊天及附件；旧完整 JSON 不包含聊天，所有便携导出均排除密钥。会话导出仍可单独使用。

设置总览提供独立 Agent 设置，关闭功能后仍可管理连接和偏好；功能管理仅保留开关。各布局的完整聊天共用会话、草稿和运行，同一应用不重复打开聊天路由。返回工作区后再次进入会恢复草稿和阅读位置；运行中关闭页面不停止请求。聊天支持 Markdown、代码及消息复制、历史搜索和稳定阅读位置，详见[对话界面](AGENT_CHAT_DESIGN.md)。

聊天初始化失败时仍可返回工作区或打开设置，原记录保留。界面只提供安全的失败阶段说明；重试重新核对主存储、会话和连接，并完成保留时间清理后才开放运行。不支持的未发布 Agent 配置保持严格拒绝，不自动转成其他强度或新建空库覆盖原件。

Skills 和记忆可在独立 Agent 设置中编辑，也可由会话工具按当前权限维护；内置技能修改形成可恢复覆盖，当前运行保留已加载版本。知识正文、版本和条件逆操作由独立仓储保存，维护或存储失败时阻止继续写入。详见[共享知识](AGENT_KNOWLEDGE.md)。

聊天支持任意类型的本地二进制附件及仅附件消息；文件先保存并核验，再按当前 API 的原生内容块发送。不支持或发送失败时保留原消息和文件，显式继续不会重复追加消息；历史附件需用户重新附加，来源路径不进入聊天。详见[附件存储与协议](AGENT_ATTACHMENTS.md)。

纯文字回复可以重新生成并保留原文与新版本，该过程不提供执行工具，也不重新操作业务数据。具有完整宿主轮次记录的用户消息可以编辑并重做：先预检该轮次及其后本会话的全部逆变更，再撤销并只执行选中的新请求；手动修改和其他会话不回滚。冲突、不可逆、缺回执或超预算时整段不开始，编辑草稿保留。旧消息与附件进入历史版本，查看历史不改变当前上下文。中断后继续同一批次，启动与存储重试只恢复已接受的撤销，不自动调用模型；旧审批和排队输入不再执行。详见[历史与回复版本](AGENT_HISTORY.md)。

设置中的备份按对象选择课表、分类、学校站点、Skills、记忆和聊天，应用偏好与 Agent 配置按组选择，聊天文件可独立勾选。设备面板尺寸和开发者预览偏好需按平台分组选择，不支持的分组在预览中标明并保留本机设置。保存和分享生成包含清单与所选二进制的 ZIP；旧 JSON 文件或文本也进入同一选择恢复。选中对象按稳定 ID 替换原位置或新增，未选对象保留，必要的冲突依赖只复制并重绑所选对象。恢复聊天只保留历史，不恢复运行、审批和队列。详见[选择性备份](SELECTIVE_BACKUP.md)。

## Agent 连接与诊断

连接设置支持兼容 Chat Completions 和 Responses 的 API。基础地址与完整请求地址共用解析规则；自选模型并不保证该服务支持全部协议字段或工具调用。统一指令、轮次、工具数和 token 预算作用于新运行；在途请求固定使用开始时的连接和凭据快照。

密钥通过安全输入交给宿主，普通设置、聊天、工具参数和备份不保存原文。模型请求输入密钥时只获得绑定当前运行与目的地的短期句柄；更换目的地必须替换或清除旧凭据，不能把旧密钥直接带过去。原生平台使用安全存储，Web 兼容实现只在当前进程内存中保存密钥，刷新后需重新输入。

测试连接只发送合成的小请求，不发送当前课表或聊天；成功响应与观察到工具调用是两个独立结果。获取模型列表只接受同一 API 来源的目录地址，显示提供商返回的模型 ID；返回不完整时明确标注，不能据此推断账号一定可调用每个模型。诊断不会在打开设置时自动联网，模型发起的诊断也要经过当前模式的具体操作门禁。

HTTP 会明文传输内容和密钥。普通 Agent 运行在询问或只读计划模式下请求独立的传输确认，完全权限模式按该模式执行；传输同意不授予业务修改权限，计划模式仍不能写数据。显式同意仅在当前运行时内复用于相同端点、协议、模型和凭据快照；关闭功能或更换连接后失效，完全权限的自动放行不生成这份同意。设置页的人工诊断在已保存的 HTTP 连接旁显示风险提示，用户点击测试或获取模型按钮只授权该次人工请求。无论模式如何，敏感请求都不自动跟随重定向。

旧学校解析地址和凭据仅在新的连接字段尚未配置时迁移，单独修改统一指令或预算不会阻止迁移。旧模型 ID 保留为待配置候选，用户明确选择具体强度后才启用，不生成自动档位。旧密钥只有在同一目的地的新安全存储写入并读回成功后才退役，失败保留恢复材料；连接迁移不改变功能开关或权限。旧专用提示词保留为兼容材料，不自动变成统一指令或 Skill。

## 会话附件

会话输入区允许选择任意类型的本地文件，每份最多 32 MB、每条消息最多 20 份。文件先复制到应用自己的二进制存储并核验，聊天只保存元数据和引用；支持仅附件消息。当前模型请求的文件合计最多 48 MB，编码预算与文字上下文分开。

添加附件只保存本地草稿，用户发送或加入待处理输入后才进入正常运行和权限流程。协议无法表达该类型、服务拒绝或本地文件损坏时保留附件并说明真实原因，不自动换模型或只发送文件名。当前请求的文件在工具往返中完整保留；旧消息文件可显式重新附加。

保存引用失败后可以复用已经核验的文件重试，重新核验期间仍可取消；没有成功发布引用的临时重试缓冲不承诺跨进程恢复。会话、消息边界或数据世代变化后，旧待保存项不能写入新上下文。移除草稿引用保留仍由历史使用的字节，删除最后一个引用后才回收文件。详见[附件存储与协议](AGENT_ATTACHMENTS.md)和[正式聊天入口回归](../test/agent/ui/agent_binary_attachment_view_test.dart)。

## 设置、资源与对象

开发者样例和 Agent 的 `developer.sample.prepare` 共用正式主页绑定的追加命令。准备不写数据，接受后只向已启用工作区追加样例；已有对象保持原内容，停用工作区保持原样，同一操作重试不会追加第二批。实际工具调用及存储读回见[应用宿主回归](../test/agent/ui/agent_application_host_test.dart)。

设置保存跨对象的使用偏好。课表绑定的节次时间集在编辑课表或导入时选择；课表菜单中的“管理节次时间集”维护共享资源，不改变任何课表绑定。共享时间集仍独立自动保存，取消外层选择只放弃绑定草稿。

课表主页的日期标题与课表名称使用 `onSurface` 和明确字重，选中资源与主要操作继续使用原强调色。触屏工具栏先为周次留出空间，再让长课表名称收缩；名称已缩至最低尺寸后，过长的周次完整换行，最低操作尺寸仍放不下时沿用横向滚动。名称截断不裁掉完整读屏文本，可通过提示或原课表选择器查看；日期控件的完整语义包含周次与起止日期，点击跳周、长按回到本周保持。桌面宽栏和紧凑栏使用一致的日期标题层级，紧凑栏仍按可用空间显示完整日期、短周次或日期图标，完整信息保留在提示和选择器入口中。

Agent 开启时，入口位于侧边导航的工作区目的地之后、资源分区之前；桌面展开／折叠侧栏和平板导航栏均可进入。手机课表与日程主页保留导航按钮，打开现有侧抽屉，底部工作区切换栏继续保留。空课表、单工作区或隐藏工作区导航时也能进入；维护及导航忙碌时沿用交互门禁。关闭 Agent 后隐藏该项，工具栏和“更多”菜单不重复提供入口。

日程主页继续以日期为主标题，使用 `onSurface` 和明确字重；日历分类保持次级筛选，选中项与主要操作沿用强调色。手机先省略同年范围中的重复年份，再让长分类名称收缩，为日期保留空间；仍放不下的范围按起止端点换行，跨年保留两端年份。每个端点与操作的最低宽度仍不足时沿用横向滚动，不截掉范围末日，也不缩小字号。日期的完整读屏文本和提示始终包含起止日期，点击原日期选择器、触屏长按回到今天以及工具栏顺序和隐藏偏好保持；桌面紧凑栏继续按空间选择完整日期、短日期或带完整语义的日期图标。

平板等非紧凑触屏分支也按完整端点分配日期的最低宽度；上一段、下一段和今天快捷按钮只在保留该宽度后仍放得下时显示，今天快捷按钮未显示时仍可长按日期标题回到今天。两行工具栏与自定义顺序继续沿用原布局，所需宽度不足时可横向滚动。600dp 布局切换不会重新把跨年范围截成一行，日期格式偏好与完整起止日期语义保持。

自动添加节次保留已有起止时间，并使用可用的默认时段或延续最近节次的时长与间隔；不能越过当天23:59。当日无法容纳完整的新节次时提示先调整已有时间，保留原列表和存档，不缩短新节次或回退到早晨。生成器与保存规范化检查收到的节次均在当天内、结束晚于开始且按顺序不重叠；无效输入报错，不静默重排或改成08:00。

短节次和放大字号不改变课表的时间比例。时间轨按实际可用高度显示编号与起止时间、仅显示编号，或隐藏放不下的标签；辅助技术始终能读取完整编号与起止时间。显示取舍不修改保存的节次时间。

没有时间集时仍可进入管理并新建；正在被课表使用的时间集不能删除。没有有效绑定时不能保存课表。JSON 导入缺少作息时要求选择已有或新建的时间集；覆盖导入展示并固定目标课表，目标失效时中止，不改写另一张当前课表。

节次时间集管理只保留一个顶栏和返回入口，单个时间集的菜单位于名称与保存状态旁。宽屏返回等待当前编辑保存后退出管理；窄窗先返回时间集列表，再退出管理。切换时间集会等待保存或退出确认，取消保留原草稿，重试或放弃后继续打开原先点击的目标。调整窗口不重建编辑器；已删除的时间集不继续显示可编辑内容。模板文字导入使用独立页面，返回仍保留原编辑器。

课程编辑按所属课表 ID 和课程 ID 读取最新数据。课间折叠仅影响布局。已有有效起止时间优先；旧课程没有有效分钟数时，网格、详情、正在上课和提醒按关联节次解析。只修改标题等字段不会把推导时间固化。课程周次必须至少选择一周，空选不能提交。

日视图在选中日没有可显示课程时，提供图标、说明和下一节真实课程的日期、时间与名称；没有后续课程则明确说明。从选中日期的次日开始搜索当前课表，范围限于第一周周一到最后一周周日；不改用今天、不限定只看明天，也不回绕至学期开始。沿用旧课程空周次表示每周、有效时间优先、节次回填及冲突显示选择；非本周预览不会成为下一节实际课程。先查找候选日期，再按已有周投影解析对应课程。

如果本地时区跳过了整个民用日期，下一节提示跳过该次不存在的上课日期，并继续检查该课程后续周次与其他课程；不会把系统归一化后的另一日期当作该次上课。只有午夜时刻缺失、同一天仍存在时，仍保留当天的课程候选。此规则只用于下一节提示，不改写保存的周次、课程或日程重复规则。

主页空态不重复绘制添加按钮，继续使用手机悬浮按钮或桌面工具栏入口；隐藏偏好、不可交互状态和所选星期的编辑预填继续生效。独立使用日视图组件时仍可选择提供空态添加入口。空态内容可滚动，较长课程名与大字日期完整换行，不恢复课程卡左侧装饰色条。

尚未创建课表时，说明用户可以新建或导入课表，不把导入描述成只有 JSON 文件一种方式。实际导入菜单继续提供文件、JSON 文本和学校网页入口，各入口沿用原有平台支持与校验规则。

当前或下一节课的高亮只在学期范围内计算：从第一周周一到最后一周周日。寒暑假不把被夹到首周或末周的周次当作真实授课周。周视图的实际周次和课程高亮使用同一次注入时钟读数，避免测试时钟或跨午夜时两者不一致；课表浏览仍可停留在首末周。

保存到隐藏日程分类时，编辑器显示分类名称与隐藏状态，保存后可直接查看日程；只有“显示分类”动作会修改可见性。分类颜色的主题色槽与固定 RGB 保持区分，未修改颜色的确认不产生颜色写入。

## 课表导入入口

学校网页导入使用统一 Agent：在学校网页选择导入后，先在来源页本地压缩、检查和编辑捕获内容，再继续到新会话。网页浏览、提取与压缩不要求先配置模型；Agent 未开启或模型未配置时，来源页保留草稿并进入功能管理或统一模型设置，返回后继续原材料。独立文字解析、解析结果编辑与解析 API 设置入口已退役；直接粘贴的文字在普通 Agent 会话处理。JSON 文本/文件、ICS 和节次的确定性直接导入继续保留。

学校配置成功读取后为空时，学校网页页只提示暂无可用学校，不要求用户检查内部配置文件。读取失败仍显示原有错误和重试入口。

学校站点使用持久 ID 区分身份，改名、改地址和排序不改变 ID。同名站点不自动合并；旧文件缺少 ID 时按兼容规则补齐，追加导入遇到身份冲突会生成副本 ID。Agent 修改仍须使用与当前版本绑定的句柄，详见[学校站点身份](SCHOOL_SITE_IDENTITIES.md)。

来源正文、脱敏 URL、标题、捕获时间、截断状态、目标上下文与首条消息一起持久保存后，才交给应用级 Agent 执行。重复点击和导航重试使用同一交接标识，不重复建会话；页面返回或关闭不取消已交接的运行。压缩前取消、来源已失效或交接保存失败不会发起模型请求。该去重不代表远端服务的推理或计费具有 exactly-once 保证。

`imports.prepare` 校验模型抽取的完整课表候选。缺少有效开学日期、总周数、课程周次或可解析时间时要求补充，不填今天或默认上课时间；来源没有作息时，明确选择已有时间集。替换必须指定真实目标课表 ID，目标失效时拒绝，不改写另一张当前课表。无效课程和超量输入整份拒绝，不静默丢弃。准备阶段不写课表；完整课表、课程、可选新作息与持久回执通过统一提交一次保存，并支持按对象核对的撤销。

只读计划模式可以解析并准备候选，每次修改前询问模式审批具体变更，完全权限模式在校验通过后直接提交。来源与模型回复均不能授予权限；保存状态来自领域回执。网页正文只作为材料，不作为系统指令或授权。HTTP 与新目的地的发送约束由统一 Agent 连接执行；浏览网页、压缩内容和导入文件不等同于允许向模型服务发送。

## 日程提醒

日程有三种提醒策略：

| 策略 | 作用 |
| --- | --- |
| 跟随默认 | 实时使用通知设置中的日程默认提前时间；默认关闭时不提醒 |
| 关闭 | 该日程不产生提醒 |
| 自定义 | 使用日程保存的一个或多个提前时间 |

新建日程默认跟随。旧记录缺少 `reminderBehavior` 时，非空提醒列表解释为自定义，空列表解释为关闭；不会根据当前设备默认值推断继承。复制和重复拆分保留原策略。修改默认值刷新正在打开的选择器预览，但不重置自定义草稿。

“隐藏日程分类后仍提醒”默认关闭，同时控制应用内提醒与系统通知。开启后普通日历仍隐藏该分类，但它的提醒和通知操作可用，打开通知不会自动显示分类。系统通知继续受通知总开关、权限和工作区启用状态控制。暂时关闭默认、隐藏分类或关闭隐藏提醒不会丢弃已处理记录。应用内提醒候选查询覆盖当前有效提醒的最大提前量，到达提前时刻立即显示，不再仅扫描未来 24 小时开始的事件。

## 重复日程编辑

从某个实例进入编辑时明确选择范围，所有详情、列表与系统通知入口共用同一规则。

| 范围 | 数据变化 |
| --- | --- |
| 仅本次 | 原系列排除该实例，新建一个不重复的独立日程 |
| 本次及以后 | 原 ID 保留前段，后段使用新 ID；首个候选实例等同整个系列 |
| 整个系列 | 原 ID 保留，影响该系列的过去和未来实例 |

单次修改产生的日程和拆分后的系列独立存在，后续整组操作不跨越这些记录。次数包含被排除的候选实例；多日事件按开始日划分。月末使用 `monthlyAnchorDay` 保留原始重复日，例如从二月末拆分每月 31 日仍会继续到三月 31 日。

单纯平移起点或时刻、实际重复步长不变时，排除日期继续按候选序号映射，超出新范围的例外移除。实际频率、间隔或单位改变时，只保留原有效排除日期中仍与新规则对齐、且处于新次数和截止范围内的绝对日期，不把这些排除日期移动到新的候选序号。停止重复时移除全部排除日期。“本次及以后”仅对所选候选及之后的例外应用这条规则，原系列前段保持不变。

重复步长按实际日历运算比较：每周与每 7 天等价，固定频率与相同步长的自定义规则等价；固定频率中未使用的单位字段不影响判断。只改次数或截止日期不算频率变化。编辑器保留既有规则的有效间隔，不因界面选择项或存储枚举不同而悄悄改变重复方式。仅切换等价规则表示或规范化未使用的单位字段，不清除已处理提醒。

导入的固定日、周或月规则若间隔大于 1，编辑器使用自定义间隔控件准确展示；实际间隔未改时保留原规则类型，普通内容编辑不会因此重置实例身份或已处理提醒。

修改实际重复步长且所选范围有排除日期时，保存前说明保留匹配日期、移除其余例外以及独立日程不受影响，并允许取消。取消返回编辑，保留草稿且不写入任何数据。确认后仍核对原对象、版本与任务有效性，不能用过期编辑覆盖后来发生的更改。

例如每周四的系列已跳过 10 月 15 日和 22 日，改为每天后，只要新范围仍包含这两天，它们继续被跳过；不会改为跳过新规则中相同序号的其他日期。确认期间不会提前保存，重复点击只产生一次写入；写入失败后保留草稿，重试再次说明例外变化。

原生时区跳过整天时，例如 Apia 的 2011 年 12 月 30 日，有效候选可能落到下一天；仍按实际候选核对次数与排除日期，避免最后一次已跳过的日程在变更规则或重新读取后恢复显示。

编辑在一个纯服务中计算所有记录及提醒状态，再一次持久化。保存前核对原对象和版本；冲突保留草稿，保存失败回滚全部变化，重试不会追加重复副本。范围外的已处理记录保留。

## 文件格式

备份页明确区分导出与恢复：保存、分享或复制备份不会替换当前应用数据；恢复先选择对象并展示新增、替换及依赖复制清单，确认后才写入。新的 ZIP 归档按所选范围携带业务对象、设置、知识、聊天及附件；复制旧完整 JSON 的兼容入口继续保留。Agent 使用相同的选择性恢复协调器，并遵守所选三种模式。便携归档不包含 API 密钥、Cookie、系统授权或运行许可。

日程 schema 为 **6**，同时包含提醒策略和可选月锚点；AppData 顶层为 **6**，在本机 Agent 配置与有界操作回执之上增加一次性开启迁移和模型目录。模型目录包含用户明确配置的具体思考档位及默认值，不提供自动档位，不根据模型名称推断。已发布的业务数据迁移不会生成未配置的模型；旧独立解析连接保留端点及凭据迁移，模型 ID 在设置中作为待配置候选。旧版通过根和嵌套版本校验拒绝读取新数据，避免忽略新字段后错误保存。完整备份保留提醒偏好、日程策略、月锚点和已处理记录；独立日程 JSON 不覆盖接收设备的通知偏好，导入的继承策略使用接收端默认值。

旧完整 JSON 与 AppData 导出不携带本机 Agent 连接、权限或操作回执；对应兼容读取也不采用外部文件中的这些字段。选择性 ZIP 可显式选择连接地址、模型目录和 Agent 偏好，但开关、三种权限和原始密钥沿用接收设备规则；变更连接目的地时先按恢复日志清理旧凭据。恢复目标、依赖映射和新数据世代在写入本机 journal 时固定，跨仓储中断后沿用同一目标。所有仓储读回核验后才解除普通写入限制；本机恢复 journal 与便携导出使用不同编码。撤销 Git 提交不等于回滚已保存的数据格式。

ICS 交换保留 `EXDATE`；同时存在 COUNT 与 UNTIL 时，导出排除例外之前的等价候选次数。月末截短使用 `BYMONTHDAY=d,-1;BYSETPOS=1` 的闭合子集。本地浮动时间保持浮动，UTC 保持 UTC。当前含 `TZID` 的事件时间属性无法无损解释时，仅跳过对应事件；检查覆盖重复属性和每一条 `EXDATE`，后面的字段不能掩盖不支持的时区。其余安全事件仍可导入，应用前先展示可复制的跳过清单，由用户取消或继续；取消保留原草稿与数据。没有安全事件时继续拒绝导入，并保留错误码、逐字段时区诊断和全部跳过原因。UTC、数值偏移及不带 TZID 的浮动本地时间维持原有基准，全天日期保持日期和排他结束。其他不支持的规则通过完整、可复制的导入报告说明，诊断不写入用户备注。ICS 仍不交换提醒，导出前提示并提供保留所选分类的 JSON 出口，替换导入前再次确认提醒覆盖风险；导入不会自动开启继承。完整状态交换使用 JSON 或备份。

ICS 文本导出将 CRLF、单独 CR 和 LF 统一为换行转义 `\n`，内容行仍使用 CRLF 分隔。备注或地点中的换行不会产生新的 ICS 属性，导入后保留为单个逻辑换行。

`TZID=UTC`、`TZID=Etc/UTC` 与 `TZID=GMT` 按 UTC 时间导入，导出恢复为 `Z` 时间；重复事件及多行、多值 `EXDATE` 使用相同 UTC 基准。重复或空 `TZID`、日期值上的 `TZID`、与 UTC 冲突的显式偏移仍使对应事件被跳过。

与本机真实 IANA 标识完全一致的 `TZID` 按现有浮动本地时间导入，保留钟面时刻、重复规则及本地例外日期；导出使用不带 `TZID` 或 `Z` 的浮动形式。界面在启动纯解析 worker 前通过平台获取标识，并把字符串显式传入；同步导入 API 的调用者可显式提供同一标识。查询失败、空标识或不同名称均不按 UTC 偏移猜测等价，仍跳过对应事件。UTC 别名优先使用 UTC 基准；本机 `TZID` 若又带显式 `Z`/数值偏移，或包含重复/空参数，仍视为不安全输入。

带 `TZID` 的导入边界只包括上述 UTC 别名与精确匹配的本机标识，不提供任意 IANA 时区的持久化重复模型。其他命名区按事件跳过，不因文件还包含安全事件而隐藏问题；应用前的完整清单列出受影响事件、字段和时区，用户可取消或继续导入安全部分。导入后改动设备时区时，本机 `TZID` 已转换的浮动时间仍遵循应用的本地时间模型。对应检查见 [时区解析](../test/services/general_calendar_ics_service_test.dart) 与 [应用前确认](../test/widgets/settings_page_test.dart)。

ICS 的 DESCRIPTION 只保存用户备注，不自动追加来源日历名。反复导入导出不会向备注累积日历标签；既有备注中用户自行写入的 `Calendar:` 文本也不会被猜测删除。

ICS 折行按输入顺序线性归并，空格与制表符续行只移除第一个续行标记，不反复复制已经归并的整段内容；长备注不会改变其后的独立属性。

ICS 接受与现有实例序列等价的 RRULE 修饰：WEEKLY 中单个、无序号且与 DTSTART 星期相同的 BYDAY；合法且不影响这些规则的 WKST；MONTHLY 中等于 DTSTART 日期且不超过 28 的单值 BYMONTHDAY。多星期、带序号或不匹配的 BYDAY、超出上述范围的单值 BYMONTHDAY 仍降为单次事件并在导入报告列明；既有月末截短闭合写法继续保持等价往返。

不带 BY 修饰的 YEARLY 按每 `12 × INTERVAL` 个月导入，保留 COUNT 与 UNTIL；转换后的月间隔超过模型上限 999 时降为单次并报告，不夹成另一个频率。2 月 29 日起始的年度规则保留现有月末截短行为：非闰年移至 2 月 28 日，后续闰年恢复 2 月 29 日，同时明确提示与源规则跳过不存在日期的差异。

ICS 改期实例按原始 UID 关联唯一母系列，与文件先后顺序无关。RECURRENCE-ID 必须精确匹配母系列在 COUNT/UNTIL 内的原候选；成功时原日期加入 EXDATE，改期内容导入为独立单次事件。STATUS:CANCELLED 的实例只排除原候选，不要求另带 DTSTART；已取消的母事件也不会成为活动日程。孤立或歧义 UID、重复实例覆盖、类型/时刻错配及 RANGE 扩展会跳过并报告；替代事件解析失败时保留母系列原实例。已有普通重复 UID 仍保留各条记录并生成唯一 ID。

ICS 的 DATE-TIME UNTIL 按瞬间包含边界：先转到 DTSTART 的 UTC/本地基准，再定位开始时刻不晚于截止时刻的最后候选，把该候选日期写入现有模型；无偏移的 UNTIL 使用 DTSTART 的钟面基准。计算复用候选定位，不全量展开远期实例，并在 EXDATE 排除之前与 COUNT 取交集。DATE UNTIL 仍包含整天。截止早于首个候选时跳过该日程并报告，避免日期规范化重新保留首实例。

通过文件选择器读取 ICS、JSON、节次模板及学校站点文本时，共用 20 MB（20,000,000 字节，含 BOM）上限：先预检文件长度，再按有界读取范围累计实际字节，超限会显示本地化提示且不进入解析或保存。严格 UTF-8 解码移除文件开头的 UTF-8 BOM，保留内部 U+FEFF 和原始空白；非法 UTF-8 仍拒绝，不猜测其他编码。此字节限制独立于 JSON/备份的模型条数预算。

ICS 解析完成后、选择追加或替换分类及任何保存之前，统一展示完整可复制的导入报告，包含跳过、时间调整、规则降级和保留规则的差异提示。无法表达的重复规则明确标为“将按单次事件导入”，不让用户误以为只丢弃某个修饰字段。取消会保留文本草稿，来源会话过期时拒绝应用；确认后仍执行原分类选择及提醒替换确认。成功只显示导入结果，不再次弹出同一报告；全部无法导入时保留完整错误报告。

普通 MONTHLY 从 29–31 日开始且候选范围内会遇到较短月份时，导入前报告明确说明：规则仍保留，但 Sked 将不存在的日期移到月底，源规则则跳过这些日期且不计入次数。检测遵守 COUNT/UNTIL，只检查有界的公历循环；不会到达短月、仅一次或提前截止的规则不误报。已有 `BYMONTHDAY=d,-1;BYSETPOS=1` 的等价月末写法不提示差异。用户接受差异后才应用；取消保留输入和存档，不改用跳过缺月日期的另一种重复模型。例如 1 月 31 日起、共三次的系列仍为 1 月 31 日、2 月末、3 月 31 日，移到月末的候选仍计入 COUNT。见 [月末差异回归](../test/services/general_calendar_ics_clamping_warning_test.dart) 与 [重复往返回归](../test/services/general_calendar_ics_recurrence_roundtrip_test.dart)。

## 验证边界

回归应覆盖宽窄布局、触控、桌面、大字号、取消、源对象失效、保存失败与重试，并比较重复系列导出回读后的实际实例集合。重复例外变更由 [候选映射](../test/models/general_recurrence_exception_policy_test.dart)、[范围编辑服务](../test/services/general_event_recurrence_change_test.dart) 和 [确认与持久化流程](../test/widgets/general_recurrence_exception_confirmation_test.dart) 共同验证。内存通知网关测试验证排程和路由规则；Windows 和 Android 系统通知实际投递仍需分别进行设备验收。
