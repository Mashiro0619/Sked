# Agent 网页与来源

`web.fetch` 读取公开网页，返回正文、链接和来源信息；地址指向附件时，保存完整文件。模型可以继续访问返回的链接，整理多篇通知或处理相关附件。

## 读取页面与附件

工具接收 `url`，支持 HTTP 和 HTTPS。正文来自服务器返回的页面，不执行页面脚本。登录后才能查看的内容，可以通过原有学校浏览器选取后交给 Agent。

下载内容分块保存，文本按页面声明的字符集解码。HTML 提取保留标题、段落、列表、表格和预格式文本，移除脚本、样式及输入控件。相对链接按页面地址和有效的 `base` 地址转换为完整地址，方便继续读取页面、图片和文档。

通过 `visibility:hidden` 隐藏的文字保留表格列位置和列表序号，避免后续内容错位。

SVG 图片和链接同时识别 `href` 与 `xlink:href`，两者并存时使用 `href`。

正文和链接清单完整保存为 UTF-8 文本。首次返回一页，后续通过 `content.read` 和返回的 `contentId` 继续读取。分页在完整字符边界结束，每页都来自同一次保存的内容。

附件进入[文件内容处理流程](AGENT_CONTENT.md)。当前模型支持的图片、PDF 等文件直接发送实际内容，其他文件保留完整字节，供后续提取和处理。

## 来源与日期

工具结果保存原始地址、重定向后的地址、抓取时间、HTTP 状态、原始媒体类型与压缩方式、文件名、长度和摘要。网页标题、正文与链接清单关联同一次抓取；重定向出现循环时返回错误。

发布日期取网站明确提供的出版字段，例如文章元数据或 JSON-LD 的 `datePublished`，同时保留日期原值和出处。HTTP `Last-Modified` 单独记录为服务器提供的修改时间；网站没有声明发布日期时，该项保持空缺。

JSON-LD 的文章实体地址可以与网页地址不同，发布日期按页面与文章的明确关联归属。

网页工具使用独立的匿名客户端。

## 内容与生命周期

页面和附件随原工具消息保存。重新打开会话后，`contentId` 仍能读取当时的内容；再次访问同一地址会保存新版本和新的抓取时间。

用户停止后，当前下载与解析结束，已保存的会话内容继续保留。临时下载文件在内容保存完成后释放。

网页服务通过 `sked.web@1` 接入。HTTP Provider 和工具分别属于独立插件，工具注册复用现有目录。插件退出时停止接收新调用，等待下载、解析和已经接纳的保存完成后释放资源；退出时再次回收临时文件，返回最终清理结果。

默认组合、实施进度与后续验收见[插件架构](AGENT_PLUGIN_ARCHITECTURE.md)。
