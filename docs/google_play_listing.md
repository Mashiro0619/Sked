## Full Description

```text
Sked 是一款本地优先的课表与日程管理应用，适合学生管理课程、周次、节次时间，也可以作为通用日历工具记录日常事件。

你可以用 Sked 创建多个课表，编辑课程名称、地点、教师、周次、节次、备注和自定义字段；也可以切换到通用日程模式，管理日历、事件、提醒和月视图 / 日视图等不同显示方式。

主要功能：

• 学生课表管理
创建、切换、编辑和删除多个课表，按周查看课程安排，支持当前课程和下一节课程提示。

• 课程与节次编辑
自由设置课程时间、上课地点、教师、周次范围、关联节次、备注和自定义信息。

• 通用日程模式
独立管理普通日程事件，支持日历视图、事件编辑、重复规则、提醒、搜索和多日历管理。

• 导入与导出
支持课表 JSON、通用日程 JSON / ICS、完整应用备份、文本导入导出和分享，方便迁移数据。

• 学校网页 / HTML 导入
可在应用内打开学校网站或粘贴页面内容，并通过你自己配置的 OpenAI 兼容解析接口辅助解析课表。Sked 不内置解析接口，解析请求只会发送到你填写的自定义接口。

• 本地优先与隐私
课表、日程、设置、节次时间和学校站点配置默认保存在本机。完整备份不会包含自定义解析 API 密钥。应用不会自动把你的本地数据上传到开发者服务器。

• 个性化外观
支持浅色、深色、跟随系统，以及主题色和多彩界面设置。

Sked 适合需要灵活管理课程表、学习安排、校园课表导入和个人日程的用户。无论是手动整理课程，还是备份、恢复、分享自己的日程数据，都可以在一个应用里完成。
```
